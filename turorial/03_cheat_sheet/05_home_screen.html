Mục 5: Mẫu Màn Hình Home (HomeScreen) & Quản Lý State Riverpod

Đây là màn hình chính Home (HomeScreen) của ứng dụng sau khi đăng nhập thành công. Màn hình hỗ trợ linh hoạt cả 2 dạng hiển thị phổ biến nhất trong đề thi PE: dạng danh sách cuộn dọc (ListView) và dạng lưới thích ứng (GridView responsive: nằm dọc 2 cột, nằm ngang 3 cột). Cả 2 dạng đã được tách riêng thành các Widget chuẩn mực (ItemListWidget và ItemGridWidget), kết hợp với Riverpod Code Gen để tự động làm mới giao diện khi có thay đổi dữ liệu.

Lưu ý: Hộp thoại xác nhận xóa (DeleteDialog) và xử lý sự kiện xóa đã được tách riêng thành một module chuyên biệt tại Mục 6: DeleteDialog →

Danh mục nội dung:
  • 1. Toàn bộ mã nguồn class HomeScreen (lib/screens/home_screen.dart)
  • 2. Hướng dẫn chuyển đổi nhanh giữa ListView và GridView trong phòng thi
  • 3. Hình ảnh minh họa giao diện UI HomeScreen (Danh sách & Trạng thái rỗng)
  • 4. Giải thích chi tiết code HomeScreen: Dùng để làm gì, dùng thế nào & vì sao?
  • 5. Class ItemNotifier (lib/providers/item_provider.dart) & Lệnh sinh mã Code Gen
  • 6. Widget danh sách ListView: ItemListWidget & ItemCardWidget
  • 7. Widget dạng lưới GridView: ItemGridWidget (Responsive) & ItemGridCardWidget

1. Toàn Bộ Mã Nguồn Class HomeScreen (lib/screens/home_screen.dart)

Màn hình Home quản lý hiển thị dữ liệu qua Riverpod, nút Thêm mới (FAB), nút Đăng xuất trên AppBar và tích hợp sẵn cả 2 lựa chọn hiển thị (ListView / GridView):

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../models/item_example.dart';
import '../providers/item_provider.dart';
import '../services/session_service.dart';
import '../widgets/delete_dialog.dart'; // Import Dialog xóa tách riêng
import '../widgets/item_list_widget.dart'; // Widget hiển thị dạng ListView tách riêng
import '../widgets/item_grid_widget.dart'; // Widget hiển thị dạng GridView tách riêng
import '../widgets/app_drawer.dart'; // Widget Drawer thanh menu bên hông (Xem Mục 10)
import 'add_item_screen.dart'; // Màn Thêm mới
import 'edit_item_screen.dart'; // Màn Chỉnh sửa
import 'detail_screen.dart'; // Màn Chi tiết
import 'login_screen.dart';

class HomeScreen extends ConsumerWidget {
  const HomeScreen({super.key});

  // Xử lý Xóa phần tử & Hiển thị SnackBar thông báo thành công
  Future<void> _handleDelete(BuildContext context, WidgetRef ref, ItemModel item) async {
    // 1. Mở dialog xác nhận xóa đã tách riêng ở file DeleteDialog
    final bool confirm = await DeleteDialog.show(context, item.title);

    if (confirm && item.id != null) {
      // 2. Gọi Riverpod xóa item
      await ref.read(itemProvider.notifier).deleteItem(item.id!);

      if (!context.mounted) return;
      // 3. HIỆN SNACKBAR THÔNG BÁO XÓA THÀNH CÔNG
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Đã xóa "${item.title}" thành công!'),
          duration: const Duration(seconds: 2),
          action: SnackBarAction(
            label: 'ĐÓNG',
            textColor: Colors.amber,
            onPressed: () {},
          ),
        ),
      );
    }
  }

  Future<void> _logout(BuildContext context) async {
    await SessionService.clearSession();
    if (!context.mounted) return;
    Navigator.pushAndRemoveUntil(
      context,
      MaterialPageRoute(builder: (_) => const LoginScreen()),
      (route) => false,
    );
  }

  void _navigateToEdit(BuildContext context, ItemModel item) {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => EditItemScreen(item: item)),
    );
  }

  void _navigateToDetail(BuildContext context, ItemModel item) {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => DetailScreen(item: item)),
    );
  }

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final asyncItems = ref.watch(itemProvider);

    return Scaffold(
      drawer: const AppDrawer(),
      appBar: AppBar(
        title: const Text('Danh sách'),
        centerTitle: true,
        actions: [
          IconButton(
            icon: const Icon(Icons.logout),
            tooltip: 'Đăng xuất',
            onPressed: () => _logout(context),
          ),
        ],
      ),
      // Xử lý 3 trạng thái với .when: loading, error, data (kèm xử lý rỗng)
      body: asyncItems.when(
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (err, stack) => Center(child: Text('Lỗi: $err')),
        data: (items) {
          // TRẠNG THÁI KHÔNG CÓ DỮ LIỆU (EMPTY STATE)
          if (items.isEmpty) {
            return const Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Icon(Icons.inbox, size: 64, color: Colors.grey),
                  SizedBox(height: 12),
                  Text(
                    'Chưa có dữ liệu nào',
                    style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
                  ),
                  SizedBox(height: 6),
                  Text(
                    '(No items found)',
                    style: TextStyle(color: Colors.grey),
                  ),
                ],
              ),
            );
          }

          // ===================================================================
          // CHEAT SHEET PHÒNG THI - TÙY BIẾN HIỂN THỊ LISTVIEW / GRIDVIEW:
          // ===================================================================
          // [TRƯỜNG HỢP 1] Đề bắt: "Dọc là List, Ngang là Grid" (Mặc định)
          // [TRƯỜNG HỢP 2] Đề bắt: "Dọc là Grid, Ngang là List":
          //    -> Đổi: if (isPortrait) return ItemGridWidget(...)
          //            else return ItemListWidget(...)
          // [TRƯỜNG HỢP 3] Đề chỉ bắt duy nhất ListView:
          //    -> Xóa OrientationBuilder, return ItemListWidget(...)
          // [TRƯỜNG HỢP 4] Đề chỉ bắt duy nhất GridView:
          //    -> Xóa OrientationBuilder, return ItemGridWidget(...)
          // ===================================================================
          return OrientationBuilder(
            builder: (context, orientation) {
              final isPortrait = orientation == Orientation.portrait;

              // 1. Màn hình DỌC (Portrait) -> Mặc định là ListView
              if (isPortrait) {
                return ItemListWidget(
                  items: items,
                  onDelete: (item) => _handleDelete(context, ref, item),
                  onEdit: (item) => _navigateToEdit(context, item),
                  onTap: (item) => _navigateToDetail(context, item),
                );
              }

              // 2. Màn hình NGANG (Landscape) -> Mặc định là GridView (3 cột)
              return ItemGridWidget(
                items: items,
                landscapeCount: 3, // Tùy chỉnh số cột khi xoay ngang
                onDelete: (item) => _handleDelete(context, ref, item),
                onEdit: (item) => _navigateToEdit(context, item),
                onTap: (item) => _navigateToDetail(context, item),
              );
            },
          );
        },
      ),
      // Nút Thêm mới dẫn sang AddItemScreen
      floatingActionButton: FloatingActionButton(
        onPressed: () {
          Navigator.push(
            context,
            MaterialPageRoute(builder: (_) => const AddItemScreen()),
          );
        },
        child: const Icon(Icons.add),
      ),
    );
  }
}

2. Hướng Dẫn Chuyển Đổi Nhanh Giữa ListView Và GridView Trong Phòng Thi

Tùy theo yêu cầu của đề thi PE, bạn chỉ cần thay đổi nhanh trong khối OrientationBuilder của HomeScreen:

  • Mặc định (Dọc là List, Ngang là Grid): 
    if (isPortrait) {
  return ItemListWidget(...); // Dọc là ListView
}
return ItemGridWidget(..., landscapeCount: 3); // Ngang là GridView 3 cột
  • Nếu đề bắt "Dọc là Grid, Ngang là List": Hoán đổi 2 widget cho nhau: 
    if (isPortrait) {
  return ItemGridWidget(..., portraitCount: 2); // Dọc là GridView 2 cột
}
return ItemListWidget(...); // Ngang là ListView
  • Nếu đề chỉ bắt duy nhất 1 dạng (không cần xoay): Xóa OrientationBuilder, return thẳng ItemListWidget(...) hoặc ItemGridWidget(...).

4. Giải Thích Chi Tiết Code HomeScreen: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

1. Bản chất màn hình Home (HomeScreen) và điều hướng

  • Dùng để làm gì: HomeScreen là trung tâm điều hướng của ứng dụng: Xem danh sách, mở xem chi tiết (tap), mở chỉnh sửa (nút bút xanh), xóa phần tử và mở màn thêm mới (nút FAB).
  • Lợi ích của việc tách Widget hiển thị riêng: Tách ItemListWidget và ItemGridWidget giúp code màn hình HomeScreen cực kỳ ngắn gọn, dễ chuyển đổi định dạng theo đề bài mà không sợ làm hỏng logic xóa hay mở màn hình con.

2. Kế thừa ConsumerWidget & Cơ chế ref.watch

  • Dùng để làm gì: ConsumerWidget cung cấp biến WidgetRef ref trong hàm build().
  • final asyncItems = ref.watch(itemProvider);: Lắng nghe liên tục dữ liệu từ itemProvider. Bất cứ khi nào có hành động Thêm/Sửa/Xóa thành công, Riverpod tự động kích hoạt hàm build() của HomeScreen chạy lại để cập nhật giao diện mới nhất.
  • Xử lý 3 trạng thái với asyncItems.when(...):
    - loading: Hiện CircularProgressIndicator() khi đang đọc SQLite.
    - error: Hiện lỗi nếu câu lệnh truy vấn CSDL thất bại.
    - data: Nhận danh sách List<ItemModel> để hiển thị.

3. Xử lý Đăng xuất (Logout) trên AppBar

  • Gọi await SessionService.clearSession() xóa sạch thông tin đăng nhập trong SharedPreferences.
  • Dùng Navigator.pushAndRemoveUntil(..., (route) => false) xóa sạch toàn bộ lịch sử màn hình cũ, ngăn người dùng bấm phím Back quay lại màn Home.

4. Tích hợp Drawer Menu bên hông & Chuyển đổi Theme (AppDrawer)

  • Khai báo drawer: const AppDrawer() trong Scaffold. Flutter tự động sinh icon Menu 3 gạch (hamburger icon) bên trái AppBar khi có thuộc tính drawer.
  • Khi bấm vào menu hoặc vuốt từ cạnh trái, ngăn kéo AppDrawer trượt ra với lời chào tên người dùng và công tắc Switch chuyển đổi giao diện Sáng / Tối trực tiếp. Chi tiết xem tại Mục 10: Drawer & Theme Service →

5. Toàn Bộ Mã Nguồn Class ItemNotifier (lib/providers/item_provider.dart)

Quản lý toàn bộ State danh sách items (đọc từ SQLite, thêm, sửa, xóa) và tự động làm mới UI:

import 'package:riverpod_annotation/riverpod_annotation.dart';
import '../utils/database_helper.dart';
import '../models/item_example.dart';

// 1. DÒNG BẮT BUỘC: Liên kết file sinh mã tự động
part 'item_provider.g.dart';

// 2. Annotation @riverpod: Tự động sinh ra itemProvider
@riverpod
class ItemNotifier extends _$ItemNotifier {
  // Hàm build() bất đồng bộ: Riverpod sẽ tự quản lý trạng thái Loading/Error/Data
  @override
  Future<List<ItemModel>> build() async {
    final rawData = await DatabaseHelper.instance.getAllItems();
    return rawData.map((e) => ItemModel.fromMap(e)).toList();
  }

  // Thêm một item mới
  Future<void> addItem(ItemModel item) async {
    await DatabaseHelper.instance.insertItem(item.toMap());
    // Làm mới lại danh sách -> UI tự động cập nhật
    ref.invalidateSelf();
    await future;
  }

  // Cập nhật một item theo ID
  Future<void> updateItem(ItemModel item) async {
    if (item.id == null) return;
    await DatabaseHelper.instance.updateItem(item.id!, item.toMap());
    ref.invalidateSelf();
    await future;
  }

  // Xóa một item theo ID
  Future<void> deleteItem(int id) async {
    await DatabaseHelper.instance.deleteItem(id);
    ref.invalidateSelf();
    await future;
  }
}
BẮT BUỘC CHẠY LỆNH CODE GENERATOR SAU KHI TẠO FILE NÀY:

File item_provider.g.dart được liên kết bằng part 'item_provider.g.dart'; là file do máy tự sinh, BẠN KHÔNG CẦN TỰ GÕ FILE ĐÓ. Mở Terminal tại thư mục dự án và chạy ngay lệnh sau:

dart run build_runner build --delete-conflicting-outputs

Lệnh này sẽ tự động sinh ra file lib/providers/item_provider.g.dart chứa itemProvider và lớp cha _$ItemNotifier trong 5 giây, mọi gạch đỏ báo lỗi biến mất ngay lập tức!

6. Widget Danh Sách ListView (lib/widgets/item_list_widget.dart & item_list_card_widget.dart)

Bộ đôi widget chịu trách nhiệm hiển thị danh sách cuộn dọc chuẩn mực:

6.1. File lib/widgets/item_list_widget.dart

Bọc ListView.builder và truyền sự kiện chạm, sửa, xóa xuống từng dòng:

import 'package:flutter/material.dart';
import '../models/item_example.dart';
import 'item_list_card_widget.dart';

class ItemListWidget extends StatelessWidget {
  final List<ItemModel> items;
  final void Function(ItemModel item) onDelete;
  final void Function(ItemModel item)? onEdit;
  final void Function(ItemModel item)? onTap;

  const ItemListWidget({
    super.key,
    required this.items,
    required this.onDelete,
    this.onEdit,
    this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return ListView.builder(
      padding: const EdgeInsets.symmetric(vertical: 8),
      itemCount: items.length,
      itemBuilder: (context, index) {
        final item = items[index];
        return ItemCardWidget(
          item: item,
          index: index,
          onDelete: () => onDelete(item),
          onEdit: onEdit != null ? () => onEdit!(item) : null,
          onTap: onTap != null ? () => onTap!(item) : null,
        );
      },
    );
  }
}

import 'package:flutter/material.dart';

class ItemCardWidget extends StatelessWidget {

7. Widget Dạng Lưới GridView (lib/widgets/item_grid_widget.dart & item_grid_card_widget.dart)

Bộ đôi widget chịu trách nhiệm hiển thị dạng lưới và tự động Responsive xoay màn hình:

7.1. File lib/widgets/item_grid_widget.dart (Tự động thích ứng: Dọc 2 cột, Ngang 3 cột)

Sử dụng MediaQuery.of(context).orientation để tự động chuyển 2 cột khi dọc và 3 cột khi ngang, cùng tỉ lệ khung hình childAspectRatio phù hợp tránh tràn giao diện:

import 'package:flutter/material.dart';
import '../models/item_example.dart';
import 'item_grid_card_widget.dart';

class ItemGridWidget extends StatelessWidget {
  final List<ItemModel> items;
  final void Function(ItemModel item) onDelete;
  final void Function(ItemModel item)? onEdit;
  final void Function(ItemModel item)? onTap;

  /// Cố định số cột (nếu truyền vào thì bỏ qua responsive)
  final int? crossAxisCount;

  /// Số cột khi màn hình DỌC (Portrait) - mặc định là 2
  final int portraitCount;

  /// Số cột khi màn hình NGANG (Landscape) - mặc định là 3
  final int landscapeCount;

  /// Tỉ lệ chiều rộng / chiều cao của mỗi item
  final double? childAspectRatio;

  const ItemGridWidget({
    super.key,
    required this.items,
    required this.onDelete,
    this.onEdit,
    this.onTap,
    this.crossAxisCount,
    this.portraitCount = 2,
    this.landscapeCount = 3,
    this.childAspectRatio,
  });

  @override
  Widget build(BuildContext context) {
    // Kiểm tra hướng màn hình hiện tại
    final isLandscape = MediaQuery.of(context).orientation == Orientation.landscape;

    // Responsive: Dọc = 2 cột, Ngang = 3 cột (hoặc lấy crossAxisCount cố định nếu được truyền)
    final int effectiveCrossAxisCount = crossAxisCount ?? (isLandscape ? landscapeCount : portraitCount);

    // Tỉ lệ kích thước item: Ngang cần tỉ lệ cao hơn để card không bị kéo dài quá mức
    final double effectiveAspectRatio = childAspectRatio ?? (isLandscape ? 0.95 : 0.8);

    return GridView.builder(
      padding: const EdgeInsets.all(8),
      gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
        crossAxisCount: effectiveCrossAxisCount,
        crossAxisSpacing: 8,
        mainAxisSpacing: 8,
        childAspectRatio: effectiveAspectRatio,
      ),
      itemCount: items.length,
      itemBuilder: (context, index) {
        final item = items[index];
        return ItemGridCardWidget(
          item: item,
          index: index,
          onDelete: () => onDelete(item),
          onEdit: onEdit != null ? () => onEdit!(item) : null,
          onTap: onTap != null ? () => onTap!(item) : null,
        );
      },
    );
  }
}

7.2. File lib/widgets/item_grid_card_widget.dart

Card được thiết kế chuyên biệt cho ô lưới GridView: bố cục cột gọn gàng, có badge phân loại, tiêu đề, mô tả tóm tắt, giá tiền và nút Sửa/Xóa mini:

import 'package:flutter/material.dart';
import '../models/item_example.dart';

class ItemGridCardWidget extends StatelessWidget {
  final ItemModel item;
  final int index;
  final VoidCallback onDelete;
  final VoidCallback? onEdit;
  final VoidCallback? onTap;

  const ItemGridCardWidget({
    super.key,
    required this.item,
    required this.index,
    required this.onDelete,
    this.onEdit,
    this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return Card(
      elevation: 2,
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
      clipBehavior: Clip.antiAlias,
      child: InkWell(
        onTap: onTap,
        child: Padding(
          padding: const EdgeInsets.all(10.0),
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // Hàng trên: Số thứ tự & Tag phân loại (Category)
              Row(
                mainAxisAlignment: MainAxisAlignment.spaceBetween,
                children: [
                  CircleAvatar(
                    radius: 12,
                    child: Text(
                      '${index + 1}',
                      style: const TextStyle(fontSize: 11, fontWeight: FontWeight.bold),
                    ),
                  ),
                  if (item.category != null && item.category!.isNotEmpty)
                    Container(
                      padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
                      decoration: BoxDecoration(
                        color: Colors.blue.shade50,
                        borderRadius: BorderRadius.circular(6),
                      ),
                      child: Text(
                        item.category!,
                        style: TextStyle(
                          fontSize: 11,
                          color: Colors.blue.shade700,
                          fontWeight: FontWeight.w600,
                        ),
                      ),
                    ),
                ],
              ),
              const SizedBox(height: 8),

              // Tiêu đề
              Text(
                item.title,
                maxLines: 1,
                overflow: TextOverflow.ellipsis,
                style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 14),
              ),
              const SizedBox(height: 2),

              // Dòng phụ / Mô tả ngắn
              Expanded(
                child: Text(
                  item.subtitle,
                  maxLines: 2,
                  overflow: TextOverflow.ellipsis,
                  style: TextStyle(color: Colors.grey.shade600, fontSize: 12),
                ),
              ),

              // Giá tiền
              Text(
                '\$${item.price ?? 0.0}',
                style: TextStyle(
                  color: Colors.green.shade700,
                  fontWeight: FontWeight.bold,
                  fontSize: 13,
                ),
              ),
              const Divider(height: 10),

              // Hàng nút: Chỉnh sửa & Xóa
              Row(
                mainAxisAlignment: MainAxisAlignment.end,
                children: [
                  if (onEdit != null)
                    IconButton(
                      icon: const Icon(Icons.edit, color: Colors.blue, size: 20),
                      visualDensity: VisualDensity.compact,
                      tooltip: 'Chỉnh sửa',
                      onPressed: onEdit,
                    ),
                  IconButton(
                    icon: const Icon(Icons.delete, color: Colors.red, size: 20),
                    visualDensity: VisualDensity.compact,
                    tooltip: 'Xóa mục này',
                    onPressed: onDelete,
                  ),
                ],
              ),
            ],
          ),
        ),
      ),
    );
  }
}
