Mục 4: Mẫu Màn Hình Login, Quản Lý Session & Xử Lý Logout

Cung cấp đầy đủ mã nguồn class SessionService và class LoginScreen lên trên cùng, kèm hình ảnh minh họa giao diện iPhone SE trên trình duyệt và các mục giải thích chi tiết: Dùng để làm gì, dùng thế nào và vì sao.

1. Toàn Bộ Mã Nguồn Class SessionService (lib/services/session_service.dart)

Quản lý cờ trạng thái đăng nhập người dùng bằng SharedPreferences, lưu trữ thông tin phiên làm việc và xóa cờ khi Logout:

import 'package:shared_preferences/shared_preferences.dart';

class SessionService {
  static const String keyIsLoggedIn = 'isLoggedIn';
  static const String keyUsername = 'username';

  // Lưu cờ đăng nhập thành công
  static Future<void> saveSession(String username) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(keyIsLoggedIn, true);
    await prefs.setString(keyUsername, username);
  }

  // Kiểm tra trạng thái đã đăng nhập chưa
  static Future<bool> isLoggedIn() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(keyIsLoggedIn) ?? false;
  }

  // Lấy tên người dùng hiện tại
  static Future<String> getUsername() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(keyUsername) ?? 'User';
  }

  // Xóa cờ khi Logout
  static Future<void> clearSession() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.clear();
  }
}

2. Giải Thích Code SessionService: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

  • Hàm saveSession(String username):
    Dùng để làm gì: Lưu cờ isLoggedIn = true và tên người dùng vào SharedPreferences ngay sau khi xác thực mật khẩu thành công.
    Dùng thế nào: Gọi await SessionService.saveSession(username) trong hàm _login().
  • Hàm isLoggedIn():
    Dùng để làm gì: Kiểm tra xem người dùng đã từng đăng nhập trước đó hay chưa.
    Dùng thế nào: Gọi trong hàm main() trước khi khởi chạy runApp() để phân luồng điều hướng màn hình đầu tiên.
    Vì sao có ?? false: Nếu app mới cài lần đầu, key chưa tồn tại trong bộ nhớ sẽ trả về null, fallback ?? false đảm bảo luôn trả về boolean hợp lệ.
  • Hàm getUsername():
    Dùng để làm gì: Lấy tên người dùng hiện tại để hiển thị câu chào "Welcome, admin" trên AppBar hoặc Drawer của HomeScreen.
  • Hàm clearSession():
    Dùng để làm gì: Xóa sạch toàn bộ key trong SharedPreferences khi người dùng bấm nút Đăng xuất (Logout).

3. Toàn Bộ Mã Nguồn Class LoginScreen (lib/screens/login_screen.dart)

Màn hình đăng nhập chuẩn của đề thi: Xác thực với SQLite thông qua DatabaseHelper, lưu phiên và chuyển sang HomeScreen:

import 'package:flutter/material.dart';
import '../utils/database_helper.dart';
import '../services/session_service.dart';
import '../utils/app_validator.dart';
import 'home_screen.dart';
import 'register_screen.dart';

class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State<LoginScreen> createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final _formKey = GlobalKey<FormState>();
  final _usernameController = TextEditingController();
  final _passwordController = TextEditingController();

  @override
  void dispose() {
    _usernameController.dispose();
    _passwordController.dispose();
    super.dispose();
  }

  Future<void> _login() async {
    // 1. Kiểm tra validator các ô nhập
    if (!_formKey.currentState!.validate()) return;

    final username = _usernameController.text.trim();
    final password = _passwordController.text.trim();

    // 2. Xác thực tài khoản với DatabaseHelper
    final user = await DatabaseHelper.instance.loginUser(username, password);

    if (user != null) {
      // 3. Lưu session
      await SessionService.saveSession(username);

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Đăng nhập thành công! Chào $username')),
      );

      // 4. Chuyển sang màn HomeScreen
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(builder: (_) => const HomeScreen()),
      );
    } else {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Sai tên đăng nhập hoặc mật khẩu!'),
          backgroundColor: Colors.red,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Login'),
        centerTitle: true,
      ),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Username (Có validator từ AppValidator)
              TextFormField(
                controller: _usernameController,
                decoration: const InputDecoration(
                  labelText: 'Username',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.loginUsername,
              ),
              const SizedBox(height: 16),

              // Field 2: Password (Có validator từ AppValidator)
              TextFormField(
                controller: _passwordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Password',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.loginPassword,
              ),
              const SizedBox(height: 20),

              // Nút bấm Đăng nhập
              ElevatedButton(
                onPressed: _login,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: const Text('LOGIN', style: TextStyle(fontSize: 16)),
              ),
              const SizedBox(height: 12),
              // Nút chuyển sang màn hình Đăng ký
              TextButton(
                onPressed: () {
                  Navigator.push(
                    context,
                    MaterialPageRoute(builder: (_) => const RegisterScreen()),
                  );
                },
                child: const Text('Chưa có tài khoản? Đăng ký ngay'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

4. Hình Ảnh Minh Họa Giao Diện UI Chuẩn iPhone SE Trên Trình Duyệt

Đối chiếu chuẩn xác 100% từng dòng code Flutter (AppBar có tiêu đề Login, 2 ô OutlineInputBorder căn giữa màn hình và SnackBar đỏ báo lỗi khi sai thông tin):

1. Màn hình ban đầu (Chưa nhập)

Giao diện 2 trường Username & Password căn giữa màn hình kèm nút LOGIN và TextButton chuyển sang Đăng ký.

2. Màn hình khi sai tên đăng nhập / mật khẩu

Hiển thị SnackBar đỏ: "Sai tên đăng nhập hoặc mật khẩu!" chuẩn Flutter.

5. Giải Thích Chi Tiết Code LoginScreen & Cơ Chế Xử Lý Logout: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

1. Luồng xử lý của hàm _login()

  • Kiểm tra validation: Gọi if (!_formKey.currentState!.validate()) return; kích hoạt kiểm tra không được để trống của AppValidator.loginUsername và AppValidator.loginPassword.
  • Truy vấn xác thực SQLite: Gọi DatabaseHelper.instance.loginUser(username, password). Hàm này thực hiện câu lệnh SQL tìm user có username và password trùng khớp.
    Nếu tìm thấy (user != null): Gọi SessionService.saveSession(username) để lưu phiên, hiện SnackBar chào mừng và chuyển trang bằng Navigator.pushReplacement sang HomeScreen.
    Nếu không tìm thấy (user == null): Hiện SnackBar màu đỏ cảnh báo sai thông tin.
  • Chống crash bằng if (!mounted) return;: Kiểm tra bắt buộc sau mọi tác vụ bất đồng bộ await trước khi gọi ScaffoldMessenger hoặc Navigator.

2. Cơ chế xử lý Đăng xuất (Logout) trên HomeScreen

Trên thanh AppBar của HomeScreen có nút Icon Đăng xuất. Đoạn code xử lý Logout chuẩn như sau:

Future<void> _logout(BuildContext context) async {
  // 1. Xóa sạch cờ đăng nhập và username trong SharedPreferences
  await SessionService.clearSession();

  if (!context.mounted) return;

  // 2. Chuyển về LoginScreen và XÓA SẠCH toàn bộ lịch sử điều hướng
  Navigator.pushAndRemoveUntil(
    context,
    MaterialPageRoute(builder: (_) => const LoginScreen()),
    (route) => false,
  );
}
  • Vì sao dùng pushAndRemoveUntil với điều kiện (route) => false: Lệnh này xóa sạch toàn bộ ngăn xếp điều hướng (Navigation Stack). Người dùng sau khi Logout sẽ không thể bấm phím Back để quay lại xem nội dung của HomeScreen nữa, đảm bảo bảo mật và đúng chuẩn ứng dụng thương mại.
