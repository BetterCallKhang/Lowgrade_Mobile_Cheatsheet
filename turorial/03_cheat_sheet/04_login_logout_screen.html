Mục 4: Mẫu Màn Hình Login & Xử Lý Logout (Tối Giản, Đủ Tiêu Chí Chấm Điểm)

Mẫu code được thiết kế tối giản nhất có thể, không màu mè hay responsive rườm rà. Chỉ tập trung đúng và đủ các yêu cầu thi: Tên field chuẩn (Username, Password), gọi trực tiếp AppValidator đã tạo ở Mục 2, xác thực SQLite, lưu cờ Session và nút Logout có Confirmation Dialog.

⚡ Danh mục code mẫu cần copy:
  • 1. File dịch vụ Session (Lưu/Xoá cờ login) - lib/services/session_service.dart
  • 2. Màn hình LoginScreen tối giản chuẩn thi - lib/screens/login_screen.dart
  • 3. Hình ảnh minh hoạ giao diện UI màn hình Login
  • 4. Nút Logout đặt trên AppBar / Drawer (Kèm Confirm Dialog)

1. File Quản Lý Session (lib/services/session_service.dart)

Dùng lúc nào? Lưu trạng thái đăng nhập để khi tắt app mở lại không bắt đăng nhập lại, và xoá cờ khi bấm Logout.

import 'package:shared_preferences/shared_preferences.dart';

class SessionService {
  static const String keyIsLoggedIn = 'isLoggedIn';
  static const String keyUsername = 'username';

  // Lưu cờ đăng nhập thành công
  static Future<void> saveSession(String username) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(keyIsLoggedIn, true);
    await prefs.setString(keyUsername, username);
  }

  // Kiểm tra trạng thái đã đăng nhập chưa
  static Future<bool> isLoggedIn() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(keyIsLoggedIn) ?? false;
  }

  // Lấy tên người dùng hiện tại
  static Future<String> getUsername() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(keyUsername) ?? 'User';
  }

  // Xóa cờ khi Logout
  static Future<void> clearSession() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.clear();
  }
}

2. Màn Hình LoginScreen Tối Giản (lib/screens/login_screen.dart)

Dùng lúc nào? Đáp ứng Task User Login. Chỉ gồm đúng 2 ô nhập (Username, Password) dùng thẳng AppValidator của Mục 2, 1 nút Đăng nhập và 1 link Đăng ký nếu đề có.

import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../services/session_service.dart';
import '../utils/app_validator.dart';
import 'home_screen.dart';

class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State<LoginScreen> createState() => _LoginScreenState();
}

class _LoginScreenState extends State<LoginScreen> {
  final _formKey = GlobalKey<FormState>();
  final _usernameController = TextEditingController();
  final _passwordController = TextEditingController();

  @override
  void dispose() {
    _usernameController.dispose();
    _passwordController.dispose();
    super.dispose();
  }

  Future<void> _login() async {
    // 1. Kiểm tra validator các ô nhập
    if (!_formKey.currentState!.validate()) return;

    final username = _usernameController.text.trim();
    final password = _passwordController.text.trim();

    // 2. Xác thực tài khoản với DatabaseHelper
    final user = await DatabaseHelper.instance.loginUser(username, password);

    if (user != null) {
      // 3. Lưu session
      await SessionService.saveSession(username);

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Đăng nhập thành công! Chào $username')),
      );

      // 4. Chuyển sang màn HomeScreen
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(builder: (_) => const HomeScreen()),
      );
    } else {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Sai tên đăng nhập hoặc mật khẩu!'),
          backgroundColor: Colors.red,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Login'),
        centerTitle: true,
      ),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            mainAxisAlignment: MainAxisAlignment.center,
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Username (Có validator từ AppValidator)
              TextFormField(
                controller: _usernameController,
                decoration: const InputDecoration(
                  labelText: 'Username',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.loginUsername,
              ),
              const SizedBox(height: 16),

              // Field 2: Password (Có validator từ AppValidator)
              TextFormField(
                controller: _passwordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Password',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.loginPassword,
              ),
              const SizedBox(height: 20),

              // Nút bấm Đăng nhập
              ElevatedButton(
                onPressed: _login,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: const Text('LOGIN', style: TextStyle(fontSize: 16)),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

3. Hình Ảnh Minh Hoạ Giao Diện UI Màn Hình Login Chuẩn Flutter

Đối chiếu chính xác 100% với từng dòng code Flutter ở trên (AppBar centerTitle: true, 2 ô OutlineInputBorder, ElevatedButton và hiệu ứng viền đỏ báo lỗi của Form Validator):

1. Màn hình ban đầu (Chưa nhập gì)

Trạng thái nghỉ: Ô nhập viền xám mỏng, label nổi tự nhiên, nút LOGIN sẵn sàng.

2. Màn hình khi nhập sai / để trống

Trạng thái lỗi: Viền đỏ 2px, nhãn đỏ, text báo lỗi bên dưới ô và SnackBar đỏ dưới đáy.

4. Nút Đăng Xuất Logout (Kèm Hộp Thoại Xác Nhận)

Dùng lúc nào? Gắn vào nút Logout trên AppBar của màn hình HomeScreen:

// ========================================================
// 1. HÀM XỬ LÝ LOGOUT KÈM CONFIRM DIALOG (Dán vào _HomeScreenState)
// ========================================================
Future<void> _confirmLogout(BuildContext context) async {
  final bool? confirm = await showDialog<bool>(
    context: context,
    builder: (ctx) => AlertDialog(
      title: const Text('Xác nhận đăng xuất'),
      content: const Text('Bạn có chắc chắn muốn đăng xuất không?'),
      actions: [
        TextButton(
          onPressed: () => Navigator.pop(ctx, false),
          child: const Text('Hủy'),
        ),
        ElevatedButton(
          onPressed: () => Navigator.pop(ctx, true),
          child: const Text('Đăng xuất'),
        ),
      ],
    ),
  );

  if (confirm == true) {
    // Xoá session đã lưu
    await SessionService.clearSession();

    if (!context.mounted) return;
    // Quay về LoginScreen và xoá toàn bộ route cũ
    Navigator.pushAndRemoveUntil(
      context,
      MaterialPageRoute(builder: (_) => const LoginScreen()),
      (route) => false,
    );
  }
}

// ========================================================
// 2. CÁCH GẮN VÀO APPBAR TRONG MÀN HÌNH HOMESCREEN
// ========================================================
AppBar(
  title: const Text('Home'),
  actions: [
    IconButton(
      icon: const Icon(Icons.logout),
      tooltip: 'Đăng xuất',
      onPressed: () => _confirmLogout(context),
    ),
  ],
)
