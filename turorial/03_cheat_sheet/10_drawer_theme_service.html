Mục 10: Mẫu Thanh Menu Ngăn Kéo (AppDrawer), Theme Custom & Chuyển Đổi Giao Diện Sáng / Tối

Trong các đề thi PE nâng cao, đề bài thường yêu cầu bổ sung thanh menu bên hông (Drawer) chứa thông tin người dùng đang đăng nhập, kèm tính năng chuyển đổi qua lại giữa Giao diện Sáng (Light Theme) và Giao diện Tối (Dark Theme). Hơn nữa, giao diện được cấu hình theo bảng màu chuyên biệt:

  • Theme Sáng: Tiêu đề AppBar & Nút bấm màu CAM (DeepOrange), nền màn hình màu KEM (#FFF8E7).
  • Theme Tối: Tiêu đề AppBar & Nút bấm màu XANH BIỂN (Blue), nền màn hình màu ĐEN (Black / #121212).
  • Lưu trữ bền vững: Ghi nhớ trạng thái sáng/tối vào SharedPreferences để khi tắt app mở lại không bị mất.
  • Riverpod State: Đổi theme tức thì toàn bộ ứng dụng mà không cần khởi động lại.
Danh mục nội dung:
  • 1. Toàn bộ mã nguồn Widget AppDrawer (lib/widgets/app_drawer.dart)
  • 2. Toàn bộ cấu hình AppTheme (lib/utils/app_theme.dart)
  • 3. Quản lý lưu trữ ThemeService SharedPreferences (lib/services/theme_service.dart)
  • 4. Quản lý State ThemeNotifier Riverpod Code Gen (lib/providers/theme_provider.dart)
  • 5. Hướng dẫn kết nối vào main.dart và HomeScreen
  • 6. Hình ảnh minh họa trực quan giao diện Sáng / Tối của AppDrawer
  • 7. Giải thích chi tiết kiến trúc 4 tầng: Dùng để làm gì, dùng thế nào & vì sao?

1. Toàn Bộ Mã Nguồn Widget AppDrawer (lib/widgets/app_drawer.dart)

Thanh menu ngăn kéo chuẩn Material 3: Header hiển thị Avatar cùng tên tài khoản đăng nhập từ SessionService, hàng SwitchListTile gạt đổi theme sáng/tối, menu Trang chủ và nút Đăng xuất an toàn: 

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../providers/theme_provider.dart';
import '../services/session_service.dart';
import '../screens/login_screen.dart';

class AppDrawer extends ConsumerWidget {
  const AppDrawer({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final themeMode = ref.watch(themeProvider);
    final isDark = themeMode == ThemeMode.dark;
    final colorScheme = Theme.of(context).colorScheme;

    return Drawer(
      child: Column(
        children: [
          // 1. Header của Drawer hiển thị Avatar & Tên tài khoản từ Session
          DrawerHeader(
            decoration: BoxDecoration(
              color: colorScheme.primaryContainer,
            ),
            child: SizedBox(
              width: double.infinity,
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  CircleAvatar(
                    radius: 30,
                    backgroundColor: colorScheme.primary,
                    child: Icon(
                      Icons.person,
                      size: 36,
                      color: colorScheme.onPrimary,
                    ),
                  ),
                  const SizedBox(height: 12),
                  FutureBuilder<String>(
                    future: SessionService.getUsername(),
                    builder: (context, snapshot) {
                      final username = snapshot.data ?? 'Người dùng';
                      return Text(
                        'Xin chào, $username!',
                        style: TextStyle(
                          fontSize: 18,
                          fontWeight: FontWeight.bold,
                          color: colorScheme.onPrimaryContainer,
                        ),
                      );
                    },
                  ),
                ],
              ),
            ),
          ),

          // 2. Nút gạt (Switch) chuyển đổi Theme Sáng / Tối tức thì
          SwitchListTile(
            secondary: Icon(
              isDark ? Icons.dark_mode : Icons.light_mode,
              color: isDark ? Colors.blue : Colors.deepOrange,
            ),
            title: const Text(
              'Chế độ tối',
              style: TextStyle(fontWeight: FontWeight.w600),
            ),
            subtitle: Text(
              isDark ? 'Giao diện Đen - Xanh biển' : 'Giao diện Kem - Cam',
              style: const TextStyle(fontSize: 12),
            ),
            value: isDark,
            onChanged: (bool value) {
              ref.read(themeProvider.notifier).toggleTheme(value);
            },
          ),

          const Divider(),

          // 3. Menu Trang chủ (Đóng ngăn kéo Drawer)
          ListTile(
            leading: const Icon(Icons.home),
            title: const Text('Trang chủ'),
            onTap: () {
              Navigator.pop(context); // Đóng drawer
            },
          ),

          const Spacer(),
          const Divider(),

          // 4. Nút Đăng xuất: Xóa Session và điều hướng về Login
          ListTile(
            leading: const Icon(Icons.logout, color: Colors.red),
            title: const Text(
              'Đăng xuất',
              style: TextStyle(color: Colors.red, fontWeight: FontWeight.bold),
            ),
            onTap: () async {
              await SessionService.clearSession();
              if (!context.mounted) return;
              Navigator.pushAndRemoveUntil(
                context,
                MaterialPageRoute(builder: (_) => const LoginScreen()),
                (route) => false,
              );
            },
          ),
          const SizedBox(height: 16),
        ],
      ),
    );
  }
}

2. Toàn Bộ Cấu Hình Bộ Màu AppTheme (lib/utils/app_theme.dart)

Tập trung toàn bộ cấu hình giao diện Sáng / Tối vào một file duy nhất theo đúng yêu cầu đề bài: Sáng = Nền kem + Tiêu đề cam, Tối = Nền đen + Tiêu đề xanh biển: 

import 'package:flutter/material.dart';

class AppTheme {
  // Màu kem cho nền theme sáng (Cream color)
  static const Color creamBackground = Color(0xFFFFF8E7);
  // Màu cam cho tiêu đề theme sáng
  static const Color orangePrimary = Colors.deepOrange;

  // Màu đen cho nền theme tối
  static const Color blackBackground = Colors.black;
  // Màu xanh biển cho tiêu đề theme tối
  static const Color bluePrimary = Colors.blue;

  // =========================================================================
  // 1. THEME SÁNG: Tiêu đề màu CAM, nền màu KEM
  // =========================================================================
  static final ThemeData lightTheme = ThemeData(
    useMaterial3: true,
    brightness: Brightness.light,
    scaffoldBackgroundColor: creamBackground,
    colorScheme: ColorScheme.fromSeed(
      seedColor: orangePrimary,
      brightness: Brightness.light,
      surface: creamBackground,
    ),
    appBarTheme: const AppBarTheme(
      backgroundColor: creamBackground,
      foregroundColor: orangePrimary,
      centerTitle: true,
      elevation: 0,
      titleTextStyle: TextStyle(
        color: orangePrimary,
        fontSize: 20,
        fontWeight: FontWeight.bold,
      ),
      iconTheme: IconThemeData(color: orangePrimary),
    ),
    floatingActionButtonTheme: const FloatingActionButtonThemeData(
      backgroundColor: orangePrimary,
      foregroundColor: Colors.white,
    ),
    drawerTheme: const DrawerThemeData(
      backgroundColor: creamBackground,
    ),
  );

  // =========================================================================
  // 2. THEME TỐI: Tiêu đề màu XANH BIỂN, nền màu ĐEN
  // =========================================================================
  static final ThemeData darkTheme = ThemeData(
    useMaterial3: true,
    brightness: Brightness.dark,
    scaffoldBackgroundColor: blackBackground,
    colorScheme: ColorScheme.fromSeed(
      seedColor: bluePrimary,
      brightness: Brightness.dark,
      surface: const Color(0xFF1E1E1E),
    ),
    appBarTheme: const AppBarTheme(
      backgroundColor: blackBackground,
      foregroundColor: bluePrimary,
      centerTitle: true,
      elevation: 0,
      titleTextStyle: TextStyle(
        color: bluePrimary,
        fontSize: 20,
        fontWeight: FontWeight.bold,
      ),
      iconTheme: IconThemeData(color: bluePrimary),
    ),
    floatingActionButtonTheme: const FloatingActionButtonThemeData(
      backgroundColor: bluePrimary,
      foregroundColor: Colors.white,
    ),
    drawerTheme: const DrawerThemeData(
      backgroundColor: Color(0xFF121212),
    ),
  );
}

3. Dịch Vụ Lưu Trữ Theme Bền Vững (lib/services/theme_service.dart)

Sử dụng SharedPreferences để lưu cờ boolean is_dark_mode. Giúp app ghi nhớ trạng thái sáng/tối ngay cả khi người dùng tắt hẳn ứng dụng: 

import 'package:shared_preferences/shared_preferences.dart';

class ThemeService {
  static const String keyIsDarkMode = 'is_dark_mode';

  // Lưu trạng thái theme (true: dark, false: light)
  static Future<void> saveThemeMode(bool isDark) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(keyIsDarkMode, isDark);
  }

  // Đọc trạng thái theme từ SharedPreferences
  static Future<bool> isDarkMode() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(keyIsDarkMode) ?? false;
  }
}

4. Quản Lý Trạng Thái ThemeNotifier Riverpod Code Gen (lib/providers/theme_provider.dart)

Notifier quản lý trạng thái ThemeMode hiện tại với cú pháp Riverpod Code Generation (@riverpod). Tự động nạp theme đã lưu khi khởi tạo và cung cấp hàm toggleTheme: 

import 'package:flutter/material.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';
import '../services/theme_service.dart';

// 1. DÒNG BẮT BUỘC: Liên kết file sinh mã tự động
part 'theme_provider.g.dart';

// 2. Annotation @riverpod: Tự động sinh ra themeProvider
@riverpod
class ThemeNotifier extends _$ThemeNotifier {
  @override
  ThemeMode build() {
    // Khởi tạo và đọc theme đã lưu từ SharedPreferences
    _loadTheme();
    return ThemeMode.light;
  }

  // Đọc theme đã lưu từ SharedPreferences
  Future<void> _loadTheme() async {
    final isDark = await ThemeService.isDarkMode();
    state = isDark ? ThemeMode.dark : ThemeMode.light;
  }

  // Đổi qua lại giữa theme sáng và tối, đồng thời lưu vào SharedPreferences
  Future<void> toggleTheme(bool isDark) async {
    state = isDark ? ThemeMode.dark : ThemeMode.light;
    await ThemeService.saveThemeMode(isDark);
  }
}
Lệnh sinh file theme_provider.g.dart tự động:

Mở Terminal trong thư mục dự án và chạy lệnh sau:

dart run build_runner build --delete-conflicting-outputs

File theme_provider.g.dart sẽ tự sinh ra chứa themeProvider và _$ThemeNotifier chỉ trong vài giây.

5. Hướng Dẫn Kết Nối Vào main.dart & HomeScreen

5.1. Kết nối tại lib/main.dart

Bọc ứng dụng bằng ConsumerWidget, lắng nghe themeProvider và truyền vào MaterialApp:

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'screens/register_screen.dart';
import 'services/session_service.dart';
import 'screens/home_screen.dart';
import 'providers/theme_provider.dart'; // Import themeProvider
import 'utils/app_theme.dart';           // Import cấu hình AppTheme

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  final bool isLoggedIn = await SessionService.isLoggedIn();

  runApp(
    ProviderScope(
      child: MyApp(startAtHome: isLoggedIn),
    ),
  );
}

class MyApp extends ConsumerWidget { // Dùng ConsumerWidget để đọc ref
  final bool startAtHome;
  const MyApp({super.key, required this.startAtHome});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // 1. Lắng nghe trạng thái Theme hiện tại
    final themeMode = ref.watch(themeProvider);

    return MaterialApp(
      title: 'Exam Practical App',
      debugShowCheckedModeBanner: false,
      // 2. Gán cấu hình Theme động
      themeMode: themeMode,
      theme: AppTheme.lightTheme,
      darkTheme: AppTheme.darkTheme,
      home: startAtHome ? const HomeScreen() : const RegisterScreen(),
    );
  }
}

6. Hình Ảnh Minh Họa Giao Diện Sáng / Tối Của AppDrawer

So sánh trực quan hai trạng thái giao diện khi mở ngăn kéo AppDrawer:

7. Giải Thích Chi Tiết Kiến Trúc 4 Tầng: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

1. Tầng Giao Diện: AppTheme (ThemeData)

  • Dùng để làm gì: Gom toàn bộ thông số màu sắc vào hai đối tượng ThemeData (Sáng: Nền kem + Tiêu đề cam; Tối: Nền đen + Tiêu đề xanh biển).
  • Dùng thế nào: Định nghĩa các thuộc tính scaffoldBackgroundColor, colorScheme, appBarTheme, floatingActionButtonTheme và drawerTheme.
  • Vì sao cần tách riêng: Khi đề thi yêu cầu đổi màu chủ đạo (ví dụ sang Xanh lá hoặc Tím), bạn chỉ cần đổi đúng 1 file app_theme.dart, toàn bộ các màn hình Register, Login, Home, Add, Edit, Detail sẽ tự động đổi màu theo mà không cần sửa code từng màn hình.

2. Tầng Lưu Trữ: ThemeService (SharedPreferences)

  • Dùng để làm gì: Lưu và đọc cờ boolean is_dark_mode xuống bộ nhớ máy tính/trình duyệt.
  • Dùng thế nào: Cung cấp 2 hàm static: saveThemeMode(bool isDark) và isDarkMode().
  • Vì sao cần tách riêng: Độc lập hoàn toàn với giao diện. Khi chạy ứng dụng, dù người dùng đóng app hay refresh lại trình duyệt web Chrome, thiết lập theme vẫn được giữ nguyên.

3. Tầng Quản Lý State: ThemeNotifier (@riverpod)

  • Dùng để làm gì: Giữ trạng thái phản ứng (reactive state) của ThemeMode trong bộ nhớ RAM khi app đang chạy.
  • Dùng thế nào: Gọi ref.read(themeProvider.notifier).toggleTheme(value) khi người dùng gạt công tắc Switch.
  • Vì sao cần dùng Riverpod: Không cần truyền callback hay bọc InheritedWidget phức tạp. main.dart lắng nghe qua ref.watch(themeProvider) sẽ tự rebuild MaterialApp tức thì, chuyển màu toàn bộ ứng dụng mượt mà trong 1 frame hình ảnh.

4. Tầng Thành Phần UI: AppDrawer (Widget)

  • Dùng để làm gì: Hiển thị ngăn kéo menu bên hông chuẩn Material Design khi gắn vào Scaffold(drawer: const AppDrawer()).
  • Dùng thế nào: Dùng DrawerHeader + FutureBuilder nạp tên tài khoản từ SessionService.getUsername(), kết hợp SwitchListTile và ListTile Đăng xuất.
  • Vì sao cần tách thành widget riêng: Có thể gắn vào bất kỳ màn hình nào (HomeScreen, DetailScreen, ProfileScreen...) mà không lặp lại code, giúp file home_screen.dart luôn tinh gọn và dễ chấm điểm.
