Mục 3: Mẫu Màn Hình Đăng Ký (Register Screen) Chuẩn Đề Thi

Mẫu code được thiết kế tối giản, chỉ gồm đúng 4 trường bắt buộc của đề bài: Username, Email, Password và Password Confirm. Sử dụng toàn bộ các hàm static có sẵn trong AppValidator (Mục 2), kiểm tra tài khoản trùng trong SQLite qua DatabaseHelper, hiển thị SnackBar và có hình ảnh minh hoạ đối chiếu trực quan.

⚡ Danh mục nội dung:
  • 1. Code RegisterScreen hoàn chỉnh (lib/screens/register_screen.dart)
  • 2. Hình ảnh minh hoạ giao diện UI màn hình Register chuẩn Flutter
  • 3. Cách mở màn hình Register từ LoginScreen

1. Code RegisterScreen Hoàn Chỉnh (lib/screens/register_screen.dart)

Dùng lúc nào? Đáp ứng Task User Registration. Gồm đúng 4 trường và 1 nút Bấm:

  • Username: Kiểm tra không rỗng và độ dài ≥ 3 ký tự (gọi AppValidator.registerUsername).
  • Email: Kiểm tra không rỗng và Regex email chuẩn (gọi AppValidator.email).
  • Password: Kiểm tra không rỗng và độ dài ≥ 6 ký tự (gọi AppValidator.registerPassword).
  • Confirm Password: Kiểm tra khớp mật khẩu (gọi AppValidator.confirmPassword(_passwordController.text)).
  • Kiểm tra trùng: Gọi DatabaseHelper.instance.isUsernameExists trước khi thêm.
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../utils/app_validator.dart';
import 'login_screen.dart';

class RegisterScreen extends StatefulWidget {
  const RegisterScreen({super.key});

  @override
  State<RegisterScreen> createState() => _RegisterScreenState();
}

class _RegisterScreenState extends State<RegisterScreen> {
  final _formKey = GlobalKey<FormState>();
  final _usernameController = TextEditingController();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  final _confirmPasswordController = TextEditingController();

  @override
  void dispose() {
    _usernameController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _confirmPasswordController.dispose();
    super.dispose();
  }

  Future<void> _register() async {
    // 1. Kiểm tra toàn bộ validators của Form
    if (!_formKey.currentState!.validate()) return;

    final username = _usernameController.text.trim();
    final email = _emailController.text.trim();
    final password = _passwordController.text.trim();

    try {
      // 2. Kiểm tra tài khoản đã tồn tại trong CSDL chưa
      final isExists = await DatabaseHelper.instance.isUsernameExists(username);
      if (isExists) {
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Tên đăng nhập đã tồn tại trong CSDL!'),
            backgroundColor: Colors.red,
          ),
        );
        return;
      }

      // 3. Thêm tài khoản mới vào SQLite
      await DatabaseHelper.instance.registerUser({
        'username': username,
        'email': email,
        'password': password,
      });

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Đăng ký tài khoản thành công!'),
          backgroundColor: Colors.green,
        ),
      );

      // 4. Điều hướng sang màn hình LoginScreen
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(builder: (_) => const LoginScreen()),
      );
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Register'),
        centerTitle: true,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Username
              TextFormField(
                controller: _usernameController,
                decoration: const InputDecoration(
                  labelText: 'Username',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.registerUsername,
              ),
              const SizedBox(height: 16),

              // Field 2: Email
              TextFormField(
                controller: _emailController,
                keyboardType: TextInputType.emailAddress,
                decoration: const InputDecoration(
                  labelText: 'Email',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.email,
              ),
              const SizedBox(height: 16),

              // Field 3: Password
              TextFormField(
                controller: _passwordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Password',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.registerPassword,
              ),
              const SizedBox(height: 16),

              // Field 4: Confirm Password
              TextFormField(
                controller: _confirmPasswordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Confirm Password',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.confirmPassword(_passwordController.text),
              ),
              const SizedBox(height: 20),

              // Nút Đăng ký
              ElevatedButton(
                onPressed: _register,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: const Text('REGISTER', style: TextStyle(fontSize: 16)),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

2. Hình Ảnh Minh Hoạ Giao Diện UI Màn Hình Register Chuẩn Flutter

Đối chiếu chuẩn xác 100% từng dòng code Flutter (AppBar có tiêu đề Register, 4 ô OutlineInputBorder và hiệu ứng viền đỏ báo lỗi):

1. Màn hình ban đầu (Chưa nhập gì)

4 trường yêu cầu: Username, Email, Password, Confirm Password ở trạng thái nghỉ.

2. Màn hình khi để trống hoặc nhập sai

Báo đỏ chuẩn Flutter: Trống username, sai định dạng email, mật khẩu xác nhận không khớp.

3. Cách Mở Màn Hình Register Từ Màn Hình Login

Trong LoginScreen, bên dưới nút Đăng nhập, thêm một nút văn bản nhỏ để người dùng bấm chuyển sang RegisterScreen:

TextButton(
  onPressed: () {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => const RegisterScreen()),
    );
  },
  child: const Text('Chưa có tài khoản? Đăng ký ngay'),
)
