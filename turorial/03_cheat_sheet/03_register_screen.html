Mục 3: Mẫu Màn Hình Đăng Ký (Register Screen) Chuẩn Đề Thi

Mã nguồn đầy đủ class RegisterScreen trong lib/screens/register_screen.dart được đưa lên trên cùng. Tiếp theo là hình ảnh minh họa giao diện iPhone SE trên trình duyệt, và bên dưới là phần giải thích chi tiết từng mục: Dùng để làm gì, dùng thế nào và vì sao.

Danh mục nội dung:
  • 1. Toàn bộ mã nguồn class RegisterScreen (lib/screens/register_screen.dart)
  • 2. Hình ảnh minh họa giao diện UI iPhone SE trên trình duyệt (Khởi tạo & Báo lỗi)
  • 3. Giải thích chi tiết code: Dùng để làm gì, dùng thế nào và vì sao?

1. Toàn Bộ Mã Nguồn Class RegisterScreen (lib/screens/register_screen.dart)

Đáp ứng trọn vẹn Task User Registration của đề thi: Gồm 4 trường Form (Username, Email, Password, Confirm Password), tích hợp kiểm tra trùng tài khoản SQLite, hiển thị SnackBar và nút chuyển sang Login:

import 'package:flutter/material.dart';
import '../utils/database_helper.dart';
import '../utils/app_validator.dart';
import 'login_screen.dart';

class RegisterScreen extends StatefulWidget {
  const RegisterScreen({super.key});

  @override
  State<RegisterScreen> createState() => _RegisterScreenState();
}

class _RegisterScreenState extends State<RegisterScreen> {
  final _formKey = GlobalKey<FormState>();
  final _usernameController = TextEditingController();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  final _confirmPasswordController = TextEditingController();

  @override
  void dispose() {
    _usernameController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _confirmPasswordController.dispose();
    super.dispose();
  }

  Future<void> _register() async {
    // 1. Kiểm tra toàn bộ validators của Form
    if (!_formKey.currentState!.validate()) return;

    final username = _usernameController.text.trim();
    final email = _emailController.text.trim();
    final password = _passwordController.text.trim();

    try {
      // 2. Kiểm tra tài khoản đã tồn tại trong CSDL chưa
      final isExists = await DatabaseHelper.instance.isUsernameExists(username);
      if (isExists) {
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Tên đăng nhập đã tồn tại trong CSDL!'),
            backgroundColor: Colors.red,
          ),
        );
        return;
      }

      // 3. Thêm tài khoản mới vào SQLite
      await DatabaseHelper.instance.registerUser({
        'username': username,
        'email': email,
        'password': password,
      });

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Đăng ký tài khoản thành công!'),
          backgroundColor: Colors.green,
        ),
      );

      // 4. Điều hướng sang màn hình LoginScreen
      Navigator.pushReplacement(
        context,
        MaterialPageRoute(builder: (_) => const LoginScreen()),
      );
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Register'),
        centerTitle: true,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Username
              TextFormField(
                controller: _usernameController,
                decoration: const InputDecoration(
                  labelText: 'Username',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.registerUsername,
              ),
              const SizedBox(height: 16),

              // Field 2: Email
              TextFormField(
                controller: _emailController,
                keyboardType: TextInputType.emailAddress,
                decoration: const InputDecoration(
                  labelText: 'Email',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.email,
              ),
              const SizedBox(height: 16),

              // Field 3: Password
              TextFormField(
                controller: _passwordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Password',
                  border: OutlineInputBorder(),
                ),
                validator: AppValidator.registerPassword,
              ),
              const SizedBox(height: 16),

              // Field 4: Confirm Password
              TextFormField(
                controller: _confirmPasswordController,
                obscureText: true,
                decoration: const InputDecoration(
                  labelText: 'Confirm Password',
                  border: OutlineInputBorder(),
                ),
                validator: (value) =>
                    AppValidator.confirmPassword(value, _passwordController.text),
              ),
              const SizedBox(height: 20),

              // Nút Đăng ký
              ElevatedButton(
                onPressed: _register,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: const Text('REGISTER', style: TextStyle(fontSize: 16)),
              ),
              const SizedBox(height: 12),
              // Nút quay lại màn hình Đăng nhập
              TextButton(
                onPressed: () {
                  Navigator.pushReplacement(
                    context,
                    MaterialPageRoute(builder: (_) => const LoginScreen()),
                  );
                },
                child: const Text('Đã có tài khoản? Đăng nhập ngay'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

2. Hình Ảnh Minh Họa Giao Diện UI Chuẩn iPhone SE Trên Trình Duyệt

Đối chiếu chuẩn xác 100% từng dòng code Flutter (AppBar có tiêu đề Register, 4 ô nhập OutlineInputBorder và hiệu ứng viền đỏ báo lỗi khi validate thất bại):

1. Màn hình ban đầu (Chưa nhập gì)

4 trường yêu cầu: Username, Email, Password, Confirm Password ở trạng thái khởi tạo.

2. Màn hình khi để trống hoặc nhập sai

Báo lỗi chuẩn Flutter: Trống username, sai định dạng email, mật khẩu xác nhận không khớp.

3. Giải Thích Chi Tiết Từng Phần Code: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

1. Quản lý Controller & Hàm dispose()

  • Dùng để làm gì? 4 biến TextEditingController dùng để đọc chuỗi văn bản người dùng nhập vào ô TextField và lắng nghe thay đổi.
  • Dùng thế nào? Khởi tạo ở đầu State và gọi controller.dispose() bên trong hàm dispose().
  • Vì sao? Bắt buộc phải giải phóng bộ nhớ khi rời màn hình để tránh hiện tượng rò rỉ bộ nhớ (Memory Leak) trong Flutter.

2. Quy trình xử lý hàm _register()

  • Bước 1 - Validate Form: Gọi if (!_formKey.currentState!.validate()) return; để kích hoạt toàn bộ các hàm validator của 4 trường. Nếu có bất kỳ ô nào chưa đạt yêu cầu, form lập tức hiện thông báo đỏ và dừng thực thi.
  • Bước 2 - Kiểm tra tài khoản tồn tại: Gọi await DatabaseHelper.instance.isUsernameExists(username). Nếu trả về true → Hiện SnackBar đỏ báo lỗi và dừng lại, không chèn đè.
  • Bước 3 - Lưu vào SQLite: Gọi await DatabaseHelper.instance.registerUser(...) để thêm bản ghi mới vào bảng users.
  • Bước 4 - Thông báo & Chuyển trang: Hiển thị SnackBar màu xanh báo thành công và chuyển sang LoginScreen bằng lệnh:
    Navigator.pushReplacement(context, MaterialPageRoute(builder: (_) => const LoginScreen()));
    Vì sao dùng pushReplacement: Để thay thế hoàn toàn màn hình Register trên ngăn xếp điều hướng, ngăn người dùng bấm phím Back quay lại form đăng ký vừa hoàn thành.
  • Kiểm tra if (!mounted) return;:
    Vì sao: Sau mỗi lệnh await bất đồng bộ, người dùng có thể đã tắt hoặc thoát màn hình. Kiểm tra mounted giúp đảm bảo State còn tồn tại trên Widget Tree trước khi truy cập context, tránh lỗi crash kinh điển "Looking up a deactivated widget's ancestor is unsafe".

3. Cấu trúc Widget Tree trong hàm build()

  • SingleChildScrollView:
    Vì sao dùng: Khi người dùng bấm vào các ô nhập ở dưới, bàn phím ảo (virtual keyboard) sẽ bật lên chiếm 50% màn hình. Bọc trong SingleChildScrollView giúp giao diện tự động cuộn lên được, chống triệt để lỗi tràn pixel sọc vàng đen (RenderFlex overflowed).
  • obscureText: true trên ô Mật khẩu:
    Dùng để làm gì: Che giấu các ký tự mật khẩu thành các dấu chấm tròn bảo mật.
  • keyboardType: TextInputType.emailAddress trên ô Email:
    Dùng để làm gì: Bàn phím ảo trên điện thoại sẽ tự động xuất hiện sẵn phím ký tự @ giúp thao tác nhập email thuận tiện nhất.
  • Nút TextButton chuyển sang Đăng nhập:
    Dùng để làm gì: Cho phép người dùng chuyển thẳng sang màn hình LoginScreen nếu họ đã có tài khoản sẵn từ trước.
