1. Nhóm Danh Sách Cuộn & Lưới (ListView & GridView Đầy Đủ Constructors)

Đây là 2 widget then chốt của hầu hết các bài thi di động. Mỗi loại cung cấp nhiều Named Constructors cho từng kịch bản cụ thể.

A. Phân Tích Toàn Bộ Constructors Của ListView

Hiển thị danh sách phần tử cuộn theo 1 chiều (mặc định là cuộn dọc).

1. Constructor Mặc Định: ListView(...)

Dùng khi: Danh sách có số lượng phần tử ít, cố định đã biết trước (ví dụ: màn hình Cài đặt Settings, vài nút bấm). Toàn bộ widget con được tạo ngay lập tức (eager loading).

ListView({
  Key? key,
  Axis scrollDirection = Axis.vertical, // Chiều cuộn: vertical hoặc horizontal
  bool reverse = false,                 // Đảo ngược thứ tự cuộn từ dưới lên
  ScrollPhysics? physics,               // Hiệu ứng cuộn (BouncingScrollPhysics, NeverScrollableScrollPhysics...)
  bool shrinkWrap = false,              // Co gọn lại bằng chiều cao nội dung con
  EdgeInsetsGeometry? padding,          // Khoảng đệm bao quanh danh sách
  List children = const [], // Danh sách các widget con
})

2. Constructor Tối Ưu: ListView.builder(...) ⭐ (Thường Dùng Nhất)

Dùng khi: Danh sách động lấy từ SQLite / API có số lượng lớn hoặc chưa biết trước. Áp dụng cơ chế tái sử dụng widget (Lazy Loading / Virtualization) - chỉ vẽ các dòng đang nằm trên màn hình.

ListView.builder({
  Key? key,
  Axis scrollDirection = Axis.vertical,
  bool shrinkWrap = false,
  ScrollPhysics? physics,
  EdgeInsetsGeometry? padding,
  required int itemCount,                        // Tổng số lượng phần tử
  required NullableIndexedWidgetBuilder itemBuilder, // Hàm dựng từng dòng: (context, index) => Widget
})

// Ví dụ thực tế:
ListView.builder(
  itemCount: items.length,
  padding: const EdgeInsets.all(8),
  itemBuilder: (context, index) {
    final item = items[index];
    return Card(
      child: ListTile(
        title: Text(item.title),
        subtitle: Text('\$${item.price}'),
      ),
    );
  },
)

3. Constructor Có Đường Kẻ Ngăn Cách: ListView.separated(...)

Dùng khi: Đề bài yêu cầu hiển thị đường kẻ phân cách (Divider) hoặc khoảng cách đều đặn giữa các item mà không cần tự chèn thủ công.

ListView.separated({
  Key? key,
  required int itemCount,
  required NullableIndexedWidgetBuilder itemBuilder,    // Dựng item chính
  required NullableIndexedWidgetBuilder separatorBuilder,// Dựng đường ngăn cách ở giữa các item
  EdgeInsetsGeometry? padding,
  bool shrinkWrap = false,
})

// Ví dụ thực tế:
ListView.separated(
  itemCount: items.length,
  separatorBuilder: (context, index) => const Divider(height: 1, color: Colors.grey),
  itemBuilder: (context, index) => ListTile(title: Text(items[index].name)),
)

4. Constructor Tùy Biến Chuyên Sâu: ListView.custom(...)

Dùng khi: Cần kiểm soát thuật toán quản lý bộ nhớ đệm chi tiết thông qua SliverChildDelegate (rất ít khi dùng trong phòng thi).

B. Phân Tích Toàn Bộ Constructors Của GridView

Hiển thị tập dữ liệu theo dạng Lưới 2 chiều (cột và hàng), thích hợp cho thư viện ảnh, danh sách sản phẩm mua sắm (E-commerce grid), bảng màu, danh mục thể loại...

1. Constructor Cố Định Số Cột: GridView.count(...) ⭐ (Rất Phổ Biến)

Dùng khi: Bạn muốn chỉ định chính xác số cột hiển thị trên màn hình (ví dụ: luôn luôn chia làm 2 cột hoặc 3 cột), không phụ thuộc vào độ rộng màn hình.

GridView.count({
  Key? key,
  required int crossAxisCount,         // SỐ LƯỢNG CỘT (bắt buộc, ví dụ: 2)
  double mainAxisSpacing = 0.0,        // Khoảng cách giữa các HÀNG dọc
  double crossAxisSpacing = 0.0,       // Khoảng cách giữa các CỘT ngang
  double childAspectRatio = 1.0,       // Tỉ lệ chiều rộng / chiều cao của mỗi ô (1.0 = hình vuông)
  EdgeInsetsGeometry? padding,         // Đệm lề xung quanh lưới
  bool shrinkWrap = false,             // Thu gọn chiều cao nếu nằm trong ScrollView
  ScrollPhysics? physics,
  List children = const [], // Danh sách item cố định
})

// Ví dụ thực tế:
GridView.count(
  crossAxisCount: 2,           // 2 cột
  crossAxisSpacing: 10,        // Cách ngang 10
  mainAxisSpacing: 10,         // Cách dọc 10
  childAspectRatio: 0.8,       // Chiều cao dài hơn chiều rộng (dành cho thẻ Card sản phẩm)
  padding: const EdgeInsets.all(10),
  children: items.map((item) => ItemCard(item: item)).toList(),
)

2. Constructor Tự Động Theo Kích Thước Tối Đa: GridView.extent(...)

Dùng khi: Hỗ trợ thiết kế Responsive tự động co giãn: Bạn chỉ định chiều rộng tối đa của mỗi ô (ví dụ: tối đa 150px), điện thoại nhỏ sẽ tự chia 2 cột, máy tính bảng to sẽ tự bung thành 4-5 cột.

GridView.extent({
  Key? key,
  required double maxCrossAxisExtent,  // Chiều rộng tối đa của 1 ô (ví dụ: 180.0)
  double mainAxisSpacing = 0.0,
  double crossAxisSpacing = 0.0,
  double childAspectRatio = 1.0,
  EdgeInsetsGeometry? padding,
  List children = const [],
})

3. Constructor Tối Ưu Tải Động: GridView.builder(...) ⭐ (Chuẩn Phòng Thi & API)

Dùng khi: Dữ liệu dạng lưới lấy từ Database / REST API với số lượng lớn, yêu cầu cơ chế Lazy Loading để cuộn không bị giật lag.

GridView.builder({
  Key? key,
  required SliverGridDelegate gridDelegate,         // Bộ định nghĩa cấu hình lưới
  required NullableIndexedWidgetBuilder itemBuilder,// Hàm render từng ô: (context, index) => Widget
  int? itemCount,                                   // Tổng số lượng phần tử
  EdgeInsetsGeometry? padding,
  bool shrinkWrap = false,
  ScrollPhysics? physics,
})

// CÓ 2 LOẠI gridDelegate PHỔ BIẾN:
// Cách 1: SliverGridDelegateWithFixedCrossAxisCount (Cố định số cột)
GridView.builder(
  itemCount: items.length,
  padding: const EdgeInsets.all(8),
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,           // 2 cột
    crossAxisSpacing: 10,        // Khoảng cách cột
    mainAxisSpacing: 10,         // Khoảng cách hàng
    childAspectRatio: 0.75,      // Tỉ lệ rộng / cao
  ),
  itemBuilder: (context, index) {
    return Card(
      child: Column(
        children: [
          Expanded(child: Image.network(items[index].imageUrl, fit: BoxFit.cover)),
          Text(items[index].title, style: const TextStyle(fontWeight: FontWeight.bold)),
        ],
      ),
    );
  },
)

// Cách 2: SliverGridDelegateWithMaxCrossAxisExtent (Tự bung số cột theo chiều rộng tối đa)
gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
  maxCrossAxisExtent: 200,
  crossAxisSpacing: 10,
  mainAxisSpacing: 10,
)
