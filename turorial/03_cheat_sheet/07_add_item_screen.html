Mục 7: Mẫu Màn Hình Thêm Mới (lib/screens/add_item_screen.dart)

Màn hình đảm nhiệm Task Add New Item của đề thi: Gồm Form nhập Tiêu đề, Mô tả, Dropdown thể loại, Giá tiền số thực, kết nối Riverpod lưu vào CSDL SQLite và tự động cập nhật danh sách ở HomeScreen. Toàn bộ mã nguồn class được đưa lên trên cùng, kèm hình ảnh minh họa iPhone SE trên trình duyệt và các mục giải thích chi tiết: Dùng để làm gì, dùng thế nào và vì sao.

1. Toàn Bộ Mã Nguồn Class AddItemScreen (lib/screens/add_item_screen.dart)

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../models/item_example.dart';
import '../providers/item_provider.dart';
import '../utils/app_validator.dart';

class AddItemScreen extends ConsumerStatefulWidget {
  const AddItemScreen({super.key});

  @override
  ConsumerState<AddItemScreen> createState() => _AddItemScreenState();
}

class _AddItemScreenState extends ConsumerState<AddItemScreen> {
  final _formKey = GlobalKey<FormState>();
  final _titleController = TextEditingController();
  final _subtitleController = TextEditingController();
  final _priceController = TextEditingController();

  String _selectedCategory = 'Loại A';
  final List<String> _categories = ['Loại A', 'Loại B', 'Loại C'];

  @override
  void dispose() {
    _titleController.dispose();
    _subtitleController.dispose();
    _priceController.dispose();
    super.dispose();
  }

  Future<void> _save() async {
    if (!_formKey.currentState!.validate()) return;

    final title = _titleController.text.trim();
    final subtitle = _subtitleController.text.trim();
    final price = double.tryParse(_priceController.text.trim()) ?? 0.0;

    // THÊM MỚI (ADD): ID tự động tăng
    final newItem = ItemModel(
      title: title,
      subtitle: subtitle,
      category: _selectedCategory,
      price: price,
    );

    await ref.read(itemProvider.notifier).addItem(newItem);

    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Thêm mới thành công!')),
    );

    // Quay trở về màn hình trước (HomeScreen tự động cập nhật)
    Navigator.pop(context);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Thêm mới'),
        centerTitle: true,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Title
              TextFormField(
                controller: _titleController,
                decoration: const InputDecoration(
                  labelText: 'Title',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.required(val, 'Tiêu đề'),
              ),
              const SizedBox(height: 16),

              // Field 2: Description / Subtitle
              TextFormField(
                controller: _subtitleController,
                maxLines: 2,
                decoration: const InputDecoration(
                  labelText: 'Description',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.required(val, 'Mô tả'),
              ),
              const SizedBox(height: 16),

              // Field 3: Category Dropdown
              DropdownButtonFormField<String>(
                value: _selectedCategory,
                decoration: const InputDecoration(
                  labelText: 'Category',
                  border: OutlineInputBorder(),
                ),
                items: _categories.map((cat) {
                  return DropdownMenuItem(value: cat, child: Text(cat));
                }).toList(),
                onChanged: (val) {
                  if (val != null) setState(() => _selectedCategory = val);
                },
              ),
              const SizedBox(height: 16),

              // Field 4: Price (Số thực dương)
              TextFormField(
                controller: _priceController,
                keyboardType: const TextInputType.numberWithOptions(decimal: true),
                decoration: const InputDecoration(
                  labelText: 'Price',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.positiveDouble(val, 'Giá tiền'),
              ),
              const SizedBox(height: 24),

              // Nút Lưu
              ElevatedButton(
                onPressed: _save,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: const Text(
                  'LƯU DỮ LIỆU',
                  style: TextStyle(fontSize: 16),
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

3. Giải Thích Chi Tiết Code AddItemScreen: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

  • Kế thừa ConsumerStatefulWidget:
    Vì sao dùng: Vừa cho phép quản lý vòng đời State cục bộ (các TextEditingController, setState khi chọn Dropdown), vừa cung cấp biến ref toàn cục trong toàn bộ lớp State để giao tiếp với Riverpod.
  • Quy trình xử lý hàm _save():
    1. Kiểm tra toàn bộ validators của Form: if (!_formKey.currentState!.validate()) return;
    2. Đọc giá trị từ các ô nhập: title, subtitle, và parse giá tiền: double.tryParse(...) ?? 0.0
    3. Tạo đối tượng ItemModel mới: trường id không truyền (để null) vì SQLite sẽ tự động tăng giá trị ID trong CSDL.
    4. Gọi await ref.read(itemProvider.notifier).addItem(newItem);
    5. Hiển thị SnackBar xanh báo thành công và gọi Navigator.pop(context); quay về màn hình trước.
  • Dropdown chọn Category: DropdownButtonFormField<String>
    Dùng để làm gì: Hiển thị danh sách các phân loại cố định dạng menu thả xuống (Loại A, Loại B, Loại C).
    Dùng thế nào: Gán value: _selectedCategory và gọi setState(() => _selectedCategory = val) khi người dùng chọn một mục khác.
  • Bàn phím số thực: keyboardType: const TextInputType.numberWithOptions(decimal: true)
    Dùng để làm gì: Bàn phím số trên điện thoại sẽ tự động hiển thị thêm phím dấu chấm thập phân . để nhập giá tiền chính xác.
