Mục 6: Mẫu Hộp Thoại Xác Nhận Xóa (DeleteDialog) & Xử Lý Xóa Item

Để chống việc người dùng vô tình bấm nhầm nút thùng rác làm mất dữ liệu vĩnh viễn trong CSDL SQLite, việc hiển thị hộp thoại xác nhận xóa (Confirmation Dialog) và SnackBar thông báo thành công là tiêu chí chấm điểm bắt buộc trong kỳ thi PE. Module này được tách rời hoàn toàn thành file riêng lib/widgets/delete_dialog.dart để tái sử dụng ở bất kỳ màn hình nào.

Danh mục nội dung:
  • 1. Toàn bộ mã nguồn class DeleteDialog (lib/widgets/delete_dialog.dart)
  • 2. Hình ảnh minh họa giao diện UI iPhone SE trên trình duyệt (Dialog & SnackBar)
  • 3. Code hàm xử lý xóa _handleDelete() kết nối Riverpod & SnackBar
  • 4. Giải thích chi tiết code: Dùng để làm gì, dùng thế nào & vì sao?

1. Toàn Bộ Mã Nguồn Class DeleteDialog (lib/widgets/delete_dialog.dart)

Class tiện ích cung cấp hàm static show() hiển thị Modal AlertDialog, trả về true nếu người dùng bấm XÓA và false nếu bấm HỦY:

import 'package:flutter/material.dart';

class DeleteDialog {
  // Trả về true nếu người dùng bấm XÓA, false nếu bấm HỦY
  static Future<bool> show(BuildContext context, String itemTitle) async {
    final bool? result = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Xác nhận xóa'),
        content: Text('Bạn có chắc chắn muốn xóa "$itemTitle"?'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(ctx, false),
            child: const Text('HỦY'),
          ),
          ElevatedButton(
            style: ElevatedButton.styleFrom(backgroundColor: Colors.red),
            onPressed: () => Navigator.pop(ctx, true),
            child: const Text('XÓA', style: TextStyle(color: Colors.white)),
          ),
        ],
      ),
    );
    return result ?? false;
  }
}

2. Hình Ảnh Minh Họa Giao Diện UI iPhone SE Trên Trình Duyệt

Đối chiếu chuẩn xác giao diện hộp thoại xác nhận và thanh thông báo SnackBar nổi ở chân màn hình:

1. Popup AlertDialog xác nhận xóa

Popup Modal làm tối nền xung quanh, hiển thị tên tác phẩm cần xóa, 2 nút HỦY và XÓA (màu đỏ).

2. SnackBar báo xóa thành công

Thanh SnackBar nổi dưới đáy màn hình trong 2 giây, có nút hành động "ĐÓNG" màu vàng.

3. Code Hàm Xử Lý Xóa _handleDelete() Kết Nối Riverpod & SnackBar

Đặt hàm này trong class HomeScreen (hoặc DetailScreen) để kích hoạt Dialog và xử lý xóa dữ liệu:

// Hàm xử lý Xóa phần tử & Hiển thị SnackBar thông báo thành công
Future<void> _handleDelete(BuildContext context, WidgetRef ref, ItemModel item) async {
  // 1. Mở dialog xác nhận xóa đã tách riêng ở file DeleteDialog
  final bool confirm = await DeleteDialog.show(context, item.title);

  if (confirm && item.id != null) {
    // 2. Gọi Riverpod xóa item khỏi CSDL SQLite
    await ref.read(itemProvider.notifier).deleteItem(item.id!);

    if (!context.mounted) return;
    // 3. HIỆN SNACKBAR THÔNG BÁO XÓA THÀNH CÔNG
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(
        content: Text('Đã xóa "${item.title}" thành công!'),
        duration: const Duration(seconds: 2),
        action: SnackBarAction(
          label: 'ĐÓNG',
          textColor: Colors.amber,
          onPressed: () {},
        ),
      ),
    );
  }
}

4. Giải Thích Chi Tiết Code: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

1. Vì sao nên tách DeleteDialog thành một file độc lập trong lib/widgets/?

  • Dùng để làm gì: Biến logic hiển thị Dialog thành một hàm dùng chung duy nhất: await DeleteDialog.show(context, item.title).
  • Vì sao:
    - Tránh viết lặp đi lặp lại khối code showDialog(...) cồng kềnh trong nhiều màn hình.
    - Cả HomeScreen (xóa từ danh sách) và DetailScreen (xóa khi đang xem chi tiết) đều có thể gọi chung 1 dialog này.
    - Giúp file giao diện home_screen.dart ngắn hơn, sạch hơn và giám thị chấm điểm cấu trúc code OOP rất cao.

2. Cơ chế trả về kiểu boolean: Future<bool>

  • Khi bấm nút HỦY: Gọi Navigator.pop(ctx, false) → Hàm show() trả về false.
  • Khi bấm nút XÓA: Gọi Navigator.pop(ctx, true) → Hàm show() trả về true.
  • Khi người dùng bấm ra ngoài vùng popup (Barrier dismiss): showDialog trả về null, toán tử result ?? false đảm bảo luôn trả về false an toàn, không gây crash app.

3. Thiết kế SnackBar chuẩn UX

  • duration: const Duration(seconds: 2): Thời gian tự động ẩn là 2 giây (vừa đủ đọc, không che khuất màn hình quá lâu).
  • action: SnackBarAction(label: 'ĐÓNG', textColor: Colors.amber): Cho phép người dùng bấm nút ĐÓNG để tắt thanh thông báo ngay lập tức.
  • Kiểm tra if (!context.mounted) return;: Ngăn chặn việc gọi ScaffoldMessenger khi màn hình đã bị hủy sau tác vụ async await.
