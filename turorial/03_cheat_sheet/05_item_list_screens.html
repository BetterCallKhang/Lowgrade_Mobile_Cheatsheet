Mục 5: Mẫu Màn Hình Danh Sách ListView Sử Dụng Riverpod Code Generator (@riverpod)

Đây là cú pháp Riverpod 2.0+ hiện đại nhất (sử dụng @riverpod annotation và lệnh build_runner để sinh code tự động). Bạn chỉ cần viết class ngắn gọn với hàm build() bất đồng bộ, Riverpod sẽ tự động quản lý toàn bộ vòng đời (AsyncValue: Loading, Error, Data) cực kỳ mượt mà.

⚡ Danh mục phần code:
  • 1. Model ItemModel (lib/models/item_model.dart)
  • 2. FILE QUẢN LÝ STATE DÙNG CODE GEN: ItemNotifier (lib/providers/item_provider.dart)
  • 3. Lệnh Terminal sinh file .g.dart trong 5 giây
  • 4. FILE TÁCH RIÊNG 1: ItemCardWidget (lib/widgets/item_card_widget.dart)
  • 5. FILE TÁCH RIÊNG 2: DeleteDialog (lib/widgets/delete_dialog.dart)
  • 6. Màn hình HomeScreen hoàn chỉnh (Hiển thị danh sách, Xử lý rỗng & SnackBar xóa)
  • 7. Trọn bộ 4 Hình ảnh minh hoạ UI ListView (Bình thường, Rỗng, Dialog xóa, SnackBar thành công)

1. Thư Viện Bắt Buộc Để Dùng Riverpod Code Gen (pubspec.yaml)

Muốn dùng annotation @riverpod và sinh file .g.dart, bạn cần bổ sung các package sau vào pubspec.yaml:

dependencies:
  flutter:
    sdk: flutter
  flutter_riverpod: ^2.6.1
  riverpod_annotation: ^2.6.1

dev_dependencies:
  flutter_test:
    sdk: flutter
  build_runner: ^2.4.13
  riverpod_generator: ^2.6.2

2. File Model Item (lib/models/item_model.dart)

class ItemModel {
  final int? id;
  final String title;
  final String subtitle;
  final String? category;
  final double? price;

  ItemModel({
    this.id,
    required this.title,
    required this.subtitle,
    this.category,
    this.price,
  });

  factory ItemModel.fromMap(Map<String, dynamic> map) {
    return ItemModel(
      id: map['id'],
      title: map['title'] ?? '',
      subtitle: map['subtitle'] ?? map['description'] ?? '',
      category: map['category'],
      price: map['price'] != null ? (map['price'] as num).toDouble() : null,
    );
  }

  Map<String, dynamic> toMap() {
    final map = <String, dynamic>{
      'title': title,
      'subtitle': subtitle,
      'category': category,
      'price': price,
    };
    if (id != null) map['id'] = id;
    return map;
  }
}

3. FILE QUẢN LÝ STATE CODE GEN (lib/providers/item_provider.dart)

Nó là gì? Bạn viết cú pháp @riverpod, kế thừa _$ItemNotifier và khai báo dòng part 'item_provider.g.dart';. Trình sinh mã sẽ tự động tạo ra biến itemNotifierProvider chuẩn Async cho bạn:

import 'package:riverpod_annotation/riverpod_annotation.dart';
import '../database/database_helper.dart';
import '../models/item_model.dart';

// 1. DÒNG BẮT BUỘC: Liên kết file sinh mã tự động
part 'item_provider.g.dart';

// 2. Annotation @riverpod: Tự động sinh ra itemNotifierProvider
@riverpod
class ItemNotifier extends _$ItemNotifier {
  // Hàm build() bất đồng bộ: Riverpod sẽ tự quản lý trạng thái Loading/Error/Data
  @override
  Future<List<ItemModel>> build() async {
    final rawData = await DatabaseHelper.instance.getAllItems();
    return rawData.map((e) => ItemModel.fromMap(e)).toList();
  }

  // Thêm một item mới
  Future<void> addItem(ItemModel item) async {
    await DatabaseHelper.instance.insertItem(item.toMap());
    // Làm mới lại danh sách -> UI tự động cập nhật
    ref.invalidateSelf();
    await future;
  }

  // Xóa một item theo ID
  Future<void> deleteItem(int id) async {
    await DatabaseHelper.instance.deleteItem(id);
    ref.invalidateSelf();
    await future;
  }
}

4. Lệnh Terminal Sinh File item_provider.g.dart

Sau khi dán xong file trên, mở Terminal tại thư mục dự án và chạy 1 trong 2 lệnh sau:

# Cách 1: Sinh mã 1 lần rồi kết thúc (Khuyên dùng lúc thi)
dart run build_runner build --delete-conflicting-outputs

# Cách 2: Tự động quan sát và sinh mã mỗi khi bấm Ctrl + S
# dart run build_runner watch --delete-conflicting-outputs

4. FILE TÁCH RIÊNG 1: ItemCardWidget (lib/widgets/item_card_widget.dart)

Nó là gì? Widget hiển thị 1 dòng Card trong ListView, tách riêng ra file độc lập:

import 'package:flutter/material.dart';
import '../models/item_model.dart';

class ItemCardWidget extends StatelessWidget {
  final ItemModel item;
  final int index;
  final VoidCallback onDelete;
  final VoidCallback? onTap;

  const ItemCardWidget({
    super.key,
    required this.item,
    required this.index,
    required this.onDelete,
    this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    return Card(
      elevation: 2,
      margin: const EdgeInsets.symmetric(horizontal: 12, vertical: 6),
      child: ListTile(
        onTap: onTap,
        // Bên trái: Vòng tròn số thứ tự
        leading: CircleAvatar(
          child: Text('${index + 1}', style: const TextStyle(fontWeight: FontWeight.bold)),
        ),

        // Ở giữa: Tiêu đề in đậm
        title: Text(
          item.title,
          style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 15),
        ),

        // Dòng phụ: Thể loại & Giá tiền
        subtitle: Text(
          '${item.category ?? 'Chung'} • \$${item.price ?? 0.0}',
          style: TextStyle(color: Colors.grey.shade700, fontSize: 13),
        ),

        // Bên phải: Nút Xóa đỏ
        trailing: IconButton(
          icon: const Icon(Icons.delete, color: Colors.red),
          tooltip: 'Xóa mục này',
          onPressed: onDelete,
        ),
      ),
    );
  }
}

5. FILE TÁCH RIÊNG 2: DeleteDialog (lib/widgets/delete_dialog.dart)

Nó là gì? Hộp thoại AlertDialog xác nhận xóa được tách hẳn ra một hàm tĩnh static riêng. Khi cần xóa chỉ việc gọi DeleteDialog.show(context, itemTitle):

import 'package:flutter/material.dart';

class DeleteDialog {
  // Trả về true nếu người dùng bấm XÓA, false nếu bấm HỦY
  static Future<bool> show(BuildContext context, String itemTitle) async {
    final bool? result = await showDialog<bool>(
      context: context,
      builder: (ctx) => AlertDialog(
        title: const Text('Xác nhận xóa'),
        content: Text('Bạn có chắc chắn muốn xóa "$itemTitle"?'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(ctx, false),
            child: const Text('HỦY'),
          ),
          ElevatedButton(
            style: ElevatedButton.styleFrom(backgroundColor: Colors.red),
            onPressed: () => Navigator.pop(ctx, true),
            child: const Text('XÓA', style: TextStyle(color: Colors.white)),
          ),
        ],
      ),
    );
    return result ?? false;
  }
}

6. Màn Hình HomeScreen Hoàn Chỉnh (lib/screens/home_screen.dart)

Tích hợp nạp dữ liệu qua Riverpod Code Gen, xử lý trạng thái Rỗng ("No items found"), gọi DeleteDialog.show và hiển thị SnackBar thông báo xóa thành công:

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../models/item_model.dart';
import '../providers/item_provider.dart';
import '../services/session_service.dart';
import '../widgets/delete_dialog.dart'; // Import Dialog xóa tách riêng
import '../widgets/item_card_widget.dart'; // Import Widget dòng item tách riêng
import 'add_edit_item_screen.dart'; // Màn Thêm / Sửa
import 'detail_screen.dart'; // Màn Chi tiết
import 'login_screen.dart';

class HomeScreen extends ConsumerWidget {
  const HomeScreen({super.key});

  // Xử lý Xóa phần tử & Hiển thị SnackBar thông báo thành công
  Future<void> _handleDelete(BuildContext context, WidgetRef ref, ItemModel item) async {
    // 1. Mở dialog xác nhận xóa đã tách riêng ở file DeleteDialog
    final bool confirm = await DeleteDialog.show(context, item.title);

    if (confirm && item.id != null) {
      // 2. Gọi Riverpod xóa item
      await ref.read(itemNotifierProvider.notifier).deleteItem(item.id!);

      if (!context.mounted) return;
      // 3. HIỆN SNACKBAR THÔNG BÁO XÓA THÀNH CÔNG
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Đã xóa "${item.title}" thành công!'),
          duration: const Duration(seconds: 2),
          action: SnackBarAction(
            label: 'ĐÓNG',
            textColor: Colors.amber,
            onPressed: () {},
          ),
        ),
      );
    }
  }

  Future<void> _logout(BuildContext context) async {
    await SessionService.clearSession();
    if (!context.mounted) return;
    Navigator.pushAndRemoveUntil(
      context,
      MaterialPageRoute(builder: (_) => const LoginScreen()),
      (route) => false,
    );
  }

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final asyncItems = ref.watch(itemNotifierProvider);

    return Scaffold(
      appBar: AppBar(
        title: const Text('Danh sách'),
        centerTitle: true,
        actions: [
          IconButton(
            icon: const Icon(Icons.logout),
            tooltip: 'Đăng xuất',
            onPressed: () => _logout(context),
          ),
        ],
      ),
      // Xử lý 3 trạng thái với .when: loading, error, data (kèm xử lý rỗng)
      body: asyncItems.when(
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (err, stack) => Center(child: Text('Lỗi: $err')),
        data: (items) {
          // TRẠNG THÁI KHÔNG CÓ DỮ LIỆU (EMPTY STATE)
          if (items.isEmpty) {
            return const Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Icon(Icons.inbox, size: 64, color: Colors.grey),
                  SizedBox(height: 12),
                  Text(
                    'Chưa có dữ liệu nào',
                    style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold),
                  ),
                  SizedBox(height: 6),
                  Text(
                    '(No items found)',
                    style: TextStyle(color: Colors.grey),
                  ),
                ],
              ),
            );
          }

          // TRẠNG THÁI CÓ DỮ LIỆU: LISTVIEW CUỘN DỌC
          return ListView.builder(
            padding: const EdgeInsets.symmetric(vertical: 8),
            itemCount: items.length,
            itemBuilder: (context, index) {
              final item = items[index];
              return ItemCardWidget(
                item: item,
                index: index,
                onDelete: () => _handleDelete(context, ref, item),
                onTap: () {
                  Navigator.push(
                    context,
                    MaterialPageRoute(builder: (_) => DetailScreen(item: item)),
                  );
                },
              );
            },
          );
        },
      ),
      // Nút Thêm mới dẫn sang AddEditItemScreen
      floatingActionButton: FloatingActionButton(
        onPressed: () {
          Navigator.push(
            context,
            MaterialPageRoute(builder: (_) => const AddEditItemScreen()),
          );
        },
        child: const Icon(Icons.add),
      ),
    );
  }
}

7. Hình Ảnh Minh Hoạ UI Danh Sách ListView (Đủ 4 Trạng Thái)

1. Danh sách có dữ liệu (ListView)

Mỗi item là 1 Card gồm CircleAvatar số thứ tự, Tên, Giá và Icon xóa đỏ bên phải.

2. Trạng thái rỗng (No items found)

Khi `items.isEmpty`: Hiển thị icon hộp rỗng và thông báo "Chưa có dữ liệu nào".

3. Hộp thoại AlertDialog xác nhận xóa

Gọi từ `DeleteDialog.show`: Hỏi rõ tên item cần xóa với 2 nút HỦY và XÓA đỏ.

4. Xóa xong & Hiện SnackBar thành công

Item biến mất ngay lập tức và SnackBar xuất hiện ở đáy: "Đã xóa thành công!".
