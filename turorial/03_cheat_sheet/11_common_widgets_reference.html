1. Nhóm Danh Sách Cuộn & Lưới (ListView & GridView Đầy Đủ Constructors)

Đây là 2 widget then chốt của hầu hết các bài thi di động. Mỗi loại cung cấp nhiều Named Constructors cho từng kịch bản cụ thể, kèm theo các thuộc tính cấu hình bố cục, hiệu năng và hành vi cuộn.

A. Phân Tích Toàn Bộ Constructors Của ListView

Hiển thị danh sách phần tử cuộn theo 1 chiều (mặc định là cuộn dọc theo chiều cao màn hình).

1. Constructor Mặc Định: ListView(...)

Dùng khi: Danh sách có số lượng phần tử ít, cố định đã biết trước (ví dụ: màn hình Cài đặt Settings, danh sách vài dòng tĩnh). Toàn bộ widget con trong children được khởi tạo ngay lập tức (eager loading).

ListView({
  Key? key,
  Axis scrollDirection = Axis.vertical, // Chiều cuộn: Axis.vertical hoặc Axis.horizontal
  bool reverse = false,                 // Đảo ngược thứ tự cuộn từ dưới lên trên
  ScrollController? controller,         // Điều khiển vị trí cuộn / bắt sự kiện cuộn
  bool? primary,                        // Có liên kết với PrimaryScrollController của Scaffold không
  ScrollPhysics? physics,               // Quy định hiệu ứng cuộn (Bouncing, Clamping, NeverScrollable...)
  bool shrinkWrap = false,              // Thu gọn chiều cao bằng đúng nội dung con (Cực quan trọng)
  EdgeInsetsGeometry? padding,          // Khoảng đệm bao quanh danh sách
  double? itemExtent,                   // Chiều cao cố định của mỗi item (tối ưu hiệu năng cực lớn)
  List<Widget> children = const <Widget>[], // Mảng danh sách các widget con
})

2. Constructor Tối Ưu: ListView.builder(...) (Thường Dùng Nhất Trong Đề Thi)

Dùng khi: Danh sách động lấy từ SQLite / REST API có số lượng lớn hoặc chưa biết trước. Áp dụng cơ chế tái sử dụng widget (Lazy Loading / Virtualization) - chỉ vẽ các dòng đang nằm trên màn hình, giúp app mượt mà và không tốn RAM.

ListView.builder({
  Key? key,
  Axis scrollDirection = Axis.vertical,
  bool reverse = false,
  ScrollController? controller,
  ScrollPhysics? physics,
  bool shrinkWrap = false,
  EdgeInsetsGeometry? padding,
  double? itemExtent,
  required int itemCount,                        // BẮT BUỘC: Tổng số lượng phần tử
  required NullableIndexedWidgetBuilder itemBuilder, // BẮT BUỘC: Hàm dựng từng dòng (context, index) => Widget
})

// Ví dụ thực tế lấy từ List danh sách:
ListView.builder(
  itemCount: items.length,
  padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
  itemBuilder: (context, index) {
    final item = items[index];
    return Card(
      elevation: 2,
      margin: const EdgeInsets.only(bottom: 8),
      child: ListTile(
        leading: CircleAvatar(child: Text('${index + 1}')),
        title: Text(item.title, style: const TextStyle(fontWeight: FontWeight.bold)),
        subtitle: Text('Giá: \$${item.price} - Thể loại: ${item.category}'),
        trailing: const Icon(Icons.arrow_forward_ios, size: 16),
        onTap: () {
          // Xử lý chuyển sang màn hình xem chi tiết
        },
      ),
    );
  },
)

3. Constructor Có Đường Kẻ Ngăn Cách: ListView.separated(...)

Dùng khi: Đề bài yêu cầu hiển thị đường kẻ phân cách (Divider) hoặc khoảng cách đều đặn giữa các item mà không cần tự chèn thủ công.

ListView.separated({
  Key? key,
  required int itemCount,
  required NullableIndexedWidgetBuilder itemBuilder,    // Dựng item chính theo index
  required NullableIndexedWidgetBuilder separatorBuilder,// Dựng đường ngăn cách (chạy itemCount - 1 lần)
  EdgeInsetsGeometry? padding,
  bool shrinkWrap = false,
  ScrollPhysics? physics,
  ScrollController? controller,
})

// Ví dụ thực tế:
ListView.separated(
  itemCount: items.length,
  padding: const EdgeInsets.all(8),
  separatorBuilder: (context, index) => const Divider(height: 1, thickness: 1, color: Colors.grey),
  itemBuilder: (context, index) => ListTile(
    title: Text(items[index].name),
    subtitle: Text(items[index].email),
    trailing: IconButton(
      icon: const Icon(Icons.delete, color: Colors.red),
      onPressed: () => _deleteItem(items[index].id),
    ),
  ),
)

4. Constructor Tùy Biến Chuyên Sâu: ListView.custom(...)

Dùng khi: Cần kiểm soát thuật toán quản lý bộ nhớ đệm chi tiết thông qua SliverChildDelegate (rất ít khi dùng trong phòng thi).

Bảng Tra Cứu Toàn Bộ Thuộc Tính & Tham Số Của ListView

Thuộc tính Kiểu dữ liệu & Mặc định Giải thích ý nghĩa & Ngữ cảnh sử dụng
itemCount int (bắt buộc trong .builder) Tổng số lượng phần tử cần hiển thị (thường truyền list.length). Nếu quên truyền, danh sách có thể chạy vô tận và gây lỗi IndexOutOfRange.
itemBuilder Widget Function(BuildContext, int) Hàm callback nhận vào context và chỉ mục index chạy từ 0 đến itemCount - 1 để trả về widget hiển thị cho dòng đó. Chỉ các dòng đang hiển thị trên màn hình mới được gọi hàm này.
separatorBuilder Widget Function(BuildContext, int) Chỉ có trong ListView.separated. Dựng widget ngăn cách giữa 2 item liền kề (ví dụ: const Divider() hoặc const SizedBox(height: 10)). Chạy đúng itemCount - 1 lần.
scrollDirection Axis (mặc định: Axis.vertical) Chiều cuộn danh sách:
  • Axis.vertical: Cuộn dọc từ trên xuống dưới.
  • Axis.horizontal: Cuộn ngang từ trái sang phải (rất hay dùng làm danh sách Story, banner sản phẩm hot nằm ngang). Lưu ý: Khi cuộn ngang, các item con phải có kích thước chiều ngang xác định.
reverse bool (mặc định: false) Nếu đặt true, danh sách sẽ đảo ngược hướng: phần tử đầu tiên nằm ở dưới cùng và thanh cuộn bắt đầu từ đáy (chuẩn cho màn hình Chat tin nhắn).
shrinkWrap bool (mặc định: false) Cực kỳ quan trọng: Mặc định ListView luôn cố gắng chiếm tối đa chiều cao vô tận (infinity height). Khi đặt shrinkWrap: true, ListView sẽ co chiều cao lại bằng đúng tổng chiều cao các widget con bên trong.
Bắt buộc bật shrinkWrap: true khi đặt ListView bên trong Column hoặc SingleChildScrollView!
physics ScrollPhysics? Điều khiển quy tắc và hiệu ứng vật lý khi cuộn màn hình:
  • NeverScrollableScrollPhysics(): Khóa cuộn hoàn toàn. Dùng khi ListView nằm lồng trong 1 ScrollView cha để tránh xung đột thao tác cuộn.
  • BouncingScrollPhysics(): Hiệu ứng kéo nảy đàn hồi lò xo (phong cách iOS).
  • ClampingScrollPhysics(): Hiệu ứng chặn cứng có quầng sáng glow ở hai mép (phong cách mặc định của Android).
  • AlwaysScrollableScrollPhysics(): Luôn cho phép kéo cuộn kể cả khi danh sách quá ngắn không đầy màn hình (Bắt buộc khi bọc ListView trong RefreshIndicator để tính năng vuốt kéo reload hoạt động).
padding EdgeInsetsGeometry? Khoảng đệm bao bọc xung quanh toàn bộ danh sách (ví dụ: EdgeInsets.all(12) hoặc EdgeInsets.symmetric(horizontal: 16, vertical: 8)).
itemExtent double? Ép chiều cao cố định (nếu cuộn dọc) hoặc chiều rộng cố định (nếu cuộn ngang) cho tất cả các item con (ví dụ: itemExtent: 60.0).
Lợi ích: Tăng tốc độ cuộn cực cao cho danh sách hàng nghìn item vì Flutter không cần tự đo đạc chiều cao từng phần tử.
controller ScrollController? Lắng nghe và điều khiển hành vi cuộn:
  • Cuộn mượt về đầu trang: _controller.animateTo(0, duration: Duration(milliseconds: 300), curve: Curves.easeInOut).
  • Làm tính năng Load More (phân trang vô tận): bắt sự kiện _controller.position.pixels == _controller.position.maxScrollExtent.
Lỗi kinh điển trong phòng thi: "Vertical viewport was given unbounded height"

Lỗi này xảy ra khi bạn đặt ListView hoặc ListView.builder trực tiếp bên trong Column mà không có ràng buộc kích thước (vì Column cho phép chiều cao vô tận, còn ListView cũng đòi chiều cao vô tận).

Cách khắc phục (Chọn 1 trong 2):

  • Cách 1 (Ưu tiên): Bọc ListView bằng widget Expanded(...) nếu muốn ListView chiếm trọn toàn bộ khoảng trống còn lại của màn hình.
  • Cách 2: Nếu toàn bộ trang đã bọc trong SingleChildScrollView, thêm vào ListView 2 thuộc tính: shrinkWrap: true và physics: const NeverScrollableScrollPhysics().
B. Phân Tích Toàn Bộ Constructors Của GridView

Hiển thị tập dữ liệu theo dạng Lưới 2 chiều (cột và hàng), thích hợp cho thư viện ảnh, danh sách sản phẩm mua sắm (E-commerce grid), bảng màu, danh mục thể loại...

1. Constructor Cố Định Số Cột: GridView.count(...) (Rất Phổ Biến)

Dùng khi: Bạn muốn chỉ định chính xác số cột hiển thị trên màn hình (ví dụ: luôn luôn chia làm 2 cột hoặc 3 cột), không phụ thuộc vào độ rộng màn hình.

GridView.count({
  Key? key,
  required int crossAxisCount,         // BẮT BUỘC: SỐ LƯỢNG CỘT (ví dụ: 2)
  double mainAxisSpacing = 0.0,        // Khoảng cách giữa các HÀNG dọc
  double crossAxisSpacing = 0.0,       // Khoảng cách giữa các CỘT ngang
  double childAspectRatio = 1.0,       // Tỉ lệ chiều rộng / chiều cao của mỗi ô (1.0 = hình vuông)
  EdgeInsetsGeometry? padding,         // Đệm lề xung quanh lưới
  bool shrinkWrap = false,             // Thu gọn chiều cao nếu nằm trong ScrollView/Column
  ScrollPhysics? physics,
  List<Widget> children = const <Widget>[], // Danh sách item cố định
})

// Ví dụ thực tế:
GridView.count(
  crossAxisCount: 2,           // Luôn chia làm 2 cột
  crossAxisSpacing: 10,        // Khoảng cách ngang giữa 2 cột là 10px
  mainAxisSpacing: 10,         // Khoảng cách dọc giữa các hàng là 10px
  childAspectRatio: 0.75,      // Chiều cao lớn hơn chiều rộng (chuẩn cho thẻ Card sản phẩm)
  padding: const EdgeInsets.all(12),
  children: items.map((item) => ItemCard(item: item)).toList(),
)

2. Constructor Tự Động Theo Kích Thước Tối Đa: GridView.extent(...)

Dùng khi: Hỗ trợ thiết kế Responsive tự động co giãn: Bạn chỉ định chiều rộng tối đa của mỗi ô (ví dụ: tối đa 180px), điện thoại nhỏ sẽ tự chia 2 cột, còn màn hình máy tính bảng hoặc xoay ngang sẽ tự bung thành 3-4 cột.

GridView.extent({
  Key? key,
  required double maxCrossAxisExtent,  // Chiều rộng tối đa của 1 ô (ví dụ: 180.0)
  double mainAxisSpacing = 0.0,
  double crossAxisSpacing = 0.0,
  double childAspectRatio = 1.0,
  EdgeInsetsGeometry? padding,
  List<Widget> children = const <Widget>[],
})

3. Constructor Tối Ưu Tải Động: GridView.builder(...) (Chuẩn Phòng Thi & SQLite / API)

Dùng khi: Dữ liệu dạng lưới lấy từ Database / REST API với số lượng lớn, yêu cầu cơ chế Lazy Loading để cuộn mượt mà không bị giật lag bộ nhớ.

GridView.builder({
  Key? key,
  required SliverGridDelegate gridDelegate,         // BẮT BUỘC: Bộ định nghĩa cấu hình chia lưới
  required NullableIndexedWidgetBuilder itemBuilder,// BẮT BUỘC: Hàm render từng ô (context, index)
  int? itemCount,                                   // Tổng số lượng phần tử
  EdgeInsetsGeometry? padding,
  bool shrinkWrap = false,
  ScrollPhysics? physics,
  ScrollController? controller,
})

// Cách 1: SliverGridDelegateWithFixedCrossAxisCount (Cố định số cột - THƯỜNG DÙNG NHẤT)
GridView.builder(
  itemCount: products.length,
  padding: const EdgeInsets.all(10),
  gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
    crossAxisCount: 2,           // 2 cột trên 1 hàng
    crossAxisSpacing: 10,        // Cách ngang giữa các cột
    mainAxisSpacing: 10,         // Cách dọc giữa các hàng
    childAspectRatio: 0.72,      // Chiều rộng / Chiều cao (0.72 giúp thẻ đủ chiều cao chứa ảnh + text + giá)
  ),
  itemBuilder: (context, index) {
    final product = products[index];
    return Card(
      elevation: 3,
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(10)),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Expanded(
            child: ClipRRect(
              borderRadius: const BorderRadius.vertical(top: Radius.circular(10)),
              child: Image.network(product.imageUrl, width: double.infinity, fit: BoxFit.cover),
            ),
          ),
          Padding(
            padding: const EdgeInsets.all(8),
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(product.name, maxLines: 1, overflow: TextOverflow.ellipsis, style: const TextStyle(fontWeight: FontWeight.bold)),
                const SizedBox(height: 4),
                Text('\$${product.price}', style: const TextStyle(color: Colors.green, fontWeight: FontWeight.bold)),
              ],
            ),
          ),
        ],
      ),
    );
  },
)

// Cách 2: SliverGridDelegateWithMaxCrossAxisExtent (Tự bung số cột theo chiều rộng tối đa)
gridDelegate: const SliverGridDelegateWithMaxCrossAxisExtent(
  maxCrossAxisExtent: 200,      // Mỗi ô rộng tối đa 200px
  crossAxisSpacing: 10,
  mainAxisSpacing: 10,
  childAspectRatio: 0.8,
)

Bảng Tra Cứu Toàn Bộ Thuộc Tính & Tham Số Của GridView

Thuộc tính Kiểu dữ liệu & Mặc định Giải thích ý nghĩa & Cách sử dụng
crossAxisCount int (bắt buộc trong .count) Số lượng cột hiển thị cố định trên một hàng ngang (ví dụ: 2 cột cho màn hình mua sắm, 3 hoặc 4 cột cho thư viện ảnh).
childAspectRatio double (mặc định: 1.0) Tham số quan trọng nhất của GridView! Là tỉ lệ giữa Chiều rộng / Chiều cao (Width / Height) của mỗi ô lưới:
  • 1.0: Chiều rộng bằng chiều cao → Ô vuông hoàn hảo.
  • < 1.0 (ví dụ: 0.7, 0.75): Chiều cao lớn hơn chiều rộng. Đây là chuẩn thẻ Card sản phẩm (ảnh bên trên, tên và giá tiền bên dưới).
  • > 1.0 (ví dụ: 1.5, 2.0): Chiều rộng dài hơn chiều cao (phù hợp làm danh mục ngắn, nút chọn bộ lọc).
Mẹo sửa lỗi: Nếu các ô trong lưới bị lỗi chữ đỏ vạch vàng A RenderFlex overflowed by ... pixels ở đáy thẻ, hãy giảm giá trị childAspectRatio xuống (ví dụ từ 0.85 giảm về 0.7) để tăng thêm chiều cao cho ô!
mainAxisSpacing double (mặc định: 0.0) Khoảng cách tính bằng pixel giữa các HÀNG theo trục cuộn chính (nếu cuộn dọc thì đây là khoảng cách dọc giữa hàng trên và hàng dưới).
crossAxisSpacing double (mặc định: 0.0) Khoảng cách tính bằng pixel giữa các CỘT ngang liền kề nhau trên cùng một hàng.
maxCrossAxisExtent double (trong .extent) Chiều rộng tối đa cho phép của một ô lưới. Flutter sẽ tự động lấy bề rộng màn hình chia cho giá trị này để suy ra số lượng cột tối ưu (giúp giao diện tự tương thích tốt trên cả Mobile và Tablet).
gridDelegate SliverGridDelegate Bộ điều phối phân bổ lưới trong GridView.builder. Thường dùng 2 class con:
  • SliverGridDelegateWithFixedCrossAxisCount(...): Khi biết chắc số cột cố định.
  • SliverGridDelegateWithMaxCrossAxisExtent(...): Khi muốn tự động co giãn theo chiều rộng ô tối đa.
itemCount int? Tổng số lượng phần tử cần dựng trong lưới (trong GridView.builder).
itemBuilder Widget Function(BuildContext, int) Hàm callback nhận context và index từ 0 đến itemCount - 1 để trả về widget của ô đó.
shrinkWrap bool (mặc định: false) Thu gọn chiều cao của lưới theo đúng kích thước các ô con. Bắt buộc đặt true khi đặt GridView bên trong Column hoặc SingleChildScrollView.
physics ScrollPhysics? Cơ chế cuộn (tương tự ListView). Khi lồng trong trang đã có cuộn thì dùng physics: const NeverScrollableScrollPhysics().
padding EdgeInsetsGeometry? Khoảng đệm bao quanh 4 phía của toàn bộ khung lưới.
Mẹo phòng thi: Khi nào dùng ListView, khi nào dùng GridView?
  • Dùng ListView: Khi dữ liệu hiển thị dạng 1 cột từ trên xuống dưới (danh sách tin nhắn, danh sách sinh viên, danh sách cài đặt, danh sách liên hệ).
  • Dùng GridView: Khi đề bài yêu cầu giao diện dạng lưới 2 cột trở lên (danh sách sản phẩm e-commerce, thư viện hình ảnh, bảng phân loại danh mục, bảng chọn màu sắc).
  • Cặp bài trùng lồng ScrollView: Khi đặt ListView hoặc GridView bên trong SingleChildScrollView + Column, luôn luôn kèm 2 dòng: shrinkWrap: true và physics: const NeverScrollableScrollPhysics().

Bảng Tra Cứu Thuộc Tính Của BoxDecoration

Thuộc tính Kiểu dữ liệu Mô tả & Ví dụ cú pháp
color Color? Màu nền của khối hộp (ví dụ: Colors.white, Color(0xFFF5F5F5)).
borderRadius BorderRadiusGeometry? Bo tròn góc khung:
  • Bo đều 4 góc: BorderRadius.circular(12)
  • Bo riêng từng góc: BorderRadius.only(topLeft: Radius.circular(16), bottomRight: Radius.circular(16))

border BoxBorder? Vẽ đường viền khung:
  • Viền cả 4 phía: Border.all(color: Colors.grey, width: 1.0)
  • Chỉ viền mép dưới (gạch chân): Border(bottom: BorderSide(color: Colors.blue, width: 2))
boxShadow List<BoxShadow>? Danh sách các lớp bóng đổ:
  • color: Màu bóng (thường làm mờ bằng Colors.black.withOpacity(0.1)).
  • blurRadius: Độ mờ nhòe lan tỏa của bóng (càng lớn bóng càng mềm).

gradient Gradient? Tạo màu chuyển sắc:
  • LinearGradient(colors: [Colors.blue, Colors.teal], begin: Alignment.centerLeft, end: Alignment.centerRight)
shape BoxShape (mặc định: rectangle) Hình dạng khối: BoxShape.rectangle (hình chữ nhật) hoặc BoxShape.circle (tự động biến thành hình tròn hoàn hảo không cần tính bán kính).

Bảng Tra Cứu Toàn Bộ Thuộc Tính Của TextStyle

Thuộc tính Kiểu dữ liệu & Mặc định Ý nghĩa & Hướng dẫn sử dụng
color Color? Màu sắc của chữ: Colors.blue, Colors.black87, Color(0xFFE53935) hoặc Colors.black.withOpacity(0.6).
fontSize double? (mặc định: 14.0) Kích thước phông chữ (pixels). Quy chuẩn thiết kế đề thi:
  • 11 - 12: Ghi chú nhỏ, nhãn phụ, ngày giờ đăng.
  • 14: Văn bản nội dung thông thường (Body text).
  • 16: Phụ đề, chữ trên nút bấm, tên trường nhập liệu.
  • 18 - 20: Tiêu đề thẻ Card, tên sản phẩm, AppBar title.
  • 24+: Tiêu đề lớn màn hình chào, banner nổi bật.
fontWeight FontWeight? Độ dày/đậm của nét chữ:
  • FontWeight.w300 (Light): Nét chữ thanh mảnh.
  • FontWeight.normal / w400: Nét chữ bình thường.
  • FontWeight.w500 / w600: Đậm vừa phải (Semi-bold, rất đẹp cho subtitle/tag).
  • FontWeight.bold / w700: In đậm rõ nét (dùng cho giá tiền, tiêu đề).
  • FontWeight.w900: Rất đậm (Black/Heavy).
fontStyle FontStyle? Kiểu dáng chữ: FontStyle.italic (in nghiêng) hoặc FontStyle.normal (thẳng đứng).
letterSpacing double? Khoảng cách giãn cách giữa các ký tự chữ cái:
  • Đặt letterSpacing: 1.5: Giúp tiêu đề chữ IN HOA thoáng đãng và sang trọng.
  • Đặt letterSpacing: 4.0: Dùng cho ô nhập mã OTP hoặc số thẻ ngân hàng.
wordSpacing double? Khoảng cách giãn cách giữa các từ trong câu.
height double? Tỉ lệ chiều cao dòng (Line-height multiplier). Ví dụ: height: 1.5 nghĩa là chiều cao dòng bằng 1.5 lần fontSize, giúp đoạn văn đọc không bị dính sát vào nhau.
decoration TextDecoration? Đường kẻ trang trí văn bản:
  • TextDecoration.underline: Gạch chân dưới chữ (đường dẫn liên kết, link "Xem thêm").
  • TextDecoration.lineThrough: Gạch ngang xuyên qua chữ (giá gốc trước khi giảm giá).
  • TextDecoration.overline: Gạch ngang trên đầu chữ.
  • TextDecoration.none: Bỏ mọi đường gạch.
decorationColor Color? Màu của đường kẻ gạch (ví dụ: gạch đường màu đỏ hoặc xám).
decorationStyle TextDecorationStyle? Kiểu nét gạch: solid (nét liền), dashed (nét đứt gạch), dotted (chấm bi), wavy (lượn sóng).
shadows List<Shadow>? Đổ bóng cho chữ: [Shadow(color: Colors.black38, offset: Offset(1, 2), blurRadius: 4)].

6. Nhóm Form & Nhập Liệu Toàn Diện (Forms & Input Widgets)

Nhóm widget cốt lõi cho mọi màn hình Đăng nhập, Đăng ký, Thêm mới & Chỉnh sửa dữ liệu (CRUD) trong Flutter. Bao gồm cơ chế quản lý Form State, xác thực tính hợp lệ (Validation), các kiểu ô nhập văn bản, menu chọn thả xuống và các nút lựa chọn chuyển đổi.

A. Khung Quản Lý Form & GlobalKey<FormState>

Form là widget container bao ngoài để liên kết và điều phối toàn bộ các trường nhập liệu con (TextFormField, DropdownButtonFormField...). Quản lý tập trung việc kiểm tra dữ liệu hợp lệ (Validate), lưu dữ liệu (Save) và đặt lại dữ liệu (Reset).

// 1. Khai báo Form Key trong State
final GlobalKey<FormState> _formKey = GlobalKey<FormState>();

// 2. Cấu trúc Form bọc ngoài
Form({
  Key? key,                               // BẮT BUỘC: Truyền _formKey vào đây
  required Widget child,                  // Thường là Column hoặc ListView chứa các ô nhập
  AutovalidateMode? autovalidateMode,     // Chế độ tự động kiểm tra lỗi
  void Function()? onChanged,             // Lắng nghe khi có bất kỳ trường con nào thay đổi
})

// 3. Sử dụng 3 hàm cốt lõi của _formKey:
void _submitForm() {
  // A. Kiểm tra tính hợp lệ của toàn bộ ô nhập:
  if (_formKey.currentState!.validate()) {
    // B. Gọi onSaved của toàn bộ ô con (nếu có dùng):
    _formKey.currentState!.save();
    
    // C. Tiến hành lưu dữ liệu vào SQLite / gọi API:
    ScaffoldMessenger.of(context).showSnackBar(
      const SnackBar(content: Text('Dữ liệu hợp lệ, đang lưu...'), backgroundColor: Colors.green),
    );
  }
}

void _resetForm() {
  // Đưa toàn bộ ô nhập về rỗng và xóa hết các thông báo lỗi đỏ:
  _formKey.currentState!.reset();
}
Thuộc tính / Phương thức Kiểu dữ liệu Mô tả chi tiết & Công dụng
key: _formKey GlobalKey<FormState> Chiếc chìa khóa định danh và điều khiển trạng thái của toàn bộ Form.
autovalidateMode AutovalidateMode Quy định thời điểm hiển thị thông báo lỗi:
  • AutovalidateMode.disabled (mặc định): Chỉ báo lỗi khi người dùng bấm nút Submit và gọi lệnh validate().
  • AutovalidateMode.onUserInteraction: Rất hay dùng. Tự động kiểm tra và cập nhật lỗi ngay khi người dùng chạm vào gõ phím.
  • AutovalidateMode.always: Luôn kiểm tra lỗi ngay từ khi màn hình vừa mở lên.
validate() bool Function() Kích hoạt hàm validator của tất cả widget con. Trả về true nếu toàn bộ đều hợp lệ (tất cả validator trả về null), trả về false nếu có ít nhất 1 ô sai.

B. Phân Tích Toàn Bộ Thuộc Tính Của TextFormField (So Sánh Với TextField)

So sánh nhanh:

  • TextField: Dùng độc lập cho các ô tìm kiếm đơn giản, ô nhập tin nhắn chat nhanh không cần xác thực tính hợp lệ.
  • TextFormField: Kế thừa từ FormField<String>, bọc ngoài TextField và tích hợp chặt chẽ với Form. Hỗ trợ thuộc tính validator, onSaved, hiển thị viền đỏ báo lỗi tự động. Luôn dùng TextFormField trong đề thi và các màn hình nhập liệu!
TextFormField({
  Key? key,
  TextEditingController? controller,       // Đọc/ghi dữ liệu chữ
  String? initialValue,                    // Giá trị mặc định (không dùng chung với controller)
  InputDecoration? decoration = const InputDecoration(), // Trang trí viền, nhãn, icon
  TextInputType? keyboardType,             // Kiểu bàn phím ảo (text, number, email, phone...)
  TextInputAction? textInputAction,         // Nút hành động góc dưới bàn phím (next, done, search)
  bool obscureText = false,                // Ẩn mật khẩu (dấu tròn •)
  String obscuringCharacter = '•',         // Ký tự che mật khẩu
  FormFieldValidator<String>? validator,   // Hàm kiểm tra tính hợp lệ
  void Function(String)? onChanged,        // Bắt sự kiện gõ phím theo thời gian thực
  void Function(String?)? onSaved,         // Callback khi gọi _formKey.currentState!.save()
  void Function(String)? onFieldSubmitted, // Bắt sự kiện khi bấm nút Done/Enter trên bàn phím
  int? maxLines = 1,                       // Số dòng tối đa (nếu obscureText = true thì bắt buộc là 1)
  int? minLines,                           // Số dòng tối thiểu
  int? maxLength,                          // Giới hạn ký tự tối đa (tự hiện bộ đếm 0/100)
  bool readOnly = false,                   // Chỉ đọc, không hiện bàn phím ảo (dùng cho DatePicker)
  bool enabled = true,                     // Bật/tắt ô nhập
  List<TextInputFormatter>? inputFormatters, // Bộ lọc định dạng nhập (ví dụ: chỉ nhập số)
  VoidCallback? onTap,                     // Sự kiện chạm vào ô nhập
})

C. Menu Chọn Thả Xuống: DropdownButtonFormField<T>

Widget chọn 1 giá trị trong danh sách cho trước, tích hợp sẵn với Form Validation và có giao diện viền bao quanh tương tự TextFormField.

// Khai báo biến lưu giá trị được chọn trong State
String? _selectedCategory;
final List<String> _categories = ['Công nghệ', 'Thời trang', 'Đồ gia dụng', 'Sách'];

DropdownButtonFormField<String>({
  Key? key,
  String? value,                                     // Giá trị hiện tại đang được chọn (phải nằm trong items)

  bool isExpanded = true,                            // Mở rộng hết chiều ngang (tránh tràn chữ)

DropdownButtonFormField<String>(
  value: _selectedCategory,
  isExpanded: true,

    labelText: 'Thể loại sản phẩm',

E. Nút Chọn 1 Trong Nhiều: Radio<T> & RadioListTile<T>

Dùng khi người dùng chỉ được phép chọn duy nhất 1 lựa chọn trong một nhóm (ví dụ: Giới tính [Nam / Nữ / Khác], Phương thức thanh toán [Tiền mặt / Thẻ ATM / Ví điện tử]).

// 1. Khai báo biến lưu giá trị được chọn chung cho cả nhóm:
String _selectedGender = 'Nam';

// 2. Sử dụng RadioListTile:

  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    const Text('Giới tính:', style: TextStyle(fontWeight: FontWeight.bold)),
    RadioListTile<String>(
      title: const Text('Nam'),
      value: 'Nam',                  // Giá trị riêng của lựa chọn này
      groupValue: _selectedGender,   // Biến chung của cả nhóm (Nếu value == groupValue thì nút này được chọn)
      activeColor: Colors.blue,
      onChanged: (String? val) {
        setState(() => _selectedGender = val!);
      },
    ),
    RadioListTile<String>(
      title: const Text('Nữ'),
      value: 'Nữ',
      groupValue: _selectedGender,
      activeColor: Colors.blue,
      onChanged: (String? val) {
        setState(() => _selectedGender = val!);
      },
    ),
  ],
)
Hiểu đúng cơ chế Radio trong Flutter: value vs groupValue
  • value: Là giá trị định danh riêng của chính nút radio đó (ví dụ nút này là 'Nam', nút kia là 'Nữ').
  • groupValue: Là biến trạng thái chung lưu giá trị đang được chọn của cả nhóm radio.
  • Quy tắc hoạt động: Nút radio nào có value == groupValue thì nút đó sẽ tự động hiển thị chấm tròn được chọn.

G. Bộ Chọn Ngày & Giờ (DatePicker & TimePicker Tích Hợp Vào Form)

Cách xử lý chuẩn nhất trong bài thi để người dùng chọn Ngày tháng (Ngày sinh, Ngày đặt vé...) mà không cần tự gõ tay bằng chuỗi:

// 1. Khai báo Controller lưu ngày đã chọn
final TextEditingController _dobController = TextEditingController();

// 2. Hàm mở popup lịch chọn ngày
Future<void> _selectDate(BuildContext context) async {
  final DateTime? picked = await showDatePicker(
    context: context,
    initialDate: DateTime.now().subtract(const Duration(days: 365 * 20)), // Mặc định mở ở 20 năm trước
    firstDate: DateTime(1900),                                           // Ngày nhỏ nhất được chọn
    lastDate: DateTime.now(),                                             // Ngày lớn nhất được chọn
    helpText: 'CHỌN NGÀY SINH',
    cancelText: 'HỦY',
    confirmText: 'CHỌN',
  );
  
  if (picked != null) {
    // Định dạng ngày thành dạng YYYY-MM-DD và gán vào controller
    final String formattedDate = "${picked.year}-${picked.month.toString().padLeft(2, '0')}-${picked.day.toString().padLeft(2, '0')}";
    setState(() {
      _dobController.text = formattedDate;
    });
  }
}

// 3. Gắn vào ô TextFormField với thuộc tính readOnly: true
TextFormField(
  controller: _dobController,
  readOnly: true, // KHÔNG CHO GÕ TAY, CHỈ ĐƯỢC CHỌN QUA LỊCH

    prefixIcon: const Icon(Icons.calendar_today),
    border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
  ),
  onTap: () => _selectDate(context), // Bấm vào ô là bật popup lịch
  validator: (val) {
    if (val == null || val.trim().isEmpty) {
      return 'Vui lòng chọn ngày sinh!';

H. Mẫu Form Đăng Ký / Nhập Liệu Hoàn Chỉnh Thực Chiến (Form Validation Pattern)

Đoạn mã mẫu hoàn chỉnh từ A-Z kết hợp toàn bộ các widget Form trên: Kiểm tra hợp lệ Tên, Email (RegExp), Mật khẩu (ẩn/hiện mắt), Dropdown, Checkbox và nút Submit.

import 'package:flutter/material.dart';

class RegisterFormScreen extends StatefulWidget {
  const RegisterFormScreen({super.key});

  @override
  State<RegisterFormScreen> createState() => _RegisterFormScreenState();
}

class _RegisterFormScreenState extends State<RegisterFormScreen> {
  final GlobalKey<FormState> _formKey = GlobalKey<FormState>();

  // Controllers
  final TextEditingController _nameController = TextEditingController();
  final TextEditingController _emailController = TextEditingController();
  final TextEditingController _passwordController = TextEditingController();
  final TextEditingController _confirmPassController = TextEditingController();

  // Trạng thái Form
  bool _isObscure = true;
  String? _selectedRole;
  bool _agreeTerms = false;
  final List<String> _roles = ['Học viên', 'Giảng viên', 'Quản trị viên'];

  @override
  void dispose() {
    _nameController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _confirmPassController.dispose();
    super.dispose();
  }

  void _submit() {
    if (!_agreeTerms) {
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(content: Text('Bạn phải đồng ý với điều khoản dịch vụ!'), backgroundColor: Colors.red),
      );
      return;
    }

    if (_formKey.currentState!.validate()) {
      // Form hợp lệ 100% -> Xử lý dữ liệu
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(
          content: Text('Đăng ký thành công: ${_nameController.text} (${_selectedRole})'),
          backgroundColor: Colors.green,
        ),
      );
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Đăng Ký Tài Khoản')),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          autovalidateMode: AutovalidateMode.onUserInteraction, // Tự động validate khi người dùng nhập
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // 1. Họ và tên
              TextFormField(
                controller: _nameController,
                decoration: InputDecoration(
                  labelText: 'Họ và tên',
                  prefixIcon: const Icon(Icons.person),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
                ),
                validator: (val) {
                  if (val == null || val.trim().isEmpty) return 'Vui lòng nhập họ và tên';
                  if (val.trim().length < 3) return 'Họ tên phải từ 3 ký tự trở lên';
                  return null;
                },
              ),
              const SizedBox(height: 16),

              // 2. Email (Có regex kiểm tra định dạng)
              TextFormField(
                controller: _emailController,
                keyboardType: TextInputType.emailAddress,
                decoration: InputDecoration(
                  labelText: 'Email',
                  prefixIcon: const Icon(Icons.email),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
                ),
                validator: (val) {
                  if (val == null || val.trim().isEmpty) return 'Vui lòng nhập email';
                  final emailRegex = RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$');
                  if (!emailRegex.hasMatch(val.trim())) return 'Email không đúng định dạng';
                  return null;
                },
              ),
              const SizedBox(height: 16),

              // 3. Mật khẩu
              TextFormField(
                controller: _passwordController,
                obscureText: _isObscure,
                decoration: InputDecoration(
                  labelText: 'Mật khẩu',
                  prefixIcon: const Icon(Icons.lock),
                  suffixIcon: IconButton(
                    icon: Icon(_isObscure ? Icons.visibility_off : Icons.visibility),
                    onPressed: () => setState(() => _isObscure = !_isObscure),
                  ),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
                ),
                validator: (val) {
                  if (val == null || val.isEmpty) return 'Vui lòng nhập mật khẩu';
                  if (val.length < 6) return 'Mật khẩu phải có ít nhất 6 ký tự';
                  return null;
                },
              ),
              const SizedBox(height: 16),

              // 4. Xác nhận mật khẩu
              TextFormField(
                controller: _confirmPassController,
                obscureText: _isObscure,
                decoration: InputDecoration(
                  labelText: 'Nhập lại mật khẩu',
                  prefixIcon: const Icon(Icons.lock_outline),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
                ),
                validator: (val) {
                  if (val != _passwordController.text) return 'Mật khẩu xác nhận không trùng khớp';
                  return null;
                },
              ),
              const SizedBox(height: 16),

              // 5. Dropdown chọn vai trò
              DropdownButtonFormField<String>(
                value: _selectedRole,
                isExpanded: true,
                decoration: InputDecoration(
                  labelText: 'Vai trò',
                  prefixIcon: const Icon(Icons.badge),
                  border: OutlineInputBorder(borderRadius: BorderRadius.circular(10)),
                ),
                hint: const Text('Chọn vai trò người dùng'),
                items: _roles.map((r) => DropdownMenuItem(value: r, child: Text(r))).toList(),
                onChanged: (val) => setState(() => _selectedRole = val),
                validator: (val) => val == null ? 'Vui lòng chọn vai trò' : null,
              ),
              const SizedBox(height: 12),

              // 6. Checkbox đồng ý điều khoản
              CheckboxListTile(
                value: _agreeTerms,
                title: const Text('Tôi đồng ý với điều khoản dịch vụ'),
                controlAffinity: ListTileControlAffinity.leading,
                contentPadding: EdgeInsets.zero,
                onChanged: (val) => setState(() => _agreeTerms = val ?? false),
              ),
              const SizedBox(height: 20),

              // 7. Nút Đăng Ký
              ElevatedButton.icon(
                onPressed: _submit,
                icon: const Icon(Icons.person_add),
                label: const Text('ĐĂNG KÝ NGAY', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                  backgroundColor: Colors.blue,
                  foregroundColor: Colors.white,
                  shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(10)),
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}
