Mục 6: Mẫu Màn Hình Thêm Mới & Chỉnh Sửa (Add / Edit Screen - 2 Trong 1)

Để tiết kiệm thời gian nhất khi thi, file code này được thiết kế theo kỹ thuật "2 trong 1" mà các lập trình viên Flutter chuyên nghiệp luôn áp dụng:

  • Nếu truyền vào item == null → App tự chuyển sang chế độ Thêm mới (Add) (ô trống, nút "THÊM MỚI").
  • Nếu truyền vào item != null → App tự động điền sẵn dữ liệu cũ vào các ô và chuyển sang chế độ Chỉnh sửa (Edit) (nút "CẬP NHẬT").
  • Sử dụng Riverpod Code Gen để lưu dữ liệu: Màn Home tự động cập nhật ngay lập tức sau khi bấm Lưu!
⚡ Danh mục phần code:
  • 1. Code AddEditItemScreen hoàn chỉnh (lib/screens/add_edit_item_screen.dart)
  • 2. Cách gọi mở màn hình Thêm mới và Sửa từ Home / Detail
  • 3. Hình ảnh minh hoạ giao diện UI Add/Edit Screen chuẩn Flutter

1. Code AddEditItemScreen Hoàn Chỉnh (lib/screens/add_edit_item_screen.dart)

Gồm Form nhập Title, Description, Dropdown Category, Price số thực, gọi sẵn AppValidator:

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../models/item_model.dart';
import '../providers/item_provider.dart';
import '../utils/app_validator.dart';

class AddEditItemScreen extends ConsumerStatefulWidget {
  // Nếu item == null là THÊM MỚI, nếu != null là SỬA CẬP NHẬT
  final ItemModel? item;

  const AddEditItemScreen({super.key, this.item});

  @override
  ConsumerState<AddEditItemScreen> createState() => _AddEditItemScreenState();
}

class _AddEditItemScreenState extends ConsumerState<AddEditItemScreen> {
  final _formKey = GlobalKey<FormState>();
  final _titleController = TextEditingController();
  final _subtitleController = TextEditingController();
  final _priceController = TextEditingController();

  String _selectedCategory = 'Loại A';
  final List<String> _categories = ['Loại A', 'Loại B', 'Loại C'];

  bool get isEditing => widget.item != null;

  @override
  void initState() {
    super.initState();
    // Nếu đang là chế độ Sửa -> Nạp sẵn dữ liệu cũ vào các ô nhập
    if (isEditing) {
      _titleController.text = widget.item!.title;
      _subtitleController.text = widget.item!.subtitle;
      _priceController.text = widget.item!.price?.toString() ?? '';
      if (_categories.contains(widget.item!.category)) {
        _selectedCategory = widget.item!.category!;
      }
    }
  }

  @override
  void dispose() {
    _titleController.dispose();
    _subtitleController.dispose();
    _priceController.dispose();
    super.dispose();
  }

  Future<void> _save() async {
    if (!_formKey.currentState!.validate()) return;

    final title = _titleController.text.trim();
    final subtitle = _subtitleController.text.trim();
    final price = double.tryParse(_priceController.text.trim()) ?? 0.0;

    if (isEditing) {
      // 1. CẬP NHẬT (EDIT): Giữ nguyên ID cũ
      final updatedItem = ItemModel(
        id: widget.item!.id,
        title: title,
        subtitle: subtitle,
        category: _selectedCategory,
        price: price,
      );
      // Gọi qua DatabaseHelper & làm mới Riverpod
      await ref.read(itemNotifierProvider.notifier).addItem(updatedItem);
    } else {
      // 2. THÊM MỚI (ADD): ID tự động tăng
      final newItem = ItemModel(
        title: title,
        subtitle: subtitle,
        category: _selectedCategory,
        price: price,
      );
      await ref.read(itemNotifierProvider.notifier).addItem(newItem);
    }

    if (!mounted) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text(isEditing ? 'Cập nhật thành công!' : 'Thêm mới thành công!')),
    );

    // Quay trở về màn hình trước (Màn Home tự động cập nhật ngay)
    Navigator.pop(context);
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: Text(isEditing ? 'Chỉnh sửa' : 'Thêm mới'),
        centerTitle: true,
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              // Field 1: Title
              TextFormField(
                controller: _titleController,
                decoration: const InputDecoration(
                  labelText: 'Title',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.required(val, 'Tiêu đề'),
              ),
              const SizedBox(height: 16),

              // Field 2: Description / Subtitle
              TextFormField(
                controller: _subtitleController,
                maxLines: 2,
                decoration: const InputDecoration(
                  labelText: 'Description',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.required(val, 'Mô tả'),
              ),
              const SizedBox(height: 16),

              // Field 3: Category Dropdown
              DropdownButtonFormField<String>(
                value: _selectedCategory,
                decoration: const InputDecoration(
                  labelText: 'Category',
                  border: OutlineInputBorder(),
                ),
                items: _categories.map((cat) {
                  return DropdownMenuItem(value: cat, child: Text(cat));
                }).toList(),
                onChanged: (val) {
                  if (val != null) setState(() => _selectedCategory = val);
                },
              ),
              const SizedBox(height: 16),

              // Field 4: Price (Số thực dương)
              TextFormField(
                controller: _priceController,
                keyboardType: const TextInputType.numberWithOptions(decimal: true),
                decoration: const InputDecoration(
                  labelText: 'Price',
                  border: OutlineInputBorder(),
                ),
                validator: (val) => AppValidator.positiveDouble(val, 'Giá tiền'),
              ),
              const SizedBox(height: 24),

              // Nút Lưu
              ElevatedButton(
                onPressed: _save,
                style: ElevatedButton.styleFrom(
                  padding: const EdgeInsets.symmetric(vertical: 14),
                ),
                child: Text(
                  isEditing ? 'LƯU THAY ĐỔI' : 'LƯU DỮ LIỆU',
                  style: const TextStyle(fontSize: 16),
                ),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

2. Cách Gọi Mở Màn Hình Này Từ HomeScreen & DetailScreen

Trường hợp 1: Khi bấm nút Thêm mới (+) ở HomeScreen

// Để item trống (mặc định null) -> Chế độ Thêm mới
floatingActionButton: FloatingActionButton(
  onPressed: () {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => const AddEditItemScreen()),
    );
  },
  child: const Icon(Icons.add),
)

Trường hợp 2: Khi bấm nút Sửa ở HomeScreen hoặc DetailScreen

// Truyền item đang chọn vào -> Chế độ Chỉnh sửa
IconButton(
  icon: const Icon(Icons.edit),
  onPressed: () {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => AddEditItemScreen(item: currentItem)),
    );
  },
)
