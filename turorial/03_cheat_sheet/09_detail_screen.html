Mục 9: Mẫu Màn Hình Chi Tiết (lib/screens/detail_screen.dart)

Màn hình đáp ứng Task Item Detail Screen: Nhận đối tượng ItemModel qua Constructor, trình bày thông tin chi tiết đẹp mắt dạng Card lớn, hỗ trợ nút Sửa trên AppBar và nút Quay lại danh sách. Toàn bộ mã nguồn class được đưa lên trên cùng, kèm hình ảnh minh họa iPhone SE trên trình duyệt và các mục giải thích chi tiết: Dùng để làm gì, dùng thế nào và vì sao.

Danh mục nội dung:
  • 1. Toàn bộ mã nguồn class DetailScreen (lib/screens/detail_screen.dart)
  • 2. Hình ảnh minh họa giao diện UI DetailScreen (iPhone SE Trên Trình Duyệt)
  • 3. Giải thích chi tiết code DetailScreen: Dùng để làm gì, dùng thế nào & vì sao?
  • 4. Cách mở DetailScreen từ HomeScreen khi người dùng nhấn vào Item

1. Toàn Bộ Mã Nguồn Class DetailScreen (lib/screens/detail_screen.dart)

import 'package:flutter/material.dart';
import '../models/item_example.dart';
import 'edit_item_screen.dart'; // Mở màn Sửa nếu cần

class DetailScreen extends StatelessWidget {
  final ItemModel item;

  const DetailScreen({super.key, required this.item});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(
        title: const Text('Chi tiết'),
        centerTitle: true,
        actions: [
          // Nút bấm chuyển sang màn hình Chỉnh sửa
          IconButton(
            icon: const Icon(Icons.edit),
            tooltip: 'Chỉnh sửa mục này',
            onPressed: () {
              Navigator.push(
                context,
                MaterialPageRoute(
                  builder: (_) => EditItemScreen(item: item),
                ),
              );
            },
          ),
        ],
      ),
      body: SingleChildScrollView(
        padding: const EdgeInsets.all(16.0),
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.stretch,
          children: [
            // Thẻ Card lớn chứa toàn bộ thông tin chi tiết
            Card(
              elevation: 3,
              shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
              child: Padding(
                padding: const EdgeInsets.all(20.0),
                child: Column(
                  children: [
                    // Avatar hoặc Biểu tượng lớn
                    CircleAvatar(
                      radius: 36,
                      child: Text(
                        item.title.isNotEmpty ? item.title[0].toUpperCase() : '?',
                        style: const TextStyle(fontSize: 28, fontWeight: FontWeight.bold),
                      ),
                    ),
                    const SizedBox(height: 16),

                    // Tiêu đề
                    Text(
                      item.title,
                      textAlign: TextAlign.center,
                      style: const TextStyle(fontSize: 20, fontWeight: FontWeight.bold),
                    ),
                    const SizedBox(height: 8),

                    // Giá tiền
                    Text(
                      '\$${item.price ?? 0.0}',
                      style: const TextStyle(
                        fontSize: 18,
                        fontWeight: FontWeight.bold,
                        color: Colors.green,
                      ),
                    ),
                    const Divider(height: 32),

                    // Thông tin dạng bảng dòng
                    _buildInfoRow('Mã định danh (ID):', '#${item.id ?? 0}'),
                    const SizedBox(height: 12),
                    _buildInfoRow('Thể loại (Category):', item.category ?? 'Mặc định'),
                    const SizedBox(height: 16),

                    // Mô tả chi tiết
                    const Align(
                      alignment: Alignment.centerLeft,
                      child: Text(
                        'Mô tả chi tiết:',
                        style: TextStyle(fontWeight: FontWeight.bold, fontSize: 14),
                      ),
                    ),
                    const SizedBox(height: 6),
                    Align(
                      alignment: Alignment.centerLeft,
                      child: Text(
                        item.subtitle.isNotEmpty ? item.subtitle : 'Không có mô tả chi tiết.',
                        style: TextStyle(color: Colors.grey.shade800, height: 1.4),
                      ),
                    ),
                  ],
                ),
              ),
            ),
            const SizedBox(height: 24),

            // Nút Quay lại
            ElevatedButton(
              onPressed: () => Navigator.pop(context),
              style: ElevatedButton.styleFrom(
                padding: const EdgeInsets.symmetric(vertical: 14),
              ),
              child: const Text('QUAY LẠI DANH SÁCH', style: TextStyle(fontSize: 16)),
            ),
          ],
        ),
      ),
    );
  }

  // Widget phụ tạo dòng thông tin hai bên
  Widget _buildInfoRow(String label, String value) {
    return Row(
      mainAxisAlignment: MainAxisAlignment.spaceBetween,
      children: [
        Text(label, style: const TextStyle(color: Colors.grey, fontSize: 14)),
        Text(value, style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 14)),
      ],
    );
  }
}

3. Giải Thích Chi Tiết Code DetailScreen: Dùng Để Làm Gì, Dùng Thế Nào & Vì Sao?

  • Kế thừa StatelessWidget:
    Vì sao dùng StatelessWidget: Màn hình chi tiết chỉ nhận dữ liệu item từ bên ngoài truyền vào để hiển thị (Read-only UI), không tự thay đổi dữ liệu nội bộ nên dùng StatelessWidget giúp tối ưu hiệu năng và code ngắn gọn nhất.
  • Avatar chữ cái đầu in hoa: item.title.isNotEmpty ? item.title[0].toUpperCase() : '?'
    Dùng để làm gì: Tự động lấy ký tự đầu tiên của tiêu đề (ví dụ "Mona Lisa" → lấy chữ "M") để làm logo đại diện trong CircleAvatar khi đề thi không yêu cầu load ảnh URL/file phức tạp.
  • Hàm phụ _buildInfoRow(label, value):
    Dùng để làm gì: Trình bày một hàng thông tin hai cột dạng Key - Value (nhãn xám bên trái, giá trị in đậm bên phải) bằng Row(mainAxisAlignment: MainAxisAlignment.spaceBetween).
    Vì sao: Tái sử dụng code, giúp giao diện đều đặn và chuyên nghiệp.
  • Nút chỉnh sửa trên AppBar:
    Dùng để làm gì: Người dùng đang xem chi tiết có thể bấm ngay biểu tượng bút sửa Icons.edit trên góc phải AppBar để chuyển sang EditItemScreen(item: item) mà không cần phải back lại danh sách.
  • Nút QUAY LẠI DANH SÁCH: Navigator.pop(context)
    Dùng để làm gì: Đóng màn hình Detail và quay trở về HomeScreen.

4. Cách Mở DetailScreen Từ HomeScreen Khi Bấm Vào Một Dòng Item

Tại HomeScreen, trong thuộc tính onTap: của ItemCardWidget, truyền lệnh mở màn hình chi tiết như sau:

onTap: () {
  Navigator.push(
    context,
    MaterialPageRoute(
      builder: (_) => DetailScreen(item: item),
    ),
  );
}
