Bước 6: Xây Dựng Màn Hình Đăng Nhập (Task 2: User Login Screen) & Liên Kết Session

Đề bài thi yêu cầu ở Task 2 — User Login: Tạo màn hình Đăng nhập với 2 ô Username và Password. Validate không để trống dữ liệu, xác thực tài khoản và mật khẩu từ SQLite Database. Nếu đăng nhập thành công: tạo phiên lưu trữ (Create User Session) và điều hướng vào Home Screen. Nếu thất bại: hiển thị thông báo lỗi Invalid username or password.

Mỗi hàm và thành phần giao diện được tách riêng từng mục kèm viền màu sắc phân biệt để bạn học đến đâu hiểu bản chất ngay đến đó.

Nội dung bài học gồm 8 phần chi tiết:
  • 1. Phân tích yêu cầu đề bài Task 2 & Hình ảnh UI mẫu Login
  • 2. Khai báo Form Key, Controllers & Thu hồi bộ nhớ dispose()
  • 3. Hàm kiểm tra hợp lệ Validation (Bắt buộc nhập Username & Password)
  • 4. Hàm xử lý logic đăng nhập _handleLogin() (So khớp CSDL & Lưu Session)
  • 5. Chi tiết các ô nhập liệu & Widget Logo thương hiệu Art Gallery
  • 6. Nút Đăng nhập & Điều hướng sang trang Đăng ký (Register)
  • 7. Toàn bộ mã nguồn hoàn chỉnh của login_screen.dart (Bấm copy 1 click)
  • 8. Checklist nghiệm thu chấm điểm Task 2

1. Phân Tích Yêu Cầu Đề Bài Task 2 & Hình Ảnh UI

Các ô nhập liệu (Fields) bắt buộc
  • Username: Tên tài khoản (icon: Icons.person_outline)
  • Password: Mật khẩu (ẩn ký tự: obscureText: true, icon: Icons.lock_outline)
  • Header Logo/Icon: Biểu tượng bảo tàng nghệ thuật (Icons.museum_outlined) nằm gọn trong ô vuông màu xanh teal nhạt.
Các điều kiện bắt buộc (Requirements)
  • Validate input fields: Không để trống ô Username và Password.
  • Verify credentials from database: Đối chiếu cặp tài khoản/mật khẩu với SQLite.
  • If login succeeds: Gọi SessionService.saveUserSession() & điều hướng vào Home Screen (thay thế ngăn xếp để bấm Back không bị quay lại Login).
  • If login fails: Hiển thị thông báo lỗi chính xác: Invalid username or password bằng SnackBar đỏ.

3. Hàm Kiểm Tra Hợp Lệ Dữ Liệu (Validators)

Hàm kiểm tra không được để trống

Nhiệm vụ: Kiểm tra người dùng đã gõ đầy đủ tên tài khoản và mật khẩu hay chưa trước khi gửi lệnh truy vấn CSDL.

// 1. Validator Username
String? validateUsername(String? val) {
  if (val == null || val.trim().isEmpty) {
    return 'Username is required';
  }
  return null;
}

// 2. Validator Password
String? validatePassword(String? val) {
  if (val == null || val.isEmpty) {
    return 'Password is required';
  }
  return null;
}

4. Hàm Xử Lý Sự Kiện Đăng Nhập _handleLogin()

Quy trình 5 bước xác thực & tạo Session

Nhiệm vụ: Kiểm tra Form → Gọi hàm DatabaseHelper.instance.loginUser → Nếu khớp thì gọi SessionService.saveUserSession → Chuyển sang HomeScreen bằng pushReplacement.

  Future _handleLogin() async {
    // 1. Kiểm tra validation form
    if (!_formKey.currentState!.validate()) {
      return;
    }

    final username = _usernameController.text.trim();
    final password = _passwordController.text;

    setState(() => _isLoading = true);

    try {
      // 2. Xác thực tài khoản với CSDL SQLite
      final user = await DatabaseHelper.instance.loginUser(username, password);

      if (user != null) {
        // ĐĂNG NHẬP THÀNH CÔNG (Login succeeds):
        // 3. Khởi tạo phiên làm việc (Create user session)
        await SessionService.saveUserSession(user.id!, user.username);

        if (!mounted) return;
        // Thông báo thành công
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text('Xin chào, ${user.username}! Đăng nhập thành công.'),
            backgroundColor: Colors.teal,
          ),
        );

        // 4. Chuyển sang Home Screen (Dùng pushReplacement để không Back lại màn Login)
        Navigator.pushReplacement(
          context,
          MaterialPageRoute(builder: (context) => const HomeScreen()),
        );
      } else {
        // ĐĂNG NHẬP THẤT BẠI (Login fails):
        // 5. Hiển thị thông báo lỗi chuẩn theo yêu cầu đề bài
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Invalid username or password'),
            backgroundColor: Colors.red,
          ),
        );
      }
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

7. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của login_screen.dart

Tạo file: lib/screens/login_screen.dart và dán toàn bộ mã nguồn bên dưới vào:

// lib/screens/login_screen.dart
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../services/session_service.dart';
import 'home_screen.dart';
import 'register_screen.dart';

class LoginScreen extends StatefulWidget {
  const LoginScreen({super.key});

  @override
  State createState() => _LoginScreenState();
}

class _LoginScreenState extends State {
  final _formKey = GlobalKey();
  final _usernameController = TextEditingController();
  final _passwordController = TextEditingController();

  bool _isLoading = false;
  bool _obscurePassword = true;

  @override
  void dispose() {
    _usernameController.dispose();
    _passwordController.dispose();
    super.dispose();
  }

  Future _handleLogin() async {
    if (!_formKey.currentState!.validate()) {
      return;
    }

    final username = _usernameController.text.trim();
    final password = _passwordController.text;

    setState(() => _isLoading = true);

    try {
      // 1. Xác thực từ Database SQLite
      final user = await DatabaseHelper.instance.loginUser(username, password);

      if (user != null) {
        // Đăng nhập thành công: Lưu phiên làm việc
        await SessionService.saveUserSession(user.id!, user.username);

        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          SnackBar(
            content: Text('Xin chào, ${user.username}! Đăng nhập thành công.'),
            backgroundColor: Colors.teal,
          ),
        );

        // Chuyển sang màn hình Home
        Navigator.pushReplacement(
          context,
          MaterialPageRoute(builder: (context) => const HomeScreen()),
        );
      } else {
        // Đăng nhập thất bại: Thông báo lỗi theo đúng yêu cầu đề bài
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Invalid username or password'),
            backgroundColor: Colors.red,
          ),
        );
      }
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.white,
      body: SafeArea(
        child: Center(
          child: SingleChildScrollView(
            padding: const EdgeInsets.symmetric(horizontal: 24.0, vertical: 16.0),
            child: Form(
              key: _formKey,
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.stretch,
                children: [
                  // 1. Header Logo
                  Center(
                    child: Container(
                      width: 64,
                      height: 64,
                      decoration: BoxDecoration(
                        color: const Color(0xFFE0F2F1),
                        borderRadius: BorderRadius.circular(16),
                      ),
                      child: const Icon(Icons.museum_outlined, color: Color(0xFF00695C), size: 38),
                    ),
                  ),
                  const SizedBox(height: 16),
                  const Text(
                    'Art Gallery Manager',
                    textAlign: TextAlign.center,
                    style: TextStyle(fontSize: 24, fontWeight: FontWeight.bold, color: Colors.black87),
                  ),
                  const SizedBox(height: 6),
                  const Text(
                    'Sign in to manage your collection',
                    textAlign: TextAlign.center,
                    style: TextStyle(color: Colors.grey, fontSize: 14),
                  ),
                  const SizedBox(height: 32),

                  // 2. Ô Username
                  TextFormField(
                    controller: _usernameController,
                    decoration: const InputDecoration(
                      labelText: 'Username',
                      hintText: 'testuser123',
                      prefixIcon: Icon(Icons.person_outline),
                      border: OutlineInputBorder(),
                    ),
                    validator: (val) {
                      if (val == null || val.trim().isEmpty) return 'Username is required';
                      return null;
                    },
                  ),
                  const SizedBox(height: 16),

                  // 3. Ô Password
                  TextFormField(
                    controller: _passwordController,
                    obscureText: _obscurePassword,
                    decoration: InputDecoration(
                      labelText: 'Password',
                      prefixIcon: const Icon(Icons.lock_outline),
                      border: const OutlineInputBorder(),
                      suffixIcon: IconButton(
                        icon: Icon(_obscurePassword ? Icons.visibility_off : Icons.visibility),
                        onPressed: () => setState(() => _obscurePassword = !_obscurePassword),
                      ),
                    ),
                    validator: (val) {
                      if (val == null || val.isEmpty) return 'Password is required';
                      return null;
                    },
                  ),
                  const SizedBox(height: 24),

                  // 4. Nút bấm Login
                  SizedBox(
                    height: 50,
                    child: ElevatedButton(
                      onPressed: _isLoading ? null : _handleLogin,
                      style: ElevatedButton.styleFrom(
                        backgroundColor: const Color(0xFF00695C),
                        foregroundColor: Colors.white,
                        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),
                      ),
                      child: _isLoading
                          ? const SizedBox(width: 24, height: 24, child: CircularProgressIndicator(color: Colors.white, strokeWidth: 2.5))
                          : const Text('Login', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                    ),
                  ),
                  const SizedBox(height: 20),

                  // 5. Chuyển sang Register Screen
                  Row(
                    mainAxisAlignment: MainAxisAlignment.center,
                    children: [
                      const Text('No account? '),
                      GestureDetector(
                        onTap: () {
                          Navigator.push(
                            context,
                            MaterialPageRoute(builder: (context) => const RegisterScreen()),
                          );
                        },
                        child: const Text('Register now', style: TextStyle(color: Color(0xFF00695C), fontWeight: FontWeight.bold)),
                      ),
                    ],
                  ),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}
