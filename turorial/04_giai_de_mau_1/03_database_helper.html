Bước 3: Thiết Kế & Xây Dựng DatabaseHelper (SQLite Cục Bộ Toàn App)

Trước khi dựng bất kỳ màn hình nào (Đăng ký, Đăng nhập, Danh sách, Thêm mới, Xóa), chúng ta bắt buộc phải có tầng xử lý Cơ sở dữ liệu (Database Layer). Tầng này chịu trách nhiệm: khởi tạo file CSDL, tự động tạo các bảng, nạp sẵn dữ liệu mẫu (Seeding Data) và cung cấp các hàm truy vấn cho toàn bộ ứng dụng.

Để bạn dễ học và tra cứu nhanh, mỗi hàm được tách thành từng mục riêng biệt kèm màu sắc phân biệt, giải thích rõ input/output và mục đích sử dụng trước khi xem file code hoàn chỉnh ở cuối trang.

Nội dung bài học gồm 8 phần chi tiết:
  • 1. Phân tích lược đồ CSDL & Mối quan hệ bảng (User 1 - n Artwork)
  • 2. Khởi tạo Singleton & Hàm mở kết nối _initDB() (Mobile + Web)
  • 3. Hàm tạo bảng & Nạp dữ liệu mẫu _createDB() (Data Seeding)
  • 4. Hàm kiểm tra trùng Username checkUsernameExists() (Phục vụ Task 1)
  • 5. Hàm đăng ký tài khoản registerUser() (Phục vụ Task 1)
  • 6. Hàm xác thực đăng nhập loginUser() (Phục vụ Task 2)
  • 7. Các hàm CRUD Artwork: getAllArtworks(), insertArtwork(), deleteArtwork()
  • 8. Tổng hợp toàn bộ file database_helper.dart (Bấm copy 1 click)

1. Phân Tích Lược Đồ CSDL & Mối Quan Hệ Bảng

Mối quan hệ 1 - Nhiều (1 to Many)

User (1) ———— (n) Artwork

• Một User có thể tạo nhiều tác phẩm nghệ thuật (Artworks).
• Mỗi Artwork thuộc về đúng một User thông qua khoá ngoại: createdBy INTEGER REFERENCES users(id).

Bảng Cột Kiểu SQLite Ràng buộc & Ý nghĩa
users id INTEGER PRIMARY KEY AUTOINCREMENT (Khóa chính tự tăng)
username TEXT NOT NULL UNIQUE (Bắt buộc, không trùng lặp)
email TEXT NOT NULL (Email người dùng)
password TEXT NOT NULL (Mật khẩu)
createdAt TEXT NOT NULL (Ngày tạo YYYY-MM-DD)
artworks id INTEGER PRIMARY KEY AUTOINCREMENT (Khóa chính tự tăng)
title TEXT NOT NULL (Tên tác phẩm)
artist TEXT NOT NULL (Tên nghệ sĩ)
year INTEGER NOT NULL (Năm sáng tác)
category TEXT NOT NULL (Thể loại)
description TEXT NOT NULL (Mô tả chi tiết)
createdBy INTEGER NOT NULL (Khóa ngoại trỏ về users.id)

2. Khởi Tạo Singleton & Hàm Mở Kết Nối _initDB()

Khởi tạo Singleton & Getter mở Database

Mục đích: Đảm bảo toàn bộ ứng dụng chỉ có duy nhất 1 kết nối SQLite, tránh xung đột khóa file (Database Locked). Hỗ trợ chạy mượt trên cả Android Emulator lẫn Web Browser (Chrome/Edge khi máy ảo lag).

class DatabaseHelper {
  // Thể hiện duy nhất (Singleton Instance)
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;

  // Constructor Private ngăn chặn new từ bên ngoài
  DatabaseHelper._init();

  // Getter: Nếu đã mở thì trả về luôn, chưa thì gọi _initDB()
  Future get database async {
    if (_database != null) return _database!;
    _database = await _initDB('app_gallery.db');
    return _database!;
  }

  // Hàm mở database đa nền tảng (Mobile + Web)
  Future _initDB(String filePath) async {
    // 1. Nếu chạy trên Trình duyệt Web
    if (kIsWeb) {
      final databaseFactory = databaseFactoryFfiWeb;
      return await databaseFactory.openDatabase(
        filePath,
        options: OpenDatabaseOptions(
          version: 1,
          onCreate: _createDB,
        ),
      );
    }

    // 2. Nếu chạy trên Android / iOS
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: _createDB,
    );
  }
}

4. Hàm Kiểm Tra Trùng Username checkUsernameExists()

Hàm kiểm tra trùng tài khoản (Phục vụ Task 1: Register)

Nhiệm vụ: Nhận vào một chuỗi username, tìm trong bảng users xem có ai đã sử dụng tên này chưa. Trả về true nếu đã bị trùng (không cho đăng ký), false nếu hợp lệ.

  // Kiểm tra username đã tồn tại chưa: true = ĐÃ TỒN TẠI, false = HỢP LỆ
  Future checkUsernameExists(String username) async {
    final db = await instance.database;
    final result = await db.query(
      'users',
      where: 'username = ?',
      whereArgs: [username.trim()],
    );
    return result.isNotEmpty; // Nếu kết quả khác rỗng tức là đã bị trùng
  }

5. Hàm Đăng Ký Người Dùng Mới registerUser()

Hàm thêm User vào Database (Phục vụ Task 1: Register)

Nhiệm vụ: Nhận vào đối tượng UserModel từ Form đăng ký, gọi hàm user.toMap() và thực hiện câu lệnh INSERT INTO users. SQLite sẽ tự động cấp một số id tự tăng.

  // Thêm người dùng mới vào database, trả về ID vừa sinh
  Future registerUser(UserModel user) async {
    final db = await instance.database;
    return await db.insert('users', user.toMap());
  }

6. Hàm Xác Thực Đăng Nhập loginUser()

Hàm xác thực tài khoản & mật khẩu (Phục vụ Task 2: Login)

Nhiệm vụ: Kiểm tra cặp username và password trong bảng users. Nếu đúng, trả về đầy đủ đối tượng UserModel (có chứa ID của user). Nếu sai, trả về null.

  // Tìm người dùng theo username và password
  Future loginUser(String username, String password) async {
    final db = await instance.database;
    final result = await db.query(
      'users',
      where: 'username = ? AND password = ?',
      whereArgs: [username.trim(), password],
    );

    if (result.isNotEmpty) {
      // Chuyển Map thành UserModel
      return UserModel.fromMap(result.first);
    }
    return null; // Đăng nhập thất bại (sai tài khoản hoặc mật khẩu)
  }

7. Các Hàm CRUD Artwork (Danh Sách, Thêm Mới, Xóa)

Bộ 3 hàm xử lý Artwork (Phục vụ Task 4, 5, 7)

Nhiệm vụ: Lấy toàn bộ danh sách tranh để hiển thị lên Home Screen, chèn tranh mới khi submit Add Artwork Screen, và xoá tranh theo ID khi nhấn nút Delete.

  // 1. Lấy toàn bộ danh sách tác phẩm (Sắp xếp mới nhất lên đầu - Task 4)
  Future> getAllArtworks() async {
    final db = await instance.database;
    final result = await db.query('artworks', orderBy: 'id DESC');
    return result.map((json) => ArtworkModel.fromMap(json)).toList();
  }

  // 2. Thêm mới tác phẩm vào CSDL (Task 5)
  Future insertArtwork(ArtworkModel artwork) async {
    final db = await instance.database;
    return await db.insert('artworks', artwork.toMap());
  }

  // 3. Xoá tác phẩm theo ID (Task 7)
  Future deleteArtwork(int id) async {
    final db = await instance.database;
    return await db.delete(
      'artworks',
      where: 'id = ?',
      whereArgs: [id],
    );
  }

8. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của database_helper.dart

Sau khi đã hiểu bản chất từng hàm ở trên, bạn tạo file lib/database/database_helper.dart và dán toàn bộ file hoàn chỉnh này vào:

// lib/database/database_helper.dart
import 'package:flutter/foundation.dart';
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';
import 'package:sqflite_common_ffi_web/sqflite_ffi_web.dart';
import '../models/user_model.dart';
import '../models/artwork_model.dart';

class DatabaseHelper {
  // 1. Singleton
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;

  DatabaseHelper._init();

  Future get database async {
    if (_database != null) return _database!;
    _database = await _initDB('app_gallery.db');
    return _database!;
  }

  // 2. Mở kết nối
  Future _initDB(String filePath) async {
    if (kIsWeb) {
      final databaseFactory = databaseFactoryFfiWeb;
      return await databaseFactory.openDatabase(
        filePath,
        options: OpenDatabaseOptions(
          version: 1,
          onCreate: _createDB,
        ),
      );
    }

    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: _createDB,
    );
  }

  // 3. Tạo bảng & Nạp dữ liệu mẫu
  Future _createDB(Database db, int version) async {
    await db.execute('''
      CREATE TABLE users (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        username TEXT NOT NULL UNIQUE,
        email TEXT NOT NULL,
        password TEXT NOT NULL,
        createdAt TEXT NOT NULL
      )
    ''');

    await db.execute('''
      CREATE TABLE artworks (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        artist TEXT NOT NULL,
        year INTEGER NOT NULL,
        category TEXT NOT NULL,
        description TEXT NOT NULL,
        createdBy INTEGER NOT NULL,
        FOREIGN KEY (createdBy) REFERENCES users (id) ON DELETE CASCADE
      )
    ''');

    // Chèn user mẫu
    await db.insert('users', {
      'username': 'admin',
      'email': 'admin@gallery.com',
      'password': '123456',
      'createdAt': '2026-01-10',
    });

    await db.insert('users', {
      'username': 'artist01',
      'email': 'artist01@gallery.com',
      'password': '123456',
      'createdAt': '2026-01-12',
    });

    // Chèn tranh mẫu
    await db.insert('artworks', {
      'title': 'Starry Night',
      'artist': 'Vincent van Gogh',
      'year': 1889,
      'category': 'Abstract',
      'description': 'A famous Abstract of a swirling night sky over a small town.',
      'createdBy': 1,
    });

    await db.insert('artworks', {
      'title': 'Mona Lisa',
      'artist': 'Leonardo da Vinci',
      'year': 1503,
      'category': 'Abstract',
      'description': 'A portrait Abstract known for the subject\'s mysterious smile.',
      'createdBy': 1,
    });

    await db.insert('artworks', {
      'title': 'The Persistence of Memory',
      'artist': 'Salvador Dali',
      'year': 1931,
      'category': 'Abstract',
      'description': 'A surreal Abstract featuring melting clocks.',
      'createdBy': 1,
    });
  }

  // 4. Xử lý User
  Future checkUsernameExists(String username) async {
    final db = await instance.database;
    final result = await db.query(
      'users',
      where: 'username = ?',
      whereArgs: [username.trim()],
    );
    return result.isNotEmpty;
  }

  Future registerUser(UserModel user) async {
    final db = await instance.database;
    return await db.insert('users', user.toMap());
  }

  Future loginUser(String username, String password) async {
    final db = await instance.database;
    final result = await db.query(
      'users',
      where: 'username = ? AND password = ?',
      whereArgs: [username.trim(), password],
    );

    if (result.isNotEmpty) {
      return UserModel.fromMap(result.first);
    }
    return null;
  }

  // 5. Xử lý Artwork
  Future> getAllArtworks() async {
    final db = await instance.database;
    final result = await db.query('artworks', orderBy: 'id DESC');
    return result.map((json) => ArtworkModel.fromMap(json)).toList();
  }

  Future insertArtwork(ArtworkModel artwork) async {
    final db = await instance.database;
    return await db.insert('artworks', artwork.toMap());
  }

  Future deleteArtwork(int id) async {
    final db = await instance.database;
    return await db.delete(
      'artworks',
      where: 'id = ?',
      whereArgs: [id],
    );
  }

  Future close() async {
    final db = await instance.database;
    db.close();
  }
}
