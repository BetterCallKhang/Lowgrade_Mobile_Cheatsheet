Bước 8: Xây Dựng Màn Hình Thêm Mới Tác Phẩm (Task 5: Add Artwork Screen)

Đề bài thi yêu cầu ở Task 5 — Add Artwork: Tạo màn hình Add Artwork Screen gồm các trường: Title, Artist, Year, Category (Dropdown), Description. Yêu cầu: ID tự động tăng (auto-increment), lưu vào cơ sở dữ liệu SQLite kèm ID người tạo (createdBy lấy từ Session). Sau khi lưu: hiển thị SnackBar thông báo thành công ("Artwork added successfully"), quay trở lại Home Screen và cập nhật danh sách mới.

Các hàm và thành phần giao diện được chia nhỏ theo từng mục có viền màu sắc phân biệt rõ ràng.

Nội dung bài học gồm 8 phần chi tiết:
  • 1. Phân tích yêu cầu Task 5 & Giao diện mẫu theo đề thi
  • 2. Khai báo Form Key, Controllers, biến State & Hàm dispose()
  • 3. Widget DropdownButtonFormField cho trường Thể loại (Category)
  • 4. Hàm xử lý lưu vào CSDL _handleSaveArtwork() (Lấy Session ID & Insert)
  • 5. Chi tiết các ô nhập liệu (Title, Artist, Year số nguyên, Description)
  • 6. Nút bấm "Save Artwork" & SnackBar thông báo thành công
  • 7. Toàn bộ mã nguồn hoàn chỉnh của add_artwork_screen.dart (Bấm copy 1 click)
  • 8. Checklist nghiệm thu chấm điểm Task 5

1. Phân Tích Yêu Cầu Task 5 & Giao Diện Mẫu

Các trường nhập liệu (Fields) bắt buộc
  • Title: Tên tác phẩm (icon: Icons.title)
  • Artist: Tên họa sĩ / nghệ sĩ (icon: Icons.person_outline)
  • Year: Năm sáng tác (icon: Icons.calendar_today_outlined, kiểu số)
  • Category: Thể loại tranh chọn từ Dropdown (ví dụ: Abstract, Modern, Landscape, Portrait...)
  • Description: Mô tả tác phẩm (icon: Icons.subject, nhập nhiều dòng)
Các tiêu chí yêu cầu (Requirements)
  • Validation: Bắt buộc nhập đầy đủ, hiển thị chữ đỏ báo lỗi nếu để trống.
  • Artwork ID must auto-increment: Không nhập ID, SQLite tự sinh.
  • Lấy Foreign Key createdBy: Đọc User ID từ SessionService.getUserId().
  • Save into SQLite: Gọi DatabaseHelper.instance.insertArtwork(newArtwork).
  • Return & Update: Gọi Navigator.pop(context, true) để báo cho Home reload danh sách.
  • SnackBar notification: Hiện thông báo: Artwork added successfully.

2. Khai Báo Form Key, Controllers & Hàm dispose()

Controllers, Category mặc định & Hàm thu hồi bộ nhớ dispose()

Bản chất: 4 trường dạng chữ dùng TextEditingController, riêng trường Category lưu bằng 1 biến chuỗi _selectedCategory với giá trị ban đầu là 'Abstract'.

  final _formKey = GlobalKey();

  final _titleController = TextEditingController();
  final _artistController = TextEditingController();
  final _yearController = TextEditingController();

  // Danh sách thể loại tranh
  final List _categories = ['Abstract', 'Modern', 'Landscape', 'Portrait', 'Still Life'];

  bool _isLoading = false;

  @override
  void dispose() {
    _titleController.dispose();
    _artistController.dispose();
    _yearController.dispose();
    _descriptionController.dispose();
    super.dispose();
  }

3. Widget DropdownButtonFormField Cho Category

Chọn Thể loại từ Dropdown chuẩn Material

Thiết kế: Dùng DropdownButtonFormField<String> để đồng bộ giao diện khung viền OutlineInputBorder giống hệt các ô TextFormField khác.

DropdownButtonFormField(
  value: _selectedCategory,
  decoration: const InputDecoration(
    labelText: 'Category',
    prefixIcon: Icon(Icons.category_outlined),
    border: OutlineInputBorder(),
  ),
  items: _categories.map((String cat) {
    return DropdownMenuItem(
      value: cat,
      child: Text(cat),
    );
  }).toList(),
  onChanged: (val) {
    if (val != null) {
      setState(() => _selectedCategory = val);
    }
  },
)

4. Hàm Xử Lý Lưu Tác Phẩm _handleSaveArtwork()

Quy trình 5 bước Insert vào SQLite & Trả về Home

Nhiệm vụ: Kiểm tra Form → Lấy ID User từ Session → Chuyển Year thành số nguyên → Ghi vào SQLite → Bắn SnackBar → Gọi Navigator.pop(context, true).

  Future _handleSaveArtwork() async {
    // 1. Kiểm tra Validate toàn bộ Form
    if (!_formKey.currentState!.validate()) {
      return;
    }

    setState(() => _isLoading = true);

    try {
      // 2. Lấy ID của User đang đăng nhập từ Session làm khóa ngoại createdBy
      final currentUserId = await SessionService.getUserId() ?? 1;

      // 3. Đóng gói đối tượng ArtworkModel
      final newArtwork = ArtworkModel(
        title: _titleController.text.trim(),
        artist: _artistController.text.trim(),
        year: int.parse(_yearController.text.trim()),
        category: _selectedCategory,
        description: _descriptionController.text.trim(),
        createdBy: currentUserId,
      );

      // 4. Lưu vào SQLite
      await DatabaseHelper.instance.insertArtwork(newArtwork);

      if (!mounted) return;
      // 5. Hiển thị SnackBar thông báo thành công theo đúng yêu cầu đề bài
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Artwork added successfully'),
          backgroundColor: Colors.black87,
        ),
      );

      // Quay về Home Screen và gửi cờ `true` để Home reload danh sách
      Navigator.pop(context, true);
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

5. Chi Tiết Các Ô Nhập Liệu Khác (Title, Artist, Year, Description)

Các ô TextFormField & Validator kiểm tra số nguyên

Lưu ý: Ô Year phải đặt keyboardType: TextInputType.number và kiểm tra int.tryParse() để người dùng không gõ chữ cái vào năm.

// 1. Ô Title
TextFormField(
  controller: _titleController,
  decoration: const InputDecoration(
    labelText: 'Title',
    prefixIcon: Icon(Icons.title),
    border: OutlineInputBorder(),
  ),
  validator: (val) => (val == null || val.trim().isEmpty) ? 'Title is required' : null,
),
const SizedBox(height: 16),

// 2. Ô Artist
TextFormField(
  controller: _artistController,
  decoration: const InputDecoration(
    labelText: 'Artist',
    prefixIcon: Icon(Icons.person_outline),
    border: OutlineInputBorder(),
  ),
  validator: (val) => (val == null || val.trim().isEmpty) ? 'Artist is required' : null,
),
const SizedBox(height: 16),

// 3. Ô Year (chỉ cho phép nhập số nguyên)
TextFormField(
  controller: _yearController,
  keyboardType: TextInputType.number,
  decoration: const InputDecoration(
    labelText: 'Year',
    prefixIcon: Icon(Icons.calendar_today_outlined),
    border: OutlineInputBorder(),
  ),
  validator: (val) {
    if (val == null || val.trim().isEmpty) return 'Year is required';
    final parsed = int.tryParse(val.trim());
    if (parsed == null || parsed <= 0) return 'Please enter a valid year';
    return null;
  },
),
const SizedBox(height: 16),

// 4. Ô Description (Cho phép xuống hàng nhiều dòng)
TextFormField(
  controller: _descriptionController,
  maxLines: 3,
  decoration: const InputDecoration(
    labelText: 'Description',
    prefixIcon: Icon(Icons.subject),
    border: OutlineInputBorder(),
    alignLabelWithHint: true,
  ),
  validator: (val) => (val == null || val.trim().isEmpty) ? 'Description is required' : null,
)

7. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của add_artwork_screen.dart

Tạo file: lib/screens/add_artwork_screen.dart và dán toàn bộ mã nguồn bên dưới vào:

// lib/screens/add_artwork_screen.dart
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../models/artwork_model.dart';
import '../services/session_service.dart';

class AddArtworkScreen extends StatefulWidget {
  const AddArtworkScreen({super.key});

  @override
  State createState() => _AddArtworkScreenState();
}

class _AddArtworkScreenState extends State {
  final _formKey = GlobalKey();

  final _titleController = TextEditingController();
  final _artistController = TextEditingController();
  final _yearController = TextEditingController();
  final _descriptionController = TextEditingController();

  final List _categories = ['Abstract', 'Modern', 'Landscape', 'Portrait', 'Still Life'];
  String _selectedCategory = 'Abstract';

  bool _isLoading = false;

  @override
  void dispose() {
    _titleController.dispose();
    _artistController.dispose();
    _yearController.dispose();
    _descriptionController.dispose();
    super.dispose();
  }

  Future _handleSaveArtwork() async {
    if (!_formKey.currentState!.validate()) {
      return;
    }

    setState(() => _isLoading = true);

    try {
      final currentUserId = await SessionService.getUserId() ?? 1;

      final newArtwork = ArtworkModel(
        title: _titleController.text.trim(),
        artist: _artistController.text.trim(),
        year: int.parse(_yearController.text.trim()),
        category: _selectedCategory,
        description: _descriptionController.text.trim(),
        createdBy: currentUserId,
      );

      await DatabaseHelper.instance.insertArtwork(newArtwork);

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Artwork added successfully'),
          backgroundColor: Colors.black87,
        ),
      );

      Navigator.pop(context, true);
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.white,
      appBar: AppBar(
        title: const Text('Add Artwork', style: TextStyle(fontWeight: FontWeight.bold, fontSize: 18)),
        backgroundColor: Colors.white,
        foregroundColor: Colors.black87,
        elevation: 0.5,
      ),
      body: SafeArea(
        child: SingleChildScrollView(
          padding: const EdgeInsets.symmetric(horizontal: 24.0, vertical: 16.0),
          child: Form(
            key: _formKey,
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.stretch,
              children: [
                const Text(
                  'New Artwork',
                  style: TextStyle(fontSize: 22, fontWeight: FontWeight.bold, color: Colors.black87),
                ),
                const SizedBox(height: 24),

                // 1. Ô Title
                TextFormField(
                  controller: _titleController,
                  decoration: const InputDecoration(
                    labelText: 'Title',
                    prefixIcon: Icon(Icons.title),
                    border: OutlineInputBorder(),
                  ),
                  validator: (val) => (val == null || val.trim().isEmpty) ? 'Title is required' : null,
                ),
                const SizedBox(height: 16),

                // 2. Ô Artist
                TextFormField(
                  controller: _artistController,
                  decoration: const InputDecoration(
                    labelText: 'Artist',
                    prefixIcon: Icon(Icons.person_outline),
                    border: OutlineInputBorder(),
                  ),
                  validator: (val) => (val == null || val.trim().isEmpty) ? 'Artist is required' : null,
                ),
                const SizedBox(height: 16),

                // 3. Ô Year
                TextFormField(
                  controller: _yearController,
                  keyboardType: TextInputType.number,
                  decoration: const InputDecoration(
                    labelText: 'Year',
                    prefixIcon: Icon(Icons.calendar_today_outlined),
                    border: OutlineInputBorder(),
                  ),
                  validator: (val) {
                    if (val == null || val.trim().isEmpty) return 'Year is required';
                    final parsed = int.tryParse(val.trim());
                    if (parsed == null || parsed <= 0) return 'Please enter a valid year';
                    return null;
                  },
                ),
                const SizedBox(height: 16),

                // 4. Ô Dropdown Category
                DropdownButtonFormField(
                  value: _selectedCategory,
                  decoration: const InputDecoration(
                    labelText: 'Category',
                    prefixIcon: Icon(Icons.category_outlined),
                    border: OutlineInputBorder(),
                  ),
                  items: _categories.map((String cat) {
                    return DropdownMenuItem(
                      value: cat,
                      child: Text(cat),
                    );
                  }).toList(),
                  onChanged: (val) {
                    if (val != null) {
                      setState(() => _selectedCategory = val);
                    }
                  },
                ),
                const SizedBox(height: 16),

                // 5. Ô Description
                TextFormField(
                  controller: _descriptionController,
                  maxLines: 3,
                  decoration: const InputDecoration(
                    labelText: 'Description',
                    prefixIcon: Icon(Icons.subject),
                    border: OutlineInputBorder(),
                    alignLabelWithHint: true,
                  ),
                  validator: (val) => (val == null || val.trim().isEmpty) ? 'Description is required' : null,
                ),
                const SizedBox(height: 28),

                // 6. Nút Save Artwork
                SizedBox(
                  height: 50,
                  child: ElevatedButton(
                    onPressed: _isLoading ? null : _handleSaveArtwork,
                    style: ElevatedButton.styleFrom(
                      backgroundColor: const Color(0xFF00695C),
                      foregroundColor: Colors.white,
                      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),
                    ),
                    child: _isLoading
                        ? const SizedBox(width: 24, height: 24, child: CircularProgressIndicator(color: Colors.white, strokeWidth: 2.5))
                        : const Text('Save Artwork', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                  ),
                ),
              ],
            ),
          ),
        ),
      ),
    );
  }
}
