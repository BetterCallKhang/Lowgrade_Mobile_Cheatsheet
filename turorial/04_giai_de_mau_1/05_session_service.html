Bước 5: Xây Dựng SessionService Với SharedPreferences (Task 3: Session Management)

Đề bài thi yêu cầu ở Task 3 — Session Management: "The application must remember login status. When the application starts: Check stored session information. If a session exists → Open Home Screen. If no session exists → Open Login Screen."

1. Phân Tích Yêu Cầu Task 3: Session Là Gì? Cần Lưu Những Gì?

Khái niệm Session trong App Mobile

Session (Phiên làm việc) là cơ chế ghi nhớ trạng thái người dùng đã đăng nhập vào thiết bị, để lần sau khi người dùng tắt app đi mở lại (hoặc reload trang), app tự động nhận diện tài khoản và mở thẳng vào màn hình Home mà không bắt đăng nhập lại từ đầu.

Khóa (Key) Kiểu dữ liệu Giá trị mẫu Mục đích sử dụng trong đề thi
is_logged_in bool true / false Cờ kiểm tra ở main.dart: nếu true thì mở Home, ngược lại mở Login.
user_id int 1 Lưu ID người dùng để gán vào trường createdBy khi thêm mới tác phẩm (Task 5).
username String "admin" Hiển thị lời chào trên Banner Home Screen: "Welcome testuser123" (Task 4).

2. Khởi Tạo Class SessionService & Bộ Keys Hằng Số

🔷 Cấu trúc Class & Định nghĩa Keys hằng số

Mục đích: Định nghĩa các chuỗi key thành biến static const để khi gọi không bị gõ nhầm chính tả. Mọi hàm đều là static giúp gọi trực tiếp ở bất kỳ đâu dạng SessionService.tênHàm() mà không cần khởi tạo đối tượng rườm rà.

// lib/services/session_service.dart
import 'package:shared_preferences/shared_preferences.dart';

class SessionService {
  // Bộ keys hằng số tránh gõ sai chính tả
  static const String _keyIsLoggedIn = 'is_logged_in';
  static const String _keyUserId = 'user_id';
  static const String _keyUsername = 'username';
}

3. Hàm Lưu Phiên Đăng Nhập saveUserSession()

🟢 Hàm lưu phiên khi User đăng nhập thành công

Nhiệm vụ: Nhận vào userId và username từ User vừa đăng nhập, ghi đồng thời 3 thông tin vào SharedPreferences: đặt is_logged_in = true, lưu userId và username.

  // Lưu thông tin khi đăng nhập thành công (Gọi tại LoginScreen)
  static Future saveUserSession(int userId, String username) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_keyIsLoggedIn, true);
    await prefs.setInt(_keyUserId, userId);
    await prefs.setString(_keyUsername, username);
  }

4. Các Hàm Đọc Dữ Liệu Phiên Đăng Nhập

🟣 Bộ 3 hàm lấy dữ liệu phiên ra sử dụng

Nhiệm vụ:

  • isLoggedIn() → Trả về true/false (dùng tại main.dart để phân luồng).
  • getUserId() → Trả về ID của user (dùng gán cho createdBy khi thêm tác phẩm mới).
  • getUsername() → Trả về tên tài khoản (dùng hiển thị lời chào trên Home).
  // 1. Kiểm tra xem người dùng đã đăng nhập chưa
  static Future isLoggedIn() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_keyIsLoggedIn) ?? false;
  }

  // 2. Lấy ID của người dùng hiện tại (trả về null nếu chưa đăng nhập)
  static Future getUserId() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getInt(_keyUserId);
  }

  // 3. Lấy Username của người dùng hiện tại
  static Future getUsername() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(_keyUsername);
  }

5. Hàm Đăng Xuất & Xóa Phiên clearSession()

🔴 Hàm xóa sạch phiên khi Logout

Nhiệm vụ: Khi người dùng bấm nút Đăng xuất trên thanh AppBar hoặc Drawer của màn hình Home, hàm này sẽ xoá sạch bộ nhớ SharedPreferences và đưa người dùng quay lại màn hình Login.

  // Xóa toàn bộ phiên đăng nhập khi người dùng bấm Đăng xuất (Logout)
  static Future clearSession() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_keyIsLoggedIn);
    await prefs.remove(_keyUserId);
    await prefs.remove(_keyUsername);
    // Hoặc có thể dùng: await prefs.clear();
  }

6. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của session_service.dart

Tạo file: lib/services/session_service.dart và dán toàn bộ code bên dưới vào:

// lib/services/session_service.dart
import 'package:shared_preferences/shared_preferences.dart';

class SessionService {
  // Bộ khóa định danh dữ liệu
  static const String _keyIsLoggedIn = 'is_logged_in';
  static const String _keyUserId = 'user_id';
  static const String _keyUsername = 'username';

  // 1. Lưu phiên khi đăng nhập thành công
  static Future saveUserSession(int userId, String username) async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.setBool(_keyIsLoggedIn, true);
    await prefs.setInt(_keyUserId, userId);
    await prefs.setString(_keyUsername, username);
  }

  // 2. Kiểm tra trạng thái đã đăng nhập hay chưa
  static Future isLoggedIn() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getBool(_keyIsLoggedIn) ?? false;
  }

  // 3. Lấy ID của user đang đăng nhập
  static Future getUserId() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getInt(_keyUserId);
  }

  // 4. Lấy Username của user đang đăng nhập
  static Future getUsername() async {
    final prefs = await SharedPreferences.getInstance();
    return prefs.getString(_keyUsername);
  }

  // 5. Đăng xuất: Xóa sạch phiên làm việc
  static Future clearSession() async {
    final prefs = await SharedPreferences.getInstance();
    await prefs.remove(_keyIsLoggedIn);
    await prefs.remove(_keyUserId);
    await prefs.remove(_keyUsername);
  }
}
