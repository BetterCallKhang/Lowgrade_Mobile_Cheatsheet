Bước 9: Xây Dựng Màn Hình Chi Tiết Tác Phẩm (Task 6: Artwork Detail Screen)

Đề bài thi yêu cầu ở Task 6 — Artwork Detail: Khi người dùng chạm vào một tác phẩm bất kỳ từ danh sách ở Home Screen, điều hướng sang Artwork Detail Screen để hiển thị toàn bộ thông tin chi tiết: Title, Artist, Year, Category, Description. Màn hình phải có nút Back trên AppBar để người dùng dễ dàng quay trở lại Home Screen.

Tài liệu này hướng dẫn kỹ thuật truyền tham số đối tượng (Passing Object via Constructor) & cách dựng giao diện thẻ thông tin (Card Layout) thanh lịch, chuẩn xác theo hình chụp đề thi.

📌 Nội dung bài học gồm 6 phần chi tiết:
  • 1. Phân tích yêu cầu Task 6 & Giao diện mẫu theo đề thi
  • 2. Kỹ thuật truyền nhận dữ liệu qua Constructor (Object Passing)
  • 3. Widget hiển thị từng hàng thông tin nhãn - giá trị (Label - Value Row)
  • 4. AppBar với nút Back chuẩn Android/iOS
  • 5. Toàn bộ mã nguồn hoàn chỉnh của artwork_detail_screen.dart (Bấm copy 1 click)
  • 6. Checklist nghiệm thu chấm điểm Task 6

1. Phân Tích Yêu Cầu Task 6 & Giao Diện Mẫu

Các thông tin hiển thị (Display Information)
  • 🏷️ Title: Tiêu đề tranh to, in đậm (ví dụ: The Persistence of Memory).
  • 👤 Artist: Tên nghệ sĩ (ví dụ: Salvador Dali).
  • 📅 Year: Năm sáng tác (ví dụ: 1931).
  • 🎨 Category: Thể loại (ví dụ: Landscape hoặc Abstract).
  • 📄 Description: Đoạn văn mô tả chi tiết tác phẩm bên dưới.
Yêu cầu điều hướng (Requirements)
  • ✅ Trigger từ Home: Người dùng chạm vào item trong ListView.builder thì mở màn hình này.
  • ✅ Back button: Màn hình bắt buộc phải có nút Back (mũi tên quay lại trên AppBar) để trở về Home Screen.
  • ✅ StatelessWidget: Màn hình này chỉ đọc và hiển thị dữ liệu tĩnh đã truyền sang, không cần gọi SQLite hay đổi state nên viết dạng StatelessWidget là tối ưu hiệu năng nhất!

3. Widget Hiển Thị Từng Dòng Thông Tin (Label & Value)

🟣 Hàm phụ tái sử dụng _buildInfoRow()

Mục đích: Dùng chung cho 3 dòng Artist, Year, Category. Cột nhãn bên trái màu xám nhạt, cột giá trị bên phải màu đen đậm, giúp giao diện gọn gàng và không lặp lại code.

Widget _buildInfoRow(String label, String value) {
  return Padding(
    padding: const EdgeInsets.only(bottom: 12.0),
    child: Row(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        SizedBox(
          width: 90,
          child: Text(
            label,
            style: const TextStyle(color: Colors.grey, fontSize: 15, fontWeight: FontWeight.w500),
          ),
        ),
        Expanded(
          child: Text(
            value,
            style: const TextStyle(fontSize: 15, fontWeight: FontWeight.w600, color: Colors.black87),
          ),
        ),
      ],
    ),
  );
}

4. AppBar Chuẩn Kèm Nút Back

🟢 AppBar với nút Back tự động

Bản chất: Trong Flutter, khi dùng Navigator.push() từ Home sang Detail, Scaffold có AppBar sẽ tự động tạo nút mũi tên Back (←) bên trái thanh tiêu đề. Bấm vào nút này sẽ tự động gọi Navigator.pop(context) quay lại Home.

AppBar(
  title: const Text('Artwork Detail', style: TextStyle(fontWeight: FontWeight.bold, fontSize: 18)),
  backgroundColor: Colors.white,
  foregroundColor: Colors.black87,
  elevation: 0.5,
  leading: IconButton(
    icon: const Icon(Icons.arrow_back),
    onPressed: () => Navigator.pop(context),
  ),
)

5. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của artwork_detail_screen.dart

Tạo file: lib/screens/artwork_detail_screen.dart và dán toàn bộ mã nguồn bên dưới vào:

// lib/screens/artwork_detail_screen.dart
import 'package:flutter/material.dart';
import '../models/artwork_model.dart';

class ArtworkDetailScreen extends StatelessWidget {
  final ArtworkModel artwork;

  const ArtworkDetailScreen({super.key, required this.artwork});

  // Widget hiển thị 1 dòng thông tin dạng Nhãn : Giá trị
  Widget _buildInfoRow(String label, String value) {
    return Padding(
      padding: const EdgeInsets.only(bottom: 14.0),
      child: Row(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          SizedBox(
            width: 90,
            child: Text(
              label,
              style: const TextStyle(color: Colors.grey, fontSize: 15, fontWeight: FontWeight.w500),
            ),
          ),
          Expanded(
            child: Text(
              value,
              style: const TextStyle(fontSize: 15, fontWeight: FontWeight.w600, color: Colors.black87),
            ),
          ),
        ],
      ),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFFF8F9FA),
      appBar: AppBar(
        title: const Text('Artwork Detail', style: TextStyle(fontWeight: FontWeight.bold, fontSize: 18)),
        backgroundColor: Colors.white,
        foregroundColor: Colors.black87,
        elevation: 0.5,
        leading: IconButton(
          icon: const Icon(Icons.arrow_back),
          onPressed: () => Navigator.pop(context),
        ),
      ),
      body: SafeArea(
        child: SingleChildScrollView(
          padding: const EdgeInsets.all(16.0),
          child: Card(
            elevation: 1,
            shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(16)),
            color: Colors.white,
            child: Padding(
              padding: const EdgeInsets.all(20.0),
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.start,
                children: [
                  // 1. Tiêu đề tác phẩm nổi bật
                  Text(
                    artwork.title,
                    style: const TextStyle(
                      fontSize: 24,
                      fontWeight: FontWeight.bold,
                      color: Colors.black87,
                    ),
                  ),
                  const SizedBox(height: 20),

                  // 2. Các thông tin chi tiết
                  _buildInfoRow('Artist:', artwork.artist),
                  _buildInfoRow('Year:', artwork.year.toString()),
                  _buildInfoRow('Category:', artwork.category),

                  const SizedBox(height: 8),
                  const Divider(color: Color(0xFFEEEEEE), thickness: 1),
                  const SizedBox(height: 12),

                  // 3. Phần Mô tả tác phẩm (Description)
                  const Text(
                    'Description',
                    style: TextStyle(
                      fontSize: 16,
                      fontWeight: FontWeight.bold,
                      color: Colors.black87,
                    ),
                  ),
                  const SizedBox(height: 8),
                  Text(
                    artwork.description,
                    style: const TextStyle(
                      fontSize: 14.5,
                      color: Colors.black87,
                      height: 1.5,
                    ),
                  ),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}
