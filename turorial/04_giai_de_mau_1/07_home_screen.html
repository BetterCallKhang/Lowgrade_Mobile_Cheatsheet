Bước 7: Xây Dựng Màn Hình Danh Sách Chính & Xóa (Task 4: Home Screen & Task 7: Delete Artwork)

Theo đề thi, Home Screen là trái tim của ứng dụng: hiển thị Banner tài nguyên kèm lời chào Session ("Welcome <username>"), tải danh sách tác phẩm từ SQLite bằng ListView.builder (Title, Artist, Year), xử lý trạng thái khi danh sách trống ("No artworks found"), bấm vào từng item để xem chi tiết (Task 6), có nút + Add Artwork để thêm mới (Task 5), và mỗi item có nút Delete kèm Hộp thoại xác nhận (Confirmation Dialog) thông báo SnackBar (Task 7).

Tất cả các hàm và khối giao diện được tách thành từng mục riêng biệt với viền màu sắc phân biệt để bạn dễ theo dõi và hiểu tường tận.

Nội dung bài học gồm 9 phần chi tiết:
  • 1. Phân tích yêu cầu Task 4 (Home List) & Task 7 (Delete Artwork)
  • 2. Khai báo State & Hàm tải dữ liệu _loadData() từ SQLite và Session
  • 3. Widget Banner hình ảnh & Hiển thị lời chào Username người dùng
  • 4. Xử lý trạng thái Danh sách rỗng ("No artworks found")
  • 5. Dựng danh sách tác phẩm với ListView.builder & Thẻ Card/ListTile
  • 6. Hàm xác nhận và Xóa tác phẩm _confirmDelete() (Task 7)
  • 7. Nút bấm nổi "+ Add Artwork" & Xử lý Reload dữ liệu khi quay về
  • 8. Toàn bộ mã nguồn hoàn chỉnh của home_screen.dart (Bấm copy 1 click)
  • 9. Checklist nghiệm thu chấm điểm Task 4 & Task 7

1. Phân Tích Yêu Cầu Đề Bài (Task 4 & Task 7)

Task 4 — Home Screen (Artwork List)
  • Header Banner / Logo: Hiển thị ảnh banner đề thi cấp kèm lời chào: "Welcome <username>" lấy từ Session.
  • Load Artwork Data: Đọc toàn bộ danh sách từ SQLite.
  • ListView.builder: Hiển thị mỗi bức tranh gồm: Title, Artist, Year.
  • Trường hợp rỗng: Nếu chưa có tranh thì hiện chữ "No artworks found".
  • Tương tác: Chạm vào item để mở Artwork Detail Screen; bấm nút nổi phía dưới để mở Add Artwork Screen.
Task 7 — Delete Artwork
  • Nút Delete: Đặt icon thùng rác bên phải mỗi item trong danh sách.
  • Show Confirmation Dialog: Tiêu đề "Delete Artwork", nội dung: "Are you sure you want to delete this artwork?", có 2 nút: Cancel và Delete.
  • Khi xác nhận xóa:
    • Xóa tranh khỏi CSDL SQLite qua DatabaseHelper.instance.deleteArtwork(id).
    • Cập nhật lại danh sách trên Home tức thì.
    • Bắn thông báo: Artwork deleted successfully bằng SnackBar.

2. Khai Báo State & Hàm Tải Dữ Liệu _loadData()

Khai báo biến State & Hàm tải dữ liệu ban đầu

Nhiệm vụ: Trong initState(), gọi hàm tải đồng thời 2 nguồn: (1) Tên người dùng từ SessionService.getUsername() và (2) Danh sách tác phẩm từ DatabaseHelper.instance.getAllArtworks().

  List _artworks = [];
  String _currentUsername = 'User';
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _loadData();
  }

  // Hàm tải dữ liệu từ CSDL và Session
  Future _loadData() async {
    setState(() => _isLoading = true);
    try {
      // 1. Lấy username từ Session để hiển thị lên Banner
      final username = await SessionService.getUsername();
      // 2. Lấy danh sách tranh từ SQLite
      final list = await DatabaseHelper.instance.getAllArtworks();

      if (mounted) {
        setState(() {
          _currentUsername = username ?? 'User';
          _artworks = list;
          _isLoading = false;
        });
      }
    } catch (e) {
      if (mounted) setState(() => _isLoading = false);
    }
  }

5. Dựng Danh Sách Tác Phẩm Bằng ListView.builder

Danh sách thẻ Card bo góc & Sự kiện chạm xem Chi tiết

Bản chất: Mỗi item là 1 Card bo tròn nhẹ màu trắng, bên trong có ListTile: icon bên trái, tiêu đề tranh Title, nghệ sĩ Artist kèm năm Year (ví dụ: Salvador Dali - 1931). Bấm vào item thì mở ArtworkDetailScreen (Task 6).

Widget _buildArtworkList() {
  return ListView.builder(
    shrinkWrap: true,
    physics: const NeverScrollableScrollPhysics(),
    padding: const EdgeInsets.symmetric(horizontal: 16),
    itemCount: _artworks.length,
    itemBuilder: (context, index) {
      final artwork = _artworks[index];
      return Card(
        margin: const EdgeInsets.only(bottom: 12),
        elevation: 1,
        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
        child: ListTile(
          leading: CircleAvatar(
            backgroundColor: const Color(0xFFE0F2F1),
            child: const Icon(Icons.palette_outlined, color: Color(0xFF00695C)),
          ),
          title: Text(
            artwork.title,
            style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
          ),
          subtitle: Text(
            '${artwork.artist} - ${artwork.year}',
            style: const TextStyle(color: Colors.grey),
          ),
          trailing: IconButton(
            icon: const Icon(Icons.delete_outline, color: Colors.grey),
            onPressed: () => _confirmDelete(artwork),
          ),
          onTap: () {
            // Task 6: Chạm vào item để mở xem chi tiết
            Navigator.push(
              context,
              MaterialPageRoute(
                builder: (context) => ArtworkDetailScreen(artwork: artwork),
              ),
            );
          },
        ),
      );
    },
  );
}

6. Hàm Xác Nhận & Xóa Tác Phẩm _confirmDelete() (Task 7)

Hộp thoại xác nhận xóa & Bắn SnackBar thông báo (Task 7)

Yêu cầu đề thi: Khi bấm vào icon thùng rác, hiển thị AlertDialog với câu hỏi "Are you sure you want to delete this artwork?". Nếu chọn Delete thì xóa trong SQLite, reload lại danh sách và hiện SnackBar Artwork deleted successfully.

  Future _confirmDelete(ArtworkModel artwork) async {
    final bool? confirm = await showDialog(
      context: context,
      builder: (BuildContext ctx) {
        return AlertDialog(
          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(16)),
          title: const Text('Delete Artwork', style: TextStyle(fontWeight: FontWeight.bold)),
          content: const Text('Are you sure you want to delete this artwork?'),
          actions: [
            TextButton(
              onPressed: () => Navigator.of(ctx).pop(false),
              child: const Text('Cancel', style: TextStyle(color: Colors.grey)),
            ),
            ElevatedButton(
              onPressed: () => Navigator.of(ctx).pop(true),
              style: ElevatedButton.styleFrom(
                backgroundColor: const Color(0xFF00695C),
                foregroundColor: Colors.white,
              ),
              child: const Text('Delete'),
            ),
          ],
        );
      },
    );

    // Nếu người dùng đồng ý xóa
    if (confirm == true && artwork.id != null) {
      await DatabaseHelper.instance.deleteArtwork(artwork.id!);

      // Tải lại danh sách sau khi xóa
      await _loadData();

      if (!mounted) return;
      // Bắn SnackBar theo đúng yêu cầu đề
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Artwork deleted successfully'),
          backgroundColor: Colors.black87,
        ),
      );
    }
  }

7. Nút Bấm "+ Add Artwork" & Xử Lý Reload Khi Quay Về

Nút thêm mới có cơ chế chờ Await tự động cập nhật

Mẹo quan trọng: Dùng final result = await Navigator.push(...). Khi màn hình Thêm mới hoàn tất và trả về true, hàm sẽ lập tức gọi lại _loadData() để hiển thị bức tranh mới vừa thêm ngay lập tức!

Widget _buildAddButton() {
  return Padding(
    padding: const EdgeInsets.all(16.0),
    child: SizedBox(
      height: 48,
      child: ElevatedButton.icon(
        onPressed: () async {
          // Task 5: Mở màn hình Thêm tác phẩm
          final result = await Navigator.push(
            context,
            MaterialPageRoute(builder: (context) => const AddArtworkScreen()),
          );
          // Nếu thêm thành công thì reload lại danh sách
          if (result == true) {
            _loadData();
          }
        },
        icon: const Icon(Icons.add),
        label: const Text('Add Artwork', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
        style: ElevatedButton.styleFrom(
          backgroundColor: const Color(0xFF80CBC4), // Màu xanh teal nhạt theo thiết kế mock
          foregroundColor: const Color(0xFF004D40),
          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
        ),
      ),
    ),
  );
}

8. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của home_screen.dart

Tạo file: lib/screens/home_screen.dart và dán toàn bộ mã nguồn bên dưới vào:

// lib/screens/home_screen.dart
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../models/artwork_model.dart';
import '../services/session_service.dart';
import 'add_artwork_screen.dart';
import 'artwork_detail_screen.dart';
import 'login_screen.dart';

class HomeScreen extends StatefulWidget {
  const HomeScreen({super.key});

  @override
  State createState() => _HomeScreenState();
}

class _HomeScreenState extends State {
  List _artworks = [];
  String _currentUsername = 'User';
  bool _isLoading = true;

  @override
  void initState() {
    super.initState();
    _loadData();
  }

  // Tải danh sách từ SQLite & Session username
  Future _loadData() async {
    setState(() => _isLoading = true);
    try {
      final username = await SessionService.getUsername();
      final list = await DatabaseHelper.instance.getAllArtworks();
      if (mounted) {
        setState(() {
          _currentUsername = username ?? 'User';
          _artworks = list;
          _isLoading = false;
        });
      }
    } catch (e) {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  // Task 7: Hộp thoại xác nhận & Xóa tác phẩm
  Future _confirmDelete(ArtworkModel artwork) async {
    final bool? confirm = await showDialog(
      context: context,
      builder: (BuildContext ctx) {
        return AlertDialog(
          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(16)),
          title: const Text('Delete Artwork', style: TextStyle(fontWeight: FontWeight.bold)),
          content: const Text('Are you sure you want to delete this artwork?'),
          actions: [
            TextButton(
              onPressed: () => Navigator.of(ctx).pop(false),
              child: const Text('Cancel', style: TextStyle(color: Colors.grey)),
            ),
            ElevatedButton(
              onPressed: () => Navigator.of(ctx).pop(true),
              style: ElevatedButton.styleFrom(
                backgroundColor: const Color(0xFF00695C),
                foregroundColor: Colors.white,
              ),
              child: const Text('Delete'),
            ),
          ],
        );
      },
    );

    if (confirm == true && artwork.id != null) {
      await DatabaseHelper.instance.deleteArtwork(artwork.id!);
      await _loadData();

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Artwork deleted successfully'),
          backgroundColor: Colors.black87,
        ),
      );
    }
  }

  // Xử lý Đăng xuất (Logout)
  Future _handleLogout() async {
    await SessionService.clearSession();
    if (!mounted) return;
    Navigator.pushReplacement(
      context,
      MaterialPageRoute(builder: (context) => const LoginScreen()),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: const Color(0xFFF8F9FA),
      appBar: AppBar(
        title: const Text('Home - Artwork List', style: TextStyle(fontSize: 18, fontWeight: FontWeight.bold)),
        backgroundColor: Colors.white,
        foregroundColor: Colors.black87,
        elevation: 0.5,
        actions: [
          IconButton(
            icon: const Icon(Icons.logout, color: Colors.black54),
            tooltip: 'Logout',
            onPressed: _handleLogout,
          ),
        ],
      ),
      body: _isLoading
          ? const Center(child: CircularProgressIndicator(color: Color(0xFF00695C)))
          : SingleChildScrollView(
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.stretch,
                children: [
                  // 1. Header Banner kèm Lời chào Session
                  Container(
                    height: 140,
                    width: double.infinity,
                    margin: const EdgeInsets.all(16.0),
                    decoration: BoxDecoration(
                      borderRadius: BorderRadius.circular(16),
                      image: const DecorationImage(
                        image: AssetImage('assets/images/banner.jpg'),
                        fit: BoxFit.cover,
                      ),
                    ),
                    child: Container(
                      decoration: BoxDecoration(
                        borderRadius: BorderRadius.circular(16),
                        gradient: LinearGradient(
                          colors: [Colors.black.withOpacity(0.65), Colors.transparent],
                          begin: Alignment.bottomCenter,
                          end: Alignment.topCenter,
                        ),
                      ),
                      padding: const EdgeInsets.all(16.0),
                      alignment: Alignment.bottomLeft,
                      child: Row(
                        children: [
                          const Icon(Icons.home, color: Colors.white, size: 20),
                          const SizedBox(width: 8),
                          Text(
                            'Welcome $_currentUsername',
                            style: const TextStyle(
                              color: Colors.white,
                              fontSize: 16,
                              fontWeight: FontWeight.bold,
                              shadows: [Shadow(color: Colors.black54, blurRadius: 4)],
                            ),
                          ),
                        ],
                      ),
                    ),
                  ),

                  // 2. Danh sách tranh hoặc Trạng thái rỗng
                  if (_artworks.isEmpty)
                    const Padding(
                      padding: EdgeInsets.symmetric(vertical: 40),
                      child: Center(
                        child: Text(
                          'No artworks found',
                          style: TextStyle(color: Colors.grey, fontSize: 16),
                        ),
                      ),
                    )
                  else
                    ListView.builder(
                      shrinkWrap: true,
                      physics: const NeverScrollableScrollPhysics(),
                      padding: const EdgeInsets.symmetric(horizontal: 16),
                      itemCount: _artworks.length,
                      itemBuilder: (context, index) {
                        final artwork = _artworks[index];
                        return Card(
                          margin: const EdgeInsets.only(bottom: 12),
                          elevation: 1,
                          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                          child: ListTile(
                            leading: const CircleAvatar(
                              backgroundColor: Color(0xFFE0F2F1),
                              child: Icon(Icons.palette_outlined, color: Color(0xFF00695C)),
                            ),
                            title: Text(
                              artwork.title,
                              style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
                            ),
                            subtitle: Text(
                              '${artwork.artist} - ${artwork.year}',
                              style: const TextStyle(color: Colors.grey),
                            ),
                            trailing: IconButton(
                              icon: const Icon(Icons.delete_outline, color: Colors.grey),
                              onPressed: () => _confirmDelete(artwork),
                            ),
                            onTap: () {
                              // Task 6: Mở màn hình xem chi tiết
                              Navigator.push(
                                context,
                                MaterialPageRoute(
                                  builder: (context) => ArtworkDetailScreen(artwork: artwork),
                                ),
                              );
                            },
                          ),
                        );
                      },
                    ),

                  // 3. Nút bấm nổi "+ Add Artwork"
                  Padding(
                    padding: const EdgeInsets.all(16.0),
                    child: SizedBox(
                      height: 48,
                      child: ElevatedButton.icon(
                        onPressed: () async {
                          final result = await Navigator.push(
                            context,
                            MaterialPageRoute(builder: (context) => const AddArtworkScreen()),
                          );
                          if (result == true) {
                            _loadData();
                          }
                        },
                        icon: const Icon(Icons.add),
                        label: const Text('Add Artwork', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                        style: ElevatedButton.styleFrom(
                          backgroundColor: const Color(0xFF80CBC4),
                          foregroundColor: const Color(0xFF004D40),
                          shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                        ),
                      ),
                    ),
                  ),
                ],
              ),
            ),
    );
  }
}
