Bước 10: Hoàn Thiện File Khởi Chạy lib/main.dart (Cổng Phân Luồng Session & Nộp Bài Thi)

Đây là mảnh ghép cuối cùng để kết nối toàn bộ hệ thống lại với nhau. File main.dart sẽ hiện thực hóa phần còn lại của Task 3 — Session Management: "When the application starts: Check stored session information. If a session exists → Open Home Screen. If no session exists → Open Login Screen."

Đồng thời hướng dẫn quy trình kiểm thử tổng thể từ đầu đến cuối và lệnh nén nộp bài thi flutter clean chuẩn xác không bị trừ điểm.

Nội dung bài học gồm 6 phần chi tiết:
  • 1. Cơ chế hoạt động của Cổng kiểm tra Session (Session Gatekeeper)
  • 2. Khởi tạo WidgetsFlutterBinding.ensureInitialized() bắt buộc
  • 3. Cấu hình Theme & Màu sắc chủ đạo ColorScheme
  • 4. Toàn bộ mã nguồn hoàn chỉnh của lib/main.dart (Bấm copy 1 click)
  • 5. Kịch bản Test toàn diện 7 Tasks trước khi nộp bài thi
  • 6. Lệnh dọn dẹp flutter clean & Nén nộp bài (Tránh bị 0 điểm)

1. Cơ Chế Hoạt Động Của Cổng Kiểm Tra Session

Nguyên lý phân luồng màn hình mở đầu (Home vs Login)

Khi người dùng bấm mở App, trước khi vẽ màn hình đầu tiên lên thiết bị, hàm main() sẽ chạy hàm bất đồng bộ await SessionService.isLoggedIn():

  • Nếu trả về true (đã đăng nhập lần trước đó) → Thuộc tính home: của MaterialApp được gán là HomeScreen().
  • Nếu trả về false (chưa đăng nhập hoặc đã logout) → Thuộc tính home: của MaterialApp được gán là LoginScreen().

2. Lệnh WidgetsFlutterBinding.ensureInitialized() Bắt Buộc

LƯU Ý SỐNG CÒN:

Nếu bạn gọi bất kỳ hàm async nào (như SharedPreferences.getInstance() hoặc mở CSDL) bên trong hàm main() trước khi gọi runApp(), bạn bắt buộc phải đặt dòng lệnh:

WidgetsFlutterBinding.ensureInitialized();

ở ngay dòng đầu tiên của hàm main(). Nếu thiếu dòng này, Flutter SDK sẽ báo lỗi crash ngay khi vừa khởi động app!

3. Cấu Hình Theme Chuẩn Theo Đề Thi

ColorScheme màu xanh Teal chủ đạo

Sử dụng màu hạt giống (seed color) Color(0xFF00695C) để toàn bộ các nút bấm, icon và viền ô nhập liệu trong app tự động mang tông màu xanh ngọc bích chuẩn như đề bài.

4. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của lib/main.dart

Mở file lib/main.dart trong dự án của bạn, xóa sạch nội dung mẫu ban đầu và dán toàn bộ code bên dưới vào:

// lib/main.dart
import 'package:flutter/material.dart';
import 'screens/home_screen.dart';
import 'screens/login_screen.dart';
import 'services/session_service.dart';

void main() async {
  // Bắt buộc khởi tạo Flutter engine trước khi gọi async trong main
  WidgetsFlutterBinding.ensureInitialized();

  // Task 3: Kiểm tra session đã lưu khi app khởi chạy
  final bool isLoggedIn = await SessionService.isLoggedIn();

  runApp(MyApp(isLoggedIn: isLoggedIn));
}

class MyApp extends StatelessWidget {
  final bool isLoggedIn;

  const MyApp({super.key, required this.isLoggedIn});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Art Gallery Manager',
      debugShowCheckedModeBanner: false,
      theme: ThemeData(
        useMaterial3: true,
        colorScheme: ColorScheme.fromSeed(
          seedColor: const Color(0xFF00695C),
          primary: const Color(0xFF00695C),
        ),
        appBarTheme: const AppBarTheme(
          centerTitle: false,
          elevation: 0.5,
        ),
      ),
      // Phân luồng: Có session thì vào Home, không thì vào Login
      home: isLoggedIn ? const HomeScreen() : const LoginScreen(),
    );
  }
}

5. Kịch Bản Test Toàn Diện 7 Tasks Trước Khi Nộp Bài

Task Chức năng Thao tác kiểm thử thực tế Kết quả mong đợi
Task 1 Đăng ký (Register) Vào Sign In → bấm Register now → thử để trống để test validate → nhập username trùng admin để xem báo lỗi → tạo tài khoản mới hợp lệ. Báo lỗi màu đỏ đúng trường hợp, tạo thành công hiện SnackBar và quay lại Login.
Task 2 Đăng nhập (Login) Nhập sai mật khẩu → xem có hiện Invalid username or password không. Sau đó đăng nhập bằng tài khoản vừa tạo (hoặc tài khoản mẫu admin mật khẩu 123456). Mở thành công vào màn hình Home Screen.
Task 3 Quản lý Session Khi đang ở Home Screen → Tắt hẳn app (hoặc reload lại trang web) → Mở app lại. App tự động mở thẳng vào Home Screen mà không bắt đăng nhập lại! Bấm icon Logout trên AppBar thì quay lại Login Screen.
Task 4 Danh sách (Home) Quan sát Banner, dòng chữ "Welcome <username>", danh sách các bức tranh mẫu gồm Title, Artist, Year. Hiển thị đẹp mắt bằng ListView.builder.
Task 5 Thêm mới (Add) Bấm nút + Add Artwork → thử để trống → điền đầy đủ tranh mới → bấm Save Artwork. Hiện SnackBar Artwork added successfully & tranh mới lập tức xuất hiện ở đầu danh sách Home.
Task 6 Chi tiết (Detail) Chạm vào 1 bức tranh bất kỳ trên danh sách Home. Hiện đầy đủ Title, Artist, Year, Category, Description và bấm nút Back quay lại được Home.
Task 7 Xóa (Delete) Bấm icon thùng rác của 1 bức tranh → bấm Cancel → bấm lại thùng rác → bấm Delete. Hiện SnackBar Artwork deleted successfully và bức tranh biến mất khỏi danh sách.

6. Lệnh Dọn Dẹp flutter clean & Nén Nộp Bài Thi

HÀNH ĐỘNG BẮT BUỘC TRƯỚC KHI NÉN FILE ZIP NỘP CHO GIÁM THỊ:

1. Mở Terminal tại thư mục dự án và chạy duy nhất lệnh sau:

flutter clean

2. Lệnh này sẽ xóa các thư mục build/ và file cache nặng từ vài trăm MB xuống chỉ còn 1–2 MB.

3. Chuột phải vào thư mục dự án → Chọn Send to → Compressed (zipped) folder (hoặc nén dạng .zip theo đúng mã sinh viên mà giám thị yêu cầu).
