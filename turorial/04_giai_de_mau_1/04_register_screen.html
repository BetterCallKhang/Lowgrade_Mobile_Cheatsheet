Bước 4: Xây Dựng Màn Hình Đăng Ký (Task 1: User Registration Screen)

Sau khi đã có tầng CSDL DatabaseHelper ở Bước 3, bây giờ chúng ta bước vào xây dựng Task 1: Create a Register Screen theo đúng chuẩn đề thi. Màn hình này thu thập thông tin người dùng, kiểm tra tính hợp lệ của dữ liệu nhập (Validation), kiểm tra trùng username và lưu thông tin vào SQLite thông qua hàm registerUser.

Để code không bị dài dòng khó theo dõi, mỗi thành phần và hàm xử lý đều được tách riêng thành từng mục có viền màu sắc phân biệt, giải thích bản chất từng dòng code trước khi cung cấp toàn bộ file hoàn chỉnh.

Nội dung bài học gồm 8 phần chi tiết:
  • 1. Phân tích yêu cầu đề bài Task 1 & Các tiêu chí chấm điểm
  • 2. Khai báo Form Key, Controllers & Hàm dispose() giải phóng bộ nhớ
  • 3. Bộ 3 hàm Validation: Bắt buộc nhập, Regex Email & Khớp mật khẩu
  • 4. Hàm xử lý logic chính _handleRegister() (Async/Await & SnackBar)
  • 5. Chi tiết từng Widget nhập liệu: Username, Email, Password, Confirm
  • 6. Widget Nút bấm Đăng ký (ElevatedButton & CircularProgressIndicator)
  • 7. Toàn bộ mã nguồn hoàn chỉnh của register_screen.dart (Copy 1 click)
  • 8. Checklist nghiệm thu chấm điểm Task 1

1. Phân Tích Yêu Cầu Đề Bài Task 1 & Tiêu Chí Chấm Điểm

Các ô nhập liệu (Fields) bắt buộc
  • Username: Tên tài khoản (icon: Icons.person_outline)
  • Email: Địa chỉ email (icon: Icons.email_outlined)
  • Password: Mật khẩu (ẩn ký tự: obscureText: true, icon: Icons.lock_outline)
  • Confirm Password: Nhập lại mật khẩu (icon: Icons.lock_reset)
Các điều kiện bắt buộc (Requirements)
  • Validate all fields are filled: Không để trống bất kỳ trường nào.
  • Password and Confirm Password match: Hai mật khẩu phải trùng khớp 100%.
  • Username must be unique: Username chưa từng có trong CSDL SQLite.
  • Save user to database: Ghi vào bảng users kèm createdAt.
  • Navigate to Login Screen: Đăng ký xong quay về màn hình Đăng nhập.

2. Khai Báo Biến, Controllers & Hàm dispose()

Khai báo Controllers & Hàm thu hồi bộ nhớ dispose()

Bản chất: Mỗi ô TextFormField cần một TextEditingController riêng để hứng giá trị người dùng gõ. Đồng thời bắt buộc phải ghi đè hàm dispose() để thu hồi bộ nhớ khi thoát màn hình, tránh lỗi Memory Leak.

  // Key điều khiển trạng thái toàn bộ Form
  final _formKey = GlobalKey();

  // 4 Controllers tương ứng cho 4 ô nhập
  final _usernameController = TextEditingController();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  final _confirmPasswordController = TextEditingController();

  // Biến cờ theo dõi trạng thái
  bool _isLoading = false;
  bool _obscurePassword = true;
  bool _obscureConfirmPassword = true;

  // Bắt buộc: Giải phóng bộ nhớ khi rời màn hình
  @override
  void dispose() {
    _usernameController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _confirmPasswordController.dispose();
    super.dispose();
  }

3. Bộ 3 Quy Tắc Validation Phòng Thi

Các hàm kiểm tra tính hợp lệ dữ liệu (Validators)

Bản chất: Các hàm này trả về một String báo lỗi màu đỏ nếu dữ liệu không đạt, hoặc trả về null nếu dữ liệu hợp lệ.

// 1. Validator kiểm tra để trống & độ dài tối thiểu
String? validateUsername(String? val) {
  if (val == null || val.trim().isEmpty) return 'Username is required';
  if (val.trim().length < 3) return 'Username must be at least 3 characters';
  return null;
}

// 2. Validator kiểm tra cú pháp Email bằng Biểu thức chính quy (Regex)
String? validateEmail(String? val) {
  if (val == null || val.trim().isEmpty) return 'Email is required';
  final emailRegex = RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$');
  if (!emailRegex.hasMatch(val.trim())) return 'Invalid email format';
  return null;
}

// 3. Validator kiểm tra khớp mật khẩu xác nhận
String? validateConfirmPassword(String? val) {
  if (val == null || val.isEmpty) return 'Please confirm password';
  if (val != _passwordController.text) return 'Password and Confirm Password must match';
  return null;
}

4. Hàm Xử Lý Sự Kiện Nhấn Nút _handleRegister()

Quy trình 6 bước xử lý đăng ký (Async / Await)

Nhiệm vụ: Kích hoạt kiểm tra form → Soi CSDL xem có trùng tên không → Lưu User mới vào SQLite → Bắn SnackBar thông báo → Đóng màn hình quay về Login.

  Future _handleRegister() async {
    // Bước 1: Kiểm tra tính hợp lệ của tất cả các ô nhập trong Form
    if (!_formKey.currentState!.validate()) {
      return; // Dừng lại ngay nếu có ô chưa đúng
    }

    final username = _usernameController.text.trim();
    final email = _emailController.text.trim();
    final password = _passwordController.text;

    setState(() => _isLoading = true);

    try {
      // Bước 2: Gọi DatabaseHelper kiểm tra username trùng
      final exists = await DatabaseHelper.instance.checkUsernameExists(username);
      if (exists) {
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Tên đăng nhập đã tồn tại, vui lòng chọn tên khác!'),
            backgroundColor: Colors.red,
          ),
        );
        setState(() => _isLoading = false);
        return;
      }

      // Bước 3: Lấy ngày hiện tại tự động theo chuẩn YYYY-MM-DD
      final now = DateTime.now();
      final createdAt = "${now.year}-${now.month.toString().padLeft(2, '0')}-${now.day.toString().padLeft(2, '0')}";

      // Bước 4: Đóng gói UserModel và Insert vào SQLite
      final newUser = UserModel(
        username: username,
        email: email,
        password: password,
        createdAt: createdAt,
      );

      await DatabaseHelper.instance.registerUser(newUser);

      if (!mounted) return;
      // Bước 5: Thông báo thành công bằng SnackBar xanh
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Đăng ký tài khoản thành công!'),
          backgroundColor: Colors.teal,
        ),
      );

      // Bước 6: Đóng màn hình quay về màn hình Đăng nhập (Login)
      Navigator.pop(context);
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Đã xảy ra lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

5. Chi Tiết Các Ô Nhập Liệu (TextFormField)

Cấu trúc các ô nhập liệu giao diện

Gồm: Ô Username (prefix icon person), Ô Email (keyboardType email), Ô Password & Confirm Password (có icon con mắt bật/tắt ẩn hiện mật khẩu).

// 1. Ô Username
TextFormField(
  controller: _usernameController,
  decoration: const InputDecoration(
    labelText: 'Username',
    hintText: 'testuser123',
    prefixIcon: Icon(Icons.person_outline),
    border: OutlineInputBorder(),
  ),
  validator: (val) {
    if (val == null || val.trim().isEmpty) return 'Username is required';
    if (val.trim().length < 3) return 'Username must be at least 3 characters';
    return null;
  },
),

// 2. Ô Email
TextFormField(
  controller: _emailController,
  keyboardType: TextInputType.emailAddress,
  decoration: const InputDecoration(
    labelText: 'Email',
    hintText: 'test@example.com',
    prefixIcon: Icon(Icons.email_outlined),
    border: OutlineInputBorder(),
  ),
  validator: (val) {
    if (val == null || val.trim().isEmpty) return 'Email is required';
    if (!RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$').hasMatch(val.trim())) {
      return 'Invalid email format';
    }
    return null;
  },
),

// 3. Ô Password có nút bật tắt con mắt
TextFormField(
  controller: _passwordController,
  obscureText: _obscurePassword,
  decoration: InputDecoration(
    labelText: 'Password',
    prefixIcon: const Icon(Icons.lock_outline),

  ),
  validator: (val) {
    if (val == null || val.isEmpty) return 'Password is required';
    if (val.length < 6) return 'Password must be at least 6 characters';
    return null;
  },
),

// 4. Ô Confirm Password
TextFormField(
  controller: _confirmPasswordController,
  obscureText: _obscureConfirmPassword,
  decoration: InputDecoration(
    labelText: 'Confirm Password',
    prefixIcon: const Icon(Icons.lock_reset),
    border: const OutlineInputBorder(),
    suffixIcon: IconButton(
      icon: Icon(_obscureConfirmPassword ? Icons.visibility_off : Icons.visibility),
      onPressed: () => setState(() => _obscureConfirmPassword = !_obscureConfirmPassword),
    ),
  ),
  validator: (val) {
    if (val == null || val.isEmpty) return 'Please confirm password';
    if (val != _passwordController.text) return 'Password and Confirm Password must match';
    return null;
  },

6. Widget Nút Bấm Đăng Ký (ElevatedButton)

Nút bấm có hiệu ứng Loading xoay vòng

Mục đích: Dùng màu xanh Teal Color(0xFF00695C) chuẩn đề bài. Khi người dùng bấm nút và CSDL đang chạy, hiển thị CircularProgressIndicator để người dùng không bấm nhiều lần liên tiếp.

SizedBox(
  height: 50,
  child: ElevatedButton(
    onPressed: _isLoading ? null : _handleRegister,
    style: ElevatedButton.styleFrom(
      backgroundColor: const Color(0xFF00695C), // Màu xanh teal đậm chuẩn mock đề
      foregroundColor: Colors.white,
      shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),
    ),
    child: _isLoading
        ? const SizedBox(
            width: 24,
            height: 24,
            child: CircularProgressIndicator(color: Colors.white, strokeWidth: 2.5),
          )
        : const Text('Register', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
  ),
)

7. Toàn Bộ Mã Nguồn Hoàn Chỉnh Của register_screen.dart

Sau khi đã nắm rõ từng thành phần ở trên, tạo file lib/screens/register_screen.dart và dán toàn bộ mã nguồn bên dưới vào:

// lib/screens/register_screen.dart
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../models/user_model.dart';

class RegisterScreen extends StatefulWidget {
  const RegisterScreen({super.key});

  @override
  State createState() => _RegisterScreenState();
}

class _RegisterScreenState extends State {
  final _formKey = GlobalKey();

  final _usernameController = TextEditingController();
  final _emailController = TextEditingController();
  final _passwordController = TextEditingController();
  final _confirmPasswordController = TextEditingController();

  bool _isLoading = false;
  bool _obscurePassword = true;
  bool _obscureConfirmPassword = true;

  @override
  void dispose() {
    _usernameController.dispose();
    _emailController.dispose();
    _passwordController.dispose();
    _confirmPasswordController.dispose();
    super.dispose();
  }

  Future _handleRegister() async {
    if (!_formKey.currentState!.validate()) {
      return;
    }

    final username = _usernameController.text.trim();
    final email = _emailController.text.trim();
    final password = _passwordController.text;

    setState(() => _isLoading = true);

    try {
      final exists = await DatabaseHelper.instance.checkUsernameExists(username);
      if (exists) {
        if (!mounted) return;
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Tên đăng nhập đã tồn tại, vui lòng chọn tên khác!'),
            backgroundColor: Colors.red,
          ),
        );
        setState(() => _isLoading = false);
        return;
      }

      final now = DateTime.now();
      final createdAt = "${now.year}-${now.month.toString().padLeft(2, '0')}-${now.day.toString().padLeft(2, '0')}";

      final newUser = UserModel(
        username: username,
        email: email,
        password: password,
        createdAt: createdAt,
      );

      await DatabaseHelper.instance.registerUser(newUser);

      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        const SnackBar(
          content: Text('Đăng ký tài khoản thành công!'),
          backgroundColor: Colors.teal,
        ),
      );

      Navigator.pop(context);
    } catch (e) {
      if (!mounted) return;
      ScaffoldMessenger.of(context).showSnackBar(
        SnackBar(content: Text('Lỗi: $e'), backgroundColor: Colors.red),
      );
    } finally {
      if (mounted) setState(() => _isLoading = false);
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: Colors.white,
      appBar: AppBar(
        title: const Text('Create your account'),
        elevation: 0,
        backgroundColor: Colors.white,
        foregroundColor: Colors.black87,
      ),
      body: SafeArea(
        child: Center(
          child: SingleChildScrollView(
            padding: const EdgeInsets.symmetric(horizontal: 24.0, vertical: 16.0),
            child: Form(
              key: _formKey,
              child: Column(
                crossAxisAlignment: CrossAxisAlignment.stretch,
                children: [
                  const Text(
                    'Create your account',
                    style: TextStyle(fontSize: 26, fontWeight: FontWeight.bold, color: Colors.black87),
                  ),
                  const SizedBox(height: 6),
                  const Text(
                    'Start managing artworks with your own gallery space',
                    style: TextStyle(color: Colors.grey, fontSize: 14),
                  ),
                  const SizedBox(height: 28),

                  // 1. Ô Username
                  TextFormField(
                    controller: _usernameController,
                    decoration: const InputDecoration(
                      labelText: 'Username',
                      hintText: 'testuser123',
                      prefixIcon: Icon(Icons.person_outline),
                      border: OutlineInputBorder(),
                    ),
                    validator: (val) {
                      if (val == null || val.trim().isEmpty) return 'Username is required';
                      if (val.trim().length < 3) return 'Username must be at least 3 characters';
                      return null;
                    },
                  ),
                  const SizedBox(height: 16),

                  // 2. Ô Email
                  TextFormField(
                    controller: _emailController,
                    keyboardType: TextInputType.emailAddress,
                    decoration: const InputDecoration(
                      labelText: 'Email',
                      hintText: 'test@example.com',
                      prefixIcon: Icon(Icons.email_outlined),
                      border: OutlineInputBorder(),
                    ),
                    validator: (val) {
                      if (val == null || val.trim().isEmpty) return 'Email is required';
                      if (!RegExp(r'^[\w-\.]+@([\w-]+\.)+[\w-]{2,4}$').hasMatch(val.trim())) {
                        return 'Invalid email format';
                      }
                      return null;
                    },
                  ),
                  const SizedBox(height: 16),

                  // 3. Ô Password
                  TextFormField(
                    controller: _passwordController,
                    obscureText: _obscurePassword,
                    decoration: InputDecoration(
                      labelText: 'Password',
                      prefixIcon: const Icon(Icons.lock_outline),
                      border: const OutlineInputBorder(),
                      suffixIcon: IconButton(
                        icon: Icon(_obscurePassword ? Icons.visibility_off : Icons.visibility),
                        onPressed: () => setState(() => _obscurePassword = !_obscurePassword),
                      ),
                    ),
                    validator: (val) {
                      if (val == null || val.isEmpty) return 'Password is required';
                      if (val.length < 6) return 'Password must be at least 6 characters';
                      return null;
                    },
                  ),
                  const SizedBox(height: 16),

                  // 4. Ô Confirm Password
                  TextFormField(
                    controller: _confirmPasswordController,
                    obscureText: _obscureConfirmPassword,
                    decoration: InputDecoration(
                      labelText: 'Confirm Password',
                      prefixIcon: const Icon(Icons.lock_reset),
                      border: const OutlineInputBorder(),
                      suffixIcon: IconButton(
                        icon: Icon(_obscureConfirmPassword ? Icons.visibility_off : Icons.visibility),
                        onPressed: () => setState(() => _obscureConfirmPassword = !_obscureConfirmPassword),
                      ),
                    ),
                    validator: (val) {
                      if (val == null || val.isEmpty) return 'Please confirm password';
                      if (val != _passwordController.text) return 'Password and Confirm Password must match';
                      return null;
                    },
                  ),
                  const SizedBox(height: 24),

                  // 5. Nút Register
                  SizedBox(
                    height: 50,
                    child: ElevatedButton(
                      onPressed: _isLoading ? null : _handleRegister,
                      style: ElevatedButton.styleFrom(
                        backgroundColor: const Color(0xFF00695C),
                        foregroundColor: Colors.white,
                        shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(8)),
                      ),
                      child: _isLoading
                          ? const SizedBox(
                              width: 24,
                              height: 24,
                              child: CircularProgressIndicator(color: Colors.white, strokeWidth: 2.5),
                            )
                          : const Text('Register', style: TextStyle(fontSize: 16, fontWeight: FontWeight.bold)),
                    ),
                  ),

                  const SizedBox(height: 16),

                  // 6. Chuyển sang Sign In
                  Row(
                    mainAxisAlignment: MainAxisAlignment.center,
                    children: [
                      const Text('Already have an account? '),
                      GestureDetector(
                        onTap: () => Navigator.pop(context),
                        child: const Text('Sign In', style: TextStyle(color: Color(0xFF00695C), fontWeight: FontWeight.bold)),
                      ),
                    ],
                  ),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}
