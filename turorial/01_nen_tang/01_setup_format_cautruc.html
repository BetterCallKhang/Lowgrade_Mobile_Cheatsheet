Phần 1. Setup dự án, Format code, Cấu trúc code

Cài môi trường, tạo project Flutter, hiểu từng thư mục trong project, chạy app, format code cho gọn. Mỗi thao tác đều có 2 cách: giao diện Android Studio và dòng lệnh (Terminal). Debug và tra cứu lỗi xem ở Phần 2.

Phím tắt ghi theo dạng Windows/Linux trước, Mac ghi kèm phía sau.

1. Chuẩn bị môi trường

Khái niệm

Dart là ngôn ngữ lập trình (giống Java, C#). Flutter là framework viết bằng Dart, cung cấp sẵn các Widget để dựng giao diện và build ra app Android, iOS, Web, Desktop từ cùng một code.

Flutter SDK là bộ công cụ tải về máy, bên trong đã có sẵn Dart SDK. Cài Flutter SDK là có luôn lệnh flutter và dart.

Android Studio là IDE (phần mềm viết code). Nó cung cấp Android SDK (để build app Android) và Emulator (máy ảo Android). Muốn viết Flutter trong Android Studio phải cài thêm plugin Flutter.

1
Cài Flutter SDK và Android Studio (theo hệ điều hành)

Việc cần làm giống nhau trên mọi hệ điều hành: tải Flutter SDK, giải nén, thêm thư mục flutter/bin vào PATH, cài Android Studio. Chỉ khác cách thao tác. Trang tải chính thức: docs.flutter.dev/install và developer.android.com/studio.

Khái niệm

PATH là biến môi trường chứa danh sách thư mục mà Terminal sẽ tìm khi bạn gõ một lệnh. Thêm flutter/bin vào PATH thì gõ flutter ở thư mục nào cũng chạy được. Nếu không thêm, Terminal báo flutter: command not found (Windows: 'flutter' is not recognized...).

Quy tắc chung cho thư mục chứa Flutter SDK

Đường dẫn không có dấu cách, không có tiếng Việt, và không đặt trong thư mục cần quyền admin (Windows: không đặt trong C:\Program Files).

Windows

  1. Cài Git for Windows (Flutter dùng Git bên trong). Tải ở git-scm.com, cài mặc định.
  2. Tải Flutter SDK: file flutter_windows_x.y.z-stable.zip ở trang tải chính thức.
  3. Giải nén vào C:\src\, được thư mục C:\src\flutter (bên trong có thư mục bin).
  4. Thêm vào PATH:
    • Bấm Start, gõ env → chọn Edit environment variables for your account.
    • Ở khung User variables, chọn dòng Path → Edit → New → nhập C:\src\flutter\bin → OK → OK.
    • Tắt hết cửa sổ Terminal / PowerShell đang mở và mở lại thì PATH mới có hiệu lực.
  5. Cài Android Studio: tải file .exe, chạy và bấm Next theo mặc định. Lần đầu mở, Setup Wizard sẽ tự tải Android SDK và Emulator, chọn Standard.
PowerShell - Kiểm tra
# Xem Flutter đã nhận chưa
flutter --version

# Xem lệnh flutter đang trỏ tới đâu
where.exe flutter

Linux

  1. Cài các gói cần thiết (ví dụ Ubuntu / Debian, các distro khác dùng trình quản lý gói tương ứng):
    bash
    sudo apt-get update
sudo apt-get install -y curl git unzip xz-utils zip libglu1-mesa
  2. Tải và giải nén Flutter SDK. Chọn một trong hai cách:
    bash
    # Tạo thư mục chứa SDK
mkdir -p ~/develop

# Cách A: tải file flutter_linux_x.y.z-stable.tar.xz từ trang chính thức về ~/Downloads rồi giải nén
tar -xf ~/Downloads/flutter_linux_*-stable.tar.xz -C ~/develop/

# Cách B: lấy trực tiếp bằng git (nhánh stable)
git clone https://github.com/flutter/flutter.git -b stable ~/develop/flutter

    Kết quả: thư mục ~/develop/flutter (bên trong có bin).

  3. Thêm vào PATH. Kiểm tra shell đang dùng bằng echo $SHELL:
    bash
    # Nếu dùng bash (kết quả /bin/bash)
echo 'export PATH="$HOME/develop/flutter/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

# Nếu dùng zsh (kết quả /bin/zsh hoặc /usr/bin/zsh)
echo 'export PATH="$HOME/develop/flutter/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc

    ~/.bashrc, ~/.zshrc là file cấu hình chạy mỗi khi mở Terminal. Dòng export PATH=... ghi vào đó để lần nào mở Terminal cũng có PATH. Lệnh source nạp lại ngay mà không cần mở Terminal mới.

  4. Cài Android Studio: tải file .tar.gz, giải nén rồi chạy file bin/studio.sh. Lần đầu mở, Setup Wizard tự tải Android SDK, chọn Standard. Ubuntu có thể cài nhanh bằng sudo snap install android-studio --classic.
  5. Tạo lối tắt trên menu ứng dụng: trong Android Studio chọn Tools → Create Desktop Entry (nếu có).
bash - Kiểm tra
flutter --version

# Xem lệnh flutter đang trỏ tới đâu
which flutter

macOS

  1. Cài Xcode Command Line Tools (có sẵn Git và các công cụ build):
    zsh
    xcode-select --install
  2. Xem máy dùng chip gì: menu Apple → About This Mac. Chip Apple M1/M2/M3... là Apple Silicon, chip Intel là Intel. Tải đúng bản Flutter SDK cho chip đó. Máy Apple Silicon nên cài thêm Rosetta:
    zsh
    sudo softwareupdate --install-rosetta --agree-to-license
  3. Tải và giải nén Flutter SDK:
    zsh
    # Tạo thư mục chứa SDK

# Giải nén file .zip đã tải về (tên file tuỳ phiên bản và chip)
unzip ~/Downloads/flutter_macos_*-stable.zip -d ~/develop/

    Kết quả: thư mục ~/develop/flutter. Có thể dùng Homebrew thay cho 2 bước tải và giải nén: brew install --cask flutter.

  4. Thêm vào PATH. macOS dùng zsh làm shell mặc định:
    zsh
    echo 'export PATH="$HOME/develop/flutter/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
  5. Cài Android Studio: tải file .dmg đúng chip, mở ra và kéo biểu tượng Android Studio vào thư mục Applications. Lần đầu mở, Setup Wizard tự tải Android SDK, chọn Standard.
zsh - Kiểm tra
flutter --version

# Xem lệnh flutter đang trỏ tới đâu
which flutter

Sau khi tạo, project có các thư mục và file sau. Phần lớn thời gian chỉ làm việc trong lib/ và pubspec.yaml.

├── web/                    # File index.html cho bản Web

├── lib/                    # TOÀN BỘ CODE DART CỦA APP
│   └── main.dart           # File chạy đầu tiên, chứa hàm main()
├── test/                   # Code kiểm thử (unit test, widget test)

4. pubspec.yaml và cài thư viện

Khái niệm

Package (thư viện) là code người khác viết sẵn, đăng trên trang pub.dev. Ví dụ http để gọi API, sqflite để dùng SQLite.

dependencies là thư viện app cần khi chạy. dev_dependencies là thư viện chỉ cần lúc phát triển (sinh code, test, lint), không đóng gói vào app.

YAML là định dạng file dùng thụt lề bằng dấu cách để thể hiện cấp cha con. Thụt sai một dấu cách là lỗi. Không dùng phím Tab.

pubspec.yaml
name: ten_project                  # Tên project, dùng trong import 'package:ten_project/...'
description: "A new Flutter project."
publish_to: 'none'                 # Không đăng lên pub.dev
version: 1.0.0+1                   # Phiên bản app: 1.0.0 là tên hiển thị, +1 là số build

environment:
  sdk: ^3.12.2                     # Phiên bản Dart SDK tối thiểu

dependencies:                      # Thư viện dùng khi app chạy
  flutter:
    sdk: flutter
  cupertino_icons: ^1.0.8
  http: ^1.6.0                     # Thụt đúng 2 dấu cách so với dependencies

dev_dependencies:                  # Thư viện chỉ dùng lúc phát triển
  flutter_test:
    sdk: flutter
  flutter_lints: ^6.0.0

flutter:
  uses-material-design: true
  assets:                          # Khai báo ảnh, file dùng trong app
    - assets/images/
Ký hiệu ^ trong phiên bản

^1.6.0 nghĩa là chấp nhận mọi phiên bản từ 1.6.0 đến dưới 2.0.0. Thư viện được cập nhật bản vá nhưng không nhảy lên bản lớn có thể làm hỏng code.

Cách 1: Sửa pubspec.yaml rồi Pub get
  1. Mở pubspec.yaml, thêm tên thư viện vào dưới dependencies: hoặc dev_dependencies:, thụt 2 dấu cách.
  2. Bấm Pub get ở thanh phía trên cửa sổ code (Android Studio tự hiện khi file thay đổi).
  3. Hoặc chạy flutter pub get trong Terminal.

pub get là lệnh tải các thư viện đã khai báo về máy. Phải chạy mỗi khi sửa pubspec.yaml.

Cách 2: Lệnh flutter pub add

Lệnh này tự ghi vào pubspec.yaml với phiên bản mới nhất phù hợp và tự chạy pub get, không lo sai thụt lề.

bash
# Thêm vào dependencies (có thể thêm nhiều cái một lúc)
flutter pub add http shared_preferences

# Thêm vào dev_dependencies: dùng cờ --dev
flutter pub add --dev build_runner

# Gỡ thư viện
flutter pub remove http

# Xem thư viện nào có bản mới hơn
flutter pub outdated

5. Chia thư mục và file trong lib/

App nhỏ có thể để hết trong main.dart, nhưng khi có nhiều màn hình nên chia theo vai trò để dễ tìm, dễ sửa. Cách chia phổ biến:

lib/
lib/
├── main.dart                     # Hàm main(), cấu hình MaterialApp
├── model/                        # Class dữ liệu: User, Product, Note...
│   ├── user.dart
│   └── note.dart
├── ui/                           # Các màn hình giao diện
│   ├── login_screen.dart
│   └── note_list_screen.dart
├── providers/                    # Quản lý state (dùng khi học Riverpod)
│   └── note_notifier.dart
└── db/                           # Làm việc với database (dùng khi học SQLite)
    └── database_helper.dart
Thư mụcChứa gìVí dụ
model/Class mô tả dữ liệu: thuộc tính, constructor, chuyển đổi JSON. Không chứa giao diện.class Note { int id; String title; }
ui/Widget màn hình: mỗi màn hình một file.class NoteListScreen extends StatelessWidget
providers/Logic và trạng thái dùng chung giữa nhiều màn hình.class NoteNotifier
db/Code truy cập database: mở DB, tạo bảng, thêm sửa xoá.class DatabaseHelper
Tạo thư mục và file trong Android Studio
  • Thư mục: chuột phải lib ở cửa sổ Project bên trái → New → Directory → nhập tên.
  • File Dart: chuột phải thư mục → New → Dart File → nhập tên, không cần gõ đuôi .dart.
  • Mở cửa sổ Project nếu bị ẩn: Alt + 1 (Mac: Cmd + 1).
Quy tắc đặt tên trong Dart
  • Tên file, thư mục: snake_case (chữ thường, gạch dưới), ví dụ note_list_screen.dart.
  • Tên class: UpperCamelCase, ví dụ NoteListScreen.
  • Tên biến, hàm: lowerCamelCase, ví dụ noteList, loadData().
  • Tên bắt đầu bằng _: private, chỉ dùng được trong cùng file, ví dụ _counter.

Import file này vào file khác

Khái niệm

import là câu lệnh để dùng class, hàm được viết ở file khác. Mỗi file Dart là một thư viện riêng, muốn dùng gì ở file khác thì phải import file đó.

dart
// 1. Thư viện có sẵn của Dart: tiền tố dart:
import 'dart:convert';

// 2. Thư viện ngoài hoặc Flutter: tiền tố package:
import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;   // as: đặt tên rút gọn, gọi http.get(...)

// 3. File trong project, cách package (đường dẫn tính từ lib/)
import 'package:ten_project/model/note.dart';

// 4. File trong project, cách đường dẫn tương đối (tính từ file hiện tại)
import '../model/note.dart';
Import tự động

Gõ tên class chưa import (bị gạch đỏ), đặt con trỏ vào đó, nhấn Alt + Enter (Mac: Option + Enter) → chọn Import library '...'. Android Studio tự thêm dòng import đúng.

Hot Reload và Hot Restart

Khái niệm

Hot Reload: nạp code mới vào app đang chạy, giữ nguyên trạng thái (giá trị biến, màn hình đang mở). Chỉ chạy lại hàm build(). Dùng khi sửa giao diện.

Hot Restart: chạy lại app từ hàm main(), mất toàn bộ trạng thái. Nhanh hơn tắt app chạy lại.

Stop rồi Run lại: build lại từ đầu. Bắt buộc khi thêm thư viện mới vào pubspec.yaml hoặc sửa code trong android/, ios/.

Bạn vừa sửa gìCần làm

Đổi StatelessWidget thành StatefulWidget hoặc ngược lạiHot Restart
Thêm thư viện trong pubspec.yaml, sửa code nativeStop rồi Run lại
Thao tácAndroid StudioTerminal (flutter run)

7. Format code và kiểm tra code

Khái niệm

Format code là tự động căn lề, xuống dòng, khoảng trắng theo chuẩn chung của Dart. Không thay đổi logic, chỉ làm code dễ đọc và mọi người viết giống nhau.

Lint / Analyzer là công cụ đọc code và báo lỗi, cảnh báo ngay khi đang gõ, trước khi chạy app. Gạch đỏ là lỗi (không chạy được), gạch vàng là cảnh báo, gạch xám là gợi ý.

Format trong Android Studio
  • Format file đang mở: Ctrl + Alt + L (Mac: Cmd + Option + L), hoặc Code → Reformat Code.
  • Xoá import thừa: Ctrl + Alt + O (Mac: Ctrl + Option + O), hoặc Code → Optimize Imports.
  • Format cả thư mục: chuột phải lib → Reformat Code.
Format trong Terminal
bash
# Format toàn bộ project
dart format .

# Format một file hoặc thư mục
dart format lib/main.dart
dart format lib/

Tự động format khi lưu file

Bật một lần, sau đó mỗi lần Ctrl + S code tự được format. Vị trí cài đặt tuỳ phiên bản:

  • Settings → Languages & Frameworks → Flutter: tick Format code on save, Organize imports on save, Perform hot reload on save.
  • Nếu không thấy các mục trên: Settings → Tools → Actions on Save: tick Reformat code và Optimize imports.

Dấu phẩy cuối (trailing comma)

Khái niệm

Trailing comma là dấu phẩy đặt sau tham số cuối cùng. Formatter của Dart (từ Dart 3.7) tự quyết định thêm hoặc bỏ dấu phẩy này: nếu cả lệnh vừa một dòng thì gộp lại một dòng và bỏ phẩy, nếu dài quá thì tách mỗi tham số một dòng và thêm phẩy.

dart - Kết quả sau khi format
// Ngắn: formatter giữ một dòng
Text('Hello', style: TextStyle(fontSize: 20))

// Dài: formatter tự tách dòng và thêm dấu phẩy cuối
Container(
  padding: const EdgeInsets.all(16),
  color: Colors.blue,
  child: const Text('Hello Flutter', style: TextStyle(fontSize: 20)),
)

Muốn formatter giữ nguyên dấu phẩy bạn tự gõ (để ép tách dòng) và chỉnh độ rộng dòng, thêm vào analysis_options.yaml:

analysis_options.yaml
include: package:flutter_lints/flutter.yaml

formatter:
  page_width: 100            # Số ký tự tối đa mỗi dòng (mặc định 80)
  trailing_commas: preserve  # Có dấu phẩy cuối thì luôn tách dòng

linter:
  rules:
    avoid_print: false       # Ví dụ: tắt cảnh báo khi dùng print

Kiểm tra lỗi toàn project

Android Studio

Mở cửa sổ Dart Analysis (cạnh dưới, hoặc View → Tool Windows → Dart Analysis). Danh sách tất cả lỗi, cảnh báo của project. Bấm đúp để nhảy tới dòng lỗi.

Đặt con trỏ vào chỗ gạch chân, nhấn Alt + Enter (Mac: Option + Enter) để xem gợi ý sửa nhanh.

Terminal
bash
# Liệt kê lỗi và cảnh báo
flutter analyze

# Xem các lỗi có thể tự sửa
dart fix --dry-run

# Tự sửa (ví dụ: thêm const còn thiếu)
dart fix --apply
