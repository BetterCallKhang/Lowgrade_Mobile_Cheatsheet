Phần 6. Lập trình Bất đồng bộ trong Dart (Future & Stream)

Giải thích tường tận từ gốc rễ: Tại sao cần bất đồng bộ? Cơ chế hoạt động của Future (kết quả ở tương lai), cách dữ liệu chuyền tay nhau qua chuỗi .then(), cú pháp hiện đại async / await, và hiểu cặn kẽ Stream (dòng nước chảy dữ liệu) với async* và yield.

1. Vì sao cần Bất đồng bộ? (Ví dụ đời thực dễ hiểu nhất)

Khái niệm cốt lõi

Dart và Flutter chạy trên một luồng duy nhất (Single Thread). Hãy tưởng tượng ứng dụng của bạn như một người phục vụ quán cà phê:

  • Đồng bộ (Synchronous - Chặn luồng): Khách gọi món phải pha mất 5 phút. Người phục vụ đứng im chờ pha xong mới quay lại phục vụ khách khác. Toàn bộ quán bị tê liệt. → Trong app Flutter: Màn hình bị đơ (Freezing), vuốt không ăn, giật lag!
  • Bất đồng bộ (Asynchronous - Không chặn luồng): Khách gọi món, người phục vụ ghi phiếu gửi vào quầy pha chế, rồi ngay lập tức quay sang tiếp đón khách tiếp theo. Khi quầy pha xong và rung chuông, người phục vụ mới mang nước ra cho khách đầu tiên. → App Flutter: Giao diện luôn mượt mà 60/120 FPS trong khi mạng đang tải ngầm ở nền.

2. Future<T> là gì? (Chiếc vé hẹn lấy kết quả)

Hình tượng hoá

Future<T> giống như một Chiếc vé hẹn / Phiếu rung ở quán trà sữa. Khi bạn gọi món, quán chưa có trà sữa ngay mà đưa cho bạn 1 chiếc thẻ rung (đại diện cho 1 ly trà sữa trong tương lai):

  • Trạng thái Uncompleted (Đang chờ): Đang pha chế, chưa có kết quả.
  • Trạng thái Completed with Data (Thành công): Thẻ rung lên, bạn nhận được ly trà sữa (giá trị kiểu T).
  • Trạng thái Completed with Error (Thất bại): Hết trân châu, quán báo lỗi (ném ra Exception).

3. Cơ chế hoạt động của .then() (Chuyền tay giá trị như dây chuyền)

Bản chất của .then((value) { ... })

Hàm .then() nghĩa là: "Khi nào Future làm xong và có kết quả, hãy lấy kết quả đó nhét vào biến trong ngoặc tròn (value), rồi chạy tiếp thân hàm phía sau!"

Nếu trong .then() bạn return ra một giá trị mới, giá trị đó sẽ tiếp tục được nhồi vào biến của .then() kế tiếp (như một dây chuyền sản xuất băng chuyền nhà máy).

dart - Dây chuyền .then() chuyền tay dữ liệu
// Giả sử có một Future tạo ra số 1 sau khi chạy
Future getOne() {
  return Future(() => 1);
}

int addOne(int v) {
  return v + 1;
}

void printIntValue(int v) {
  print('Kết quả cuối cùng: $v');
}

void main() {
  print('--- Bắt đầu ---');

  // CÁCH 1: Viết tường minh bằng hàm mũi tên (Arrow function)
  Future(() => 1)
      .then((v) {
        // 'v' chính là số 1 được Future tạo ra và đưa vào đây
        print('Bước 1 nhận được: $v');
        return v + 1; // return ra 2, chuyền tiếp cho .then kế tiếp
      })
      .then((value) {
        // 'value' nhận số 2 từ bước trước
        print('Bước 2 nhận được: $value');
        return value * 10; // return ra 20
      })
      .then((finalVal) {
        // 'finalVal' nhận số 20
        print('Bước 3 in ra: $finalVal');
      })
      .catchError((error) {
        // Bắt lỗi nếu bất kỳ bước nào phía trên bị sập
        print('Có lỗi xảy ra: $error');
      });

  // CÁCH 2: Truyền thẳng tên hàm (Function tear-off)
  // Giá trị trả về của bước trước sẽ tự động biến thành đối số đầu vào của hàm sau:
  Future(getOne)
      .then(addOne)         // Lấy 1 đưa vào addOne(1) -> trả về 2
      .then(printIntValue); // Lấy 2 đưa vào printIntValue(2) -> in ra 2

  print('--- Kết thúc hàm main (Code này chạy trước cả .then do bất đồng bộ!) ---');
}

4. Cú pháp hiện đại: async và await

Vì sao sinh ra async/await?

Khi dùng .then() nối nhau quá nhiều hoặc lồng nhau (Callback Hell), code sẽ rất khó đọc và khó bắt lỗi try-catch. Dart sinh ra cặp từ khoá async và await để bạn viết code bất đồng bộ trông tự nhiên y hệt như code chạy tuần tự từ trên xuống dưới.

Từ khoáĐặt ở đâu?Ý nghĩa & Quy tắc bắt buộc
async Đặt ngay sau dấu ngoặc đơn tham số của hàm: void main() async Báo cho Dart biết: "Hàm này có chứa tác vụ bất đồng bộ, hãy cho phép tôi dùng await bên trong!". Hàm có async luôn tự động bọc giá trị trả về trong một Future.
await Đặt phía trước một biểu thức Future: var u = await fetchUser(); Báo cho Dart: "Hãy tạm dừng dòng này lại, đợi cho Future hoàn tất xong xuôi và bóc tách lấy giá trị thật gán vào biến, rồi mới chạy tiếp dòng bên dưới!" (Trong lúc đợi, app vẫn mượt mà không bị treo). Chỉ được dùng bên trong hàm có async!
dart - So sánh trực tiếp .then() và async/await
// Hàm giả lập mất 2 giây mới lấy được tên User
Future fetchUser() {
  return Future.delayed(const Duration(seconds: 2), () => "Khang");
}

// Cách cũ (.then): Bị thụt lề, khó bắt try-catch bao quát
void testThen() {
  fetchUser().then((u) {
    print('Xin chào $u');
  }).catchError((e) {
    print('Lỗi: $e');
  });
}

//  Cách mới (async / await): Rõ ràng, tuần tự, dùng try-catch chuẩn
Future testAsyncAwait() async {
  try {
    print('Đang gửi yêu cầu...');
    String u = await fetchUser(); // Đợi 2s, u nhận chuỗi "Khang"
    print('Xin chào $u');
    print('Làm tiếp việc khác sau khi đã có user...');
  } catch (e) {
    print('Bắt lỗi mạng hoặc server: $e');
  }
}

5. Stream là gì? (Đường ống dẫn nước phát dữ liệu liên tục)

Hình tượng hoá

Nếu Future chỉ là một chiếc hộp đóng gói 1 món quà duy nhất (mở ra là hết), thì Stream là một đường ống dẫn nước (dòng chảy sự kiện):

  • Nước trong ống có thể chảy ra liên tục theo từng giọt, từng đợt, không biết trước khi nào hết.
  • Bạn đứng ở đầu ra mở vòi để hứng (lắng nghe / subscribe / listen). Mỗi khi có một giọt nước rơi ra, bạn xử lý giọt nước đó.
  • Khi nào nhà máy cắt nước hoặc bạn đóng van thì Stream kết thúc.

Các từ khoá của Stream mà ai cũng phải nhớ

Từ khoáÝ nghĩa dễ hiểuVí dụ
Stream<T> Kiểu trả về của dòng dữ liệu phát ra nhiều giá trị kiểu T theo thời gian. Stream<int> countStream()
async* Có dấu sao *! Đánh dấu hàm là một Generator Stream (máy phát ra dòng dữ liệu). Stream<int> numbers() async* { ... }
yield Nghĩa là "Phát ra / Bắn ra một giá trị vào đường ống" rồi chạy tiếp vòng lặp (khác với return là trả về rồi thoát hàm ngay). yield 10; // Bắn số 10 vào ống cho ai đang nghe nhận
.listen() hoặc await for Hành động "ghé tai vào nghe" hoặc "mở xô hứng dữ liệu" từ Stream. stream.listen((val) => print(val));
dart - Ví dụ 1: Máy phát số đơn giản (numbers)
// Hàm async* tạo ra dòng dữ liệu bắn ra lần lượt 5, 10, 77
Stream numbers() async* {
  yield 5;
  yield 10;
  yield 77;
}

void main() {
  // Dùng .listen() để đón nhận từng số
  numbers().listen((v) {
    print('Nhận được: $v, nhân 3 thành: ${v * 3}');
  });
  // Kết quả in ra lần lượt:
  // Nhận được: 5, nhân 3 thành: 15
  // Nhận được: 10, nhân 3 thành: 30
  // Nhận được: 77, nhân 3 thành: 231
}
dart - Ví dụ 2: Ứng dụng Xổ số ngẫu nhiên thời gian thực (luckyNumber)
import 'dart:math';

// Đề bài: Cứ mỗi 0.5 giây bắn ra 1 số ngẫu nhiên (0 - 99).
// Khi nào trúng số 79 thì in "Grats" và đóng ống lại (dừng Stream).
Stream luckyNumber() async* {
  while (true) {
    // Đợi 500 mili-giây (nửa giây)
    await Future.delayed(const Duration(milliseconds: 500));
    
    int n = Random().nextInt(100);
    yield n; // Bắn số n ra cho bên ngoài hứng

    if (n == 79) {
      print("Grats (Trúng giải độc đắc 79)!");
      break; // Thoát vòng lặp while, Stream tự động đóng hoàn tất
    }
  }
}

void main() async {
  print('Bắt đầu quay thưởng...');
  
  // Duyệt Stream tự nhiên như duyệt mảng bằng cú pháp 'await for':
  await for (var v in luckyNumber()) {
    print('Số vừa quay được: $v');
  }
  
  print('Kết thúc buổi quay thưởng.');
}

6. Bảng tổng kết phân biệt Future vs Stream

Tiêu chíFuture (Đơn lẻ)Stream (Liên tục)
Số lượng kết quả Chỉ 1 lần duy nhất (Xong là kết thúc). Nhiều lần theo thời gian (0, 1 hoặc vô hạn).
Từ khoá định nghĩa async async*
Cách phát dữ liệu return gia_tri; yield gia_tri;
Cách nhận dữ liệu await myFuture hoặc .then() await for (var v in myStream) hoặc .listen()
Widget trong Flutter FutureBuilder<T> (gọi API lấy bài viết) StreamBuilder<T> (chat realtime, toạ độ GPS)
