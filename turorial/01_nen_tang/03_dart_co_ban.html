Phần 3. Dart cơ bản & Cú pháp cốt lõi

Cẩm nang ngữ pháp nền tảng của Dart trong Flutter: Kiểu dữ liệu, Sound Null Safety, String Interpolation, Toán tử đặc thù (Arithmetic, Cast, Cascade, Null-aware), Các luồng xử lý điều khiển (if-else, switch-case, switch expression, vòng lặp) và Hàm & Tham số.

1. Khai báo biến và Sound Null Safety

Khái niệm

Sound Null Safety trong Dart đảm bảo rằng biến không thể chứa giá trị null trừ khi bạn chủ động thêm dấu chấm hỏi ?. Trình biên dịch sẽ bắt lỗi ngay lúc gõ code, ngăn ngừa lỗi sập app runtime NullPointerException.

Từ khoá / Cú phápVí dụMục đích & Ý nghĩa
int, double, String, bool String title = 'Flutter';
int count = 10;		 Kiểu dữ liệu nguyên thuỷ. Mặc định Non-nullable (không bao giờ được nhận null).
dynamic vs Object? dynamic value = 'abc';
value = 123;
value.someMethod();		 Bỏ qua kiểm tra kiểu lúc biên dịch, chấp nhận mọi kiểu và có thể gán lại sang kiểu khác. Thường thấy trong Map<String, dynamic> khi parse JSON. Cảnh báo: Dễ gây crash lúc chạy nếu gọi phương thức không tồn tại! Khác với Object? (vẫn kiểm tra kiểu chặt chẽ).
var, final, const var a = 5; (gán lại được)
final now = DateTime.now();
const pi = 3.14;		 var: Dart tự suy luận kiểu lúc khai báo (sau đó không thể gán sang kiểu khác).
final: Gán 1 lần duy nhất lúc chạy (run-time).
const: Hằng số bất biến lúc biên dịch (compile-time), giúp Flutter tối ưu bộ nhớ.
Dấu chấm hỏi ? (Nullable) String? username;
int? selectedId;		 Cho phép biến nhận giá trị null. Ban đầu khi chưa gán thì mặc định là null.
Dấu chấm than ! (Null assertion) int len = username!.length; Khẳng định với trình biên dịch là biến chắc chắn không null. Nếu lúc chạy bị null sẽ ném lỗi văng app ngay. Dùng cẩn thận!
Toán tử ?? và ??= String name = input ?? 'Khách';
db ??= await openDB();		 a ?? b: Nếu a null thì lấy giá trị b.
a ??= b: Nếu a đang null thì gán luôn a = b.
Truy cập an toàn ?. int? len = user?.name?.length; Nếu user hoặc name null thì dừng lại trả về null chứ không văng lỗi sập app.
late late final TextEditingController _ctrl; Báo cho Dart biết biến sẽ được gán giá trị trễ hơn (ví dụ trong initState()), nhưng chắc chắn có giá trị trước khi dùng.

2. Chèn chuỗi (String Interpolation)

String Interpolation với $ và ${}

Trong Dart, không nên dùng phép cộng chuỗi "Hello " + name chậm chạp. Thay vào đó, dùng String Interpolation để nhúng trực tiếp biến hoặc biểu thức tính toán vào chuỗi:

Cú phápKhi nào dùngVí dụKết quả in ra
$bien Khi chèn một biến đơn lẻ (tên định danh thông thường). String name = 'Jon';
print('Xin chào $name!');		 Xin chào Jon!
${bieu_thuc} Khi bên trong là biểu thức, phép tính, hoặc truy cập thuộc tính/phương thức (có dấu chấm ., phép toán hoặc dấu ngoặc). print('Độ dài: ${name.length}');
print('Sang năm: ${age + 1}');
print('Giá: ${product['price']}');		 Độ dài: 3
Sang năm: 21
Giá: 75.5
\$ (Thoát ký tự) Khi muốn in ra ký tự $ thật sự (ví dụ đơn vị tiền tệ USD). double price = 9.99;
print('Giá tiền: \$$price');		 Giá tiền: $9.99

3. Các toán tử trong Dart (Operators)

Khái niệm

Ngoài các toán tử số học cơ bản, Dart có nhiều toán tử đặc thù rất mạnh mẽ như toán tử chia lấy nguyên (~/), toán tử kiểm tra & ép kiểu (is, is!, as), chuỗi toán tử Null-aware (??, ??=, ?., !), toán tử bậc 3 (?:), và toán tử Cascade (.., ?..).

Nhóm toán tửKý hiệuÝ nghĩa & Ứng dụngVí dụ
Số học (Arithmetic) +, -, *, /, ~/, % / luôn trả về double.
~/ chia lấy phần nguyên (trả về int).
% chia lấy dư.		 7 / 2 == 3.5
7 ~/ 2 == 3
7 % 2 == 1
Kiểm tra & Ép kiểu is, is!, as is: Kiểm tra thuộc kiểu (true/false) + tự Type Promotion.
is!: Không phải kiểu đó.
as: Ép kiểu (ném lỗi nếu sai).		 if (obj is String) print(obj.length);
(data as Map)['id']
Gán & Gán kết hợp =, +=, -=, *=, ??= a ??= b: Chỉ gán giá trị b cho a nếu a đang là null. int? count;
count ??= 10; // count thành 10
Toán tử 3 ngôi (Ternary) điều_kiện ? a : b Viết gọn if-else để gán giá trị hoặc hiển thị Widget theo trạng thái. isLoading ? CircularProgressIndicator() : Text('Xong')
Null-aware (An toàn Null) ??, ?., ! a ?? b: Lấy b nếu a null.
a?.b: Truy cập an toàn.
a!: Khẳng định khác null.		 String title = name ?? 'Không tên';
int? len = text?.length;
Toán tử Cascade .. hoặc ?.. Thực hiện một chuỗi thao tác/hàm/gán trên cùng một đối tượng mà không cần tạo biến tạm. Paint()..color = Colors.red..strokeWidth = 2.0
Toán tử Spread ... hoặc ...? Trải các phần tử của một Collection vào Collection khác (...? bỏ qua nếu list bị null). [1, ...[2, 3], ...?nullList]
dart - Minh hoạ thực tế các toán tử hay dùng nhất trong Flutter
// 1. Toán tử chia lấy nguyên (~/) - Rất hay dùng chia hàng/cột trong GridView
int totalItems = 25;
int itemsPerRow = 4;
int fullRows = totalItems ~/ itemsPerRow; // = 6 hàng đầy đủ
int remainder = totalItems % itemsPerRow;  // = 1 phần tử lẻ

// 2. Toán tử kiểm tra kiểu (is) và Ép kiểu (as)
void processResponse(dynamic res) {
  // Dart tự động Type Promotion: trong block if, res được coi là Map mà không cần ép kiểu
  if (res is Map) {
    print('Tên người dùng: ${res['name']}');
  } else if (res is! String) {
    print('Không phải chuỗi và cũng không phải Map!');
  }
}

// 3. Toán tử Null-aware (??, ??=, ?.)
String? inputName;
String displayName = inputName ?? 'Khách'; // displayName = 'Khách'

List? tags;
tags ??= []; // Nếu tags đang null thì khởi tạo danh sách rỗng
tags.add('Flutter');

// 4. Toán tử 3 ngôi (? :) trong render giao diện
bool isDarkMode = true;
String currentTheme = isDarkMode ? 'Chế độ tối' : 'Chế độ sáng';

// 5. Toán tử Cascade (..) - Cực tiện khi cấu hình Object
List numbers = [3, 1, 2]
  ..sort()       // Sắp xếp tại chỗ
  ..add(4);      // Thêm 4
// numbers bây giờ là [1, 2, 3, 4]

4. Các luồng xử lý điều khiển (Control Flow: if-else, switch-case, vòng lặp)

Khái niệm

Dart cung cấp đầy đủ các cấu trúc điều khiển rẽ nhánh và vòng lặp quen thuộc (if-else, switch-case, for, for-in, while, do-while). Đặc biệt từ Dart 3.0, Switch Expression & Pattern Matching cho phép switch trả về giá trị trực tiếp cực kỳ ngắn gọn khi render Widget theo trạng thái State.

Cấu trúcCú phápĐặc điểm & Ứng dụng trong Flutter
if - else if - else if (condition) { ... } else { ... } Rẽ nhánh logic theo điều kiện boolean. Dùng xử lý validate form, kiểm tra quyền đăng nhập, check null.
switch - case truyền thống switch (val) { case A: ... break; default: ... } So sánh một biến với nhiều giá trị cố định (int, String, Enum). Dùng để điều hướng màn hình hoặc phân loại lỗi.
Switch Expression (Dart 3+) final widget = switch (state) { State.a => ..., _ => ... }; Cú pháp mới trả về giá trị trực tiếp, không cần case hay break. Rất thích hợp khi render giao diện theo Enum State (Loading / Success / Error).
for & for-in for (var item in list) { ... }
for (int i = 0; i < n; i++)		 Lặp qua danh sách dữ liệu để tính toán, gộp mảng hoặc sinh widget con.
while & do-while while (condition) { ... } Lặp khi điều kiện còn đúng. Thường dùng trong thuật toán phân trang hoặc đọc dữ liệu theo stream/chunk.
break & continue break; (thoát vòng lặp)
continue; (bỏ qua bước hiện tại)		 Điều khiển ngắt vòng lặp khi tìm thấy kết quả hoặc bỏ qua các phần tử không hợp lệ.
dart - Minh hoạ thực tế các luồng xử lý điều khiển
// 1. IF - ELSE VÀ TYPE PROMOTION
void checkLogin(String? token, int roleId) {
  if (token == null || token.isEmpty) {
    print('Chưa đăng nhập!');
  } else if (roleId == 1) {
    print('Chào mừng Quản trị viên (Admin)');
  } else {
    print('Chào mừng Người dùng');
  }
}

// 2. SWITCH TRUYỀN THỐNG VỚI ENUM
enum AuthStatus { initial, loading, authenticated, unauthenticated }

void handleStatus(AuthStatus status) {
  switch (status) {
    case AuthStatus.loading:
      print('Đang tải dữ liệu...');
      break;
    case AuthStatus.authenticated:
      print('Đã xác thực, chuyển vào trang Home');
      break;
    case AuthStatus.unauthenticated:
    case AuthStatus.initial:
      print('Vui lòng đăng nhập');
      break;
  }
}

// 3. SWITCH EXPRESSION HIỆN ĐẠI (Dart 3.0+ - Rất hay dùng trong Flutter UI)
String getStatusMessage(AuthStatus status) => switch (status) {
  AuthStatus.loading => 'Vui lòng chờ...',
  AuthStatus.authenticated => 'Đăng nhập thành công!',
  AuthStatus.unauthenticated => 'Sai tài khoản hoặc mật khẩu',
  _ => 'Trạng thái không xác định', // _ đại diện cho default
};

// 4. CÁC LOẠI VÒNG LẶP (for, for-in, while, break, continue)
List numbers = [1, 2, 3, 4, 5, 6];

// Duyệt for-in bỏ qua số lẻ (continue) và dừng khi gặp số 6 (break)
for (var n in numbers) {
  if (n % 2 != 0) continue; // Bỏ qua số lẻ
  if (n == 6) break;        // Gặp 6 thì dừng lặp
  print('Số chẵn: $n');     // In ra: 2, 4
}

// Vòng lặp while
int count = 3;
while (count > 0) {
  print('Đếm ngược: $count');
  count--;
}

5. Hàm (Functions) và Các loại Tham số

Khái niệm

Flutter dựng UI hoàn toàn bằng cách lồng các Widget (vốn là các class/constructor). Vì vậy, Named Parameters (tham số có tên, bọc trong cặp ngoặc nhọn {}) là cú pháp cốt lõi xuất hiện ở 99% code Flutter.

Loại tham sốCú pháp khai báoVí dụ gọi hàmĐặc điểm & Ứng dụng
1. Vị trí thông thường (Bắt buộc) int add(int a, int b) add(2, 5) Bắt buộc truyền đủ tham số và theo đúng thứ tự.
2. Vị trí tùy chọn (Optional Positional) void greet(String name, [int age = 18]) greet('An')
greet('An', 21)		 Đặt trong [ ], có thể gán giá trị mặc định hoặc kiểu ? (nullable). Truyền theo thứ tự.
3. Tham số có tên bình thường (Optional Named) void setOpt({String theme = 'dark', double font = 14}) setOpt()
setOpt(theme: 'light')		 Đặt trong { }, không bắt buộc truyền (có giá trị mặc định hoặc kiểu ?), khi gọi phải gõ tên theme: ....
4. Tham số có tên bắt buộc (Required Named) void showUser({required String name, required int id}) showUser(name: 'Minh', id: 1)
showUser(id: 2, name: 'Linh')		 Dùng required trong { }. Bắt buộc truyền tên tham số và đối số, thứ tự tùy ý. Cốt lõi của Flutter Widget Constructor!
1. Tham số vị trí (Positional: Thường & Tùy chọn [ ])

Truyền theo đúng vị trí từ trái sang phải.

dart
// Tham số bắt buộc thông thường:
int add(int a, int b) => a + b;

// Tham số vị trí tuỳ chọn [ ] (kèm default value hoặc nullable ?):
void greet(String name, [int? age, int? gender]) {
  print('Chào $name, $age tuổi');
}
void greetWithDefault(String name, [int age = 18]) {
  print('Chào $name, $age tuổi');
}

// Cách gọi:
add(3, 5);                  // Bắt buộc 2 số
greet('Khang');             // age và gender là null
greet('Khang', 20);         // age = 20, gender = null
greetWithDefault('Khang');  // age mặc định là 18
2. Tham số có tên (Named: Bình thường & required)

Bọc trong { }. Gọi bằng tên paramName: value, thứ tự tự do.

dart
// A. Named bình thường (tuỳ chọn, có default value)
void describe({String color = "blue", String size = "medium"}) {
  print("This item is $color and $size");
}

// B. Named bắt buộc (required - thiếu là báo lỗi đỏ ngay)
void greetUser({required String name, int age = 20}) {
  print('Chào $name, $age tuổi');
}

// Cách gọi:
describe();                             // "This item is blue and medium"
describe(size: 'large');                // "This item is blue and large"
describe(color: 'red', size: 'small');  // Thứ tự đảo tuỳ ý

greetUser(name: "Mark");                // name bắt buộc, age lấy 20
greetUser(age: 25, name: "Alice");      // Đúng chuẩn Flutter Widget!
