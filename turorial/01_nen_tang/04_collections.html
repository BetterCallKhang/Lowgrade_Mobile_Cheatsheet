Phần 4. Các tập hợp dữ liệu thường dùng trong Dart & Generics

Hướng dẫn chuyên sâu về Generics (<T>), 3 cấu trúc dữ liệu cốt lõi List, Set, Map cùng danh sách đầy đủ các thuộc tính (properties) và phương thức (methods) kèm code mẫu thực tế ứng dụng trong lập trình Flutter.

1. Generics trong Dart (<T>, <E>, <K, V>)

Khái niệm

Generics (Kiểu tham số hoá) cho phép bạn chỉ định kiểu dữ liệu mà một tập hợp hoặc một lớp có thể chứa bằng cặp ngoặc nhọn <...>. Lợi ích vượt trội của Generics:

  • Bảo đảm an toàn kiểu lúc dịch (Type Safety): Báo lỗi ngay lập tức khi bạn vô tình chèn sai kiểu vào mảng.
  • Giảm thiểu ép kiểu thủ công (No typecasting): Trình biên dịch tự biết chính xác kiểu trả về của từng phần tử.
  • Tái sử dụng code linh hoạt: Viết một hàm hoặc class có thể hoạt động với bất kỳ kiểu dữ liệu nào.
Ký hiệu quy ướcÝ nghĩaVí dụ thực tế trong Flutter
<E> (Element) Phần tử trong danh sách hoặc tập hợp. List<String>, Set<int>, List<Widget>
<K, V> (Key, Value) Khoá và Giá trị trong bảng ánh xạ Map. Map<String, dynamic> (JSON), Map<int, User>
<T> (Type) Kiểu dữ liệu tổng quát bất kỳ cho class hoặc hàm. ApiResponse<T>, Future<T>, Stream<T>
dart - Ví dụ Generics với Class và Hàm
// 1. Nếu không có Generics: phải dùng Object? và ép kiểu thủ công rất rủi ro
List rawList = ['Khang', 20];
// String name = rawList[1]; // Sập runtime lúc chạy vì rawList[1] là số int!

// 2. Khi có Generics: An toàn tuyệt đối lúc biên dịch
List names = ['An', 'Bình'];
// names.add(100); // Lỗi gạch đỏ ngay lập tức: The argument type 'int' can't be assigned to 'String'

// 3. Tự viết Generic Class (Ví dụ chuẩn bọc kết quả trả về từ API)
class ApiResponse {
  final bool success;
  final String? message;
  final T? data; // Kiểu dữ liệu T linh hoạt (có thể là User, List, ...)

  ApiResponse({required this.success, this.message, this.data});
}

void main() {
  // T biến thành String
  var res1 = ApiResponse(success: true, data: 'Token_123');
  print(res1.data?.length);

  // T biến thành int
  var res2 = ApiResponse(success: true, data: 200);
  print(res2.data);
}

2. Bảng so sánh 3 cấu trúc dữ liệu cốt lõi

Tập dữ liệuCú pháp khai báoĐặc điểm chínhỨng dụng điển hình trong Flutter
List<E> (Mảng/Danh sách) List<String> items = ['A', 'B', 'A']; - Có thứ tự (ordered), truy xuất qua chỉ mục index [0].
- Cho phép phần tử trùng lặp.
- Có thể thêm/xoá linh hoạt.		 Dùng trực tiếp trong ListView.builder, GridView.builder, danh sách sản phẩm, feed tin tức.
Set<E> (Tập hợp duy nhất) Set<int> ids = {1, 2, 3, 2}; // {1, 2, 3} - Các phần tử hoàn toàn duy nhất (không trùng).
- Tốc độ kiểm tra contains() là O(1) cực nhanh.
- Dễ dàng lọc trùng: list.toSet().toList().		 Lưu ID các phần tử đã chọn (Multi-select), danh sách tags sản phẩm, tập hợp quyền hạn người dùng.
Map<K, V> (Key-Value) Map<String, dynamic> user = {'id': 1}; - Lưu trữ theo cặp Khoá & Giá trị: map['key'].
- Khoá (Key) là duy nhất.
- Trả về null nếu key không tồn tại.		 Làm việc với JSON REST API (jsonDecode), dữ liệu lưu trữ cấu hình SharedPreferences, dòng SQLite.

3. List<E>: Các biến và hàm thông dụng

Tên thuộc tính / HàmMục đíchVí dụ & Kết quả
.length Độ dài (số lượng phần tử) của danh sách. [1, 2, 3].length == 3
.isEmpty / .isNotEmpty Kiểm tra danh sách rỗng hay không. if (posts.isEmpty) return Text('Không có dữ liệu');
.first / .last Lấy phần tử đầu tiên hoặc cuối cùng. [10, 20, 30].first == 10; [10, 20, 30].last == 30
.reversed Đảo ngược thứ tự phần tử. [1, 2, 3].reversed.toList() // [3, 2, 1]
.add(e) / .addAll([...]) Thêm một hoặc nhiều phần tử vào cuối. list.add(4); list.addAll([5, 6]);
.insert(idx, e) Chèn phần tử vào vị trí index cụ thể. ['B', 'C'].insert(0, 'A') // ['A', 'B', 'C']
.remove(e) / .removeAt(idx) Xoá phần tử theo giá trị hoặc theo chỉ số index. list.remove('An'); list.removeAt(0);
.removeWhere(test) Xoá tất cả phần tử thoả điều kiện. numbers.removeWhere((n) => n < 0); // Xoá số âm
.contains(e) Kiểm tra phần tử có nằm trong list không. [1, 2, 3].contains(2) == true
.indexOf(e) Tìm chỉ mục index đầu tiên của phần tử (-1 nếu không thấy). ['a', 'b'].indexOf('b') == 1
.sublist(start, [end]) Cắt một đoạn danh sách con. [1, 2, 3, 4, 5].sublist(1, 3) // [2, 3]
.sort([compare]) Sắp xếp tại chỗ (in-place) theo thứ tự tăng/giảm dần. numbers.sort((a, b) => b.compareTo(a)); // Giảm dần
.where((e) => bool) Lọc các phần tử thoả mãn điều kiện (tương đương filter). scores.where((s) => s >= 5).toList()
.map((e) => newT) Biến đổi từng phần tử sang kiểu dữ liệu mới. items.map((item) => Text(item.name)).toList()
.any(test) / .every(test) Kiểm tra có ít nhất 1 (any) hoặc toàn bộ (every) thoả điều kiện. scores.any((s) => s >= 9); scores.every((s) => s >= 5);
.fold(initial, combine) Gộp và tính toán tích luỹ (ví dụ tính tổng tiền giỏ hàng). items.fold(0.0, (sum, i) => sum + i.price);
.firstWhere(test, orElse) Tìm phần tử đầu tiên thoả điều kiện (có fallback). users.firstWhere((u) => u.id == 1, orElse: () => null);

4. Set<E>: Các biến và hàm thông dụng

Tên thuộc tính / HàmMục đíchVí dụ & Kết quả
.length, .isEmpty Số lượng phần tử duy nhất, kiểm tra rỗng. {1, 2, 2}.length == 2
.add(e) / .addAll(iterable) Thêm phần tử (nếu đã tồn tại sẽ tự động bỏ qua). tags.add('Flutter');
.remove(e) Xoá phần tử khỏi Set. selectedIds.remove(10);
.contains(e) Kiểm tra tồn tại với độ phức tạp thời gian cực nhanh O(1). selectedIds.contains(productId)
.union(otherSet) Hợp hai tập hợp (lấy tất cả không trùng lặp). {1, 2}.union({2, 3}) // {1, 2, 3}
.intersection(otherSet) Giao hai tập hợp (lấy các phần tử chung). {1, 2}.intersection({2, 3}) // {2}
.difference(otherSet) Hiệu hai tập hợp (phần tử có ở Set hiện tại nhưng không có ở other). {1, 2}.difference({2, 3}) // {1}
.toList() Chuyển đổi Set trở lại thành List để render lên giao diện. uniqueCategories.toList()

5. Map<K, V>: Các biến và hàm thông dụng

Tên thuộc tính / HàmMục đíchVí dụ & Kết quả
.keys / .values Lấy toàn bộ danh sách khoá (Keys) hoặc giá trị (Values). user.keys.toList(); user.values.toList();
.entries Lấy danh sách các cặp MapEntry(key, value). user.entries.map((e) => Text('${e.key}: ${e.value}'))
.containsKey(k) Kiểm tra khoá key có tồn tại trong Map không (an toàn tránh null). if (json.containsKey('avatar')) { ... }
.containsValue(v) Kiểm tra xem giá trị value có trong Map không. user.containsValue('admin')
.putIfAbsent(k, () => v) Chỉ thêm key-value vào nếu key đó chưa tồn tại trong Map. config.putIfAbsent('theme', () => 'dark');
.update(k, (v) => newV) Cập nhật giá trị của một key cụ thể dựa trên giá trị hiện tại. cart.update('apple', (qty) => qty + 1, ifAbsent: () => 1);
.remove(k) Xoá cặp key-value khỏi Map và trả về giá trị vừa xoá. user.remove('password');
.forEach((k, v) => ...) Duyệt lặp qua từng cặp key-value. map.forEach((k, v) => print('$k = $v'));
.map((k, v) => MapEntry(...)) Biến đổi toàn bộ Map sang một Map mới. prices.map((k, v) => MapEntry(k, v * 1.1));

6. Kỹ thuật cao cấp: Spread (...), Collection If & Collection For

Khái niệm

Đây là 3 tính năng cực kỳ mạnh mẽ của Dart giúp bạn viết UI linh động ngay trong mảng Widget children: [...] của Column hoặc Row mà không cần viết các hàm nối mảng phức tạp.

dart - Spread, Collection If & For thực chiến trong Flutter
bool isLoggedIn = true;
bool isVip = false;
List baseMenu = ['Trang chủ', 'Sản phẩm'];
List adminMenu = ['Quản trị', 'Doanh thu'];

// Kết hợp tất cả vào 1 List duy nhất
List finalMenu = [
  ...baseMenu,                                    // 1. Spread: Trải toàn bộ phần tử baseMenu
  if (isLoggedIn) 'Hồ sơ cá nhân',                // 2. Collection If: Chỉ chèn nếu đăng nhập
  if (isVip) 'Đặc quyền VIP' else 'Nâng cấp VIP', // Collection If-Else
  if (isLoggedIn) ...adminMenu,                   // Trải danh sách admin có điều kiện
  for (int i = 1; i <= 3; i++) 'Mục bổ sung $i',  // 3. Collection For: Sinh phần tử lặp
];

// Tương tự với Map:
Map userProfile = {
  'username': 'bettercallkhang',
  'role': 'editor',
  if (isVip) 'badge': 'Kim cương',
};
