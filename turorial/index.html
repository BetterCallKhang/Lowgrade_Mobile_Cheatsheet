Flutter & Dart Cheatsheet

Cẩm nang thực hành, tra cứu cú pháp, cấu trúc code, xử lý lỗi và quy trình làm bài thực hành, đồ án và ôn thi PE Flutter từ cơ bản đến nâng cao. Mỗi nội dung đều được phân tách thành từng chuyên đề độc lập, kèm ví dụ chạy thực tế và giải thích chi tiết có dấu chuẩn xác.

Danh mục các phần học & tra cứu

Nhóm 1: Nền tảng Công cụ & Ngôn ngữ Dart

Môi trường phát triển, công cụ gỡ lỗi và ngữ pháp ngôn ngữ lập trình Dart cốt lõi:

  • Phần 1. Setup, Format & Cấu trúc dự án: Cài đặt SDK, cấu hình biến môi trường PATH, Android Studio, bảng phím tắt, định dạng code chuẩn.
  • Phần 2. Debug & Tra cứu lỗi thường gặp: Cách đọc stack trace, lỗi màn hình đỏ, lỗi vạch sọc vàng-đen layout, sửa lỗi Gradle và build Android.
  • Phần 3. Dart cơ bản & Luồng xử lý: Null Safety, String Interpolation, Toán tử đặc thù, If-Else, Switch Expression (Dart 3+), Vòng lặp, Hàm & Tham số bắt buộc (required).
  • Phần 4. Tập dữ liệu & Generics: Kiểu Generics (<T>), các thuộc tính và hàm thông dụng của List, Set, Map, kỹ thuật Spread (...), Collection If/For.
  • Phần 5. OOP & Model JSON: Constructor chuẩn, Initializer List, thuộc tính Private, Kế thừa, Interface ngầm định, Mixin, Extension Methods, Model fromJson/toJson.
  • Phần 6. Bất đồng bộ (Future & Stream): Bản chất Event Loop, cơ chế dây chuyền .then(), async/await, Stream dòng chảy dữ liệu với async* và yield.
Nhóm 2: Giao diện (UI), State & Cơ sở dữ liệu

Các kiến trúc ứng dụng giao diện Flutter hoàn chỉnh:

  • Mục 1. Toàn diện về Flutter Widgets: Khái niệm Widget, bộ 3 cây (Widget - Element - Render), StatelessWidget vs StatefulWidget & Lifecycle, MaterialApp & Scaffold Anatomy, cơ chế setState(), ListView, Card, ListTile kèm ảnh, GridView và bộ sưu tập các input widget thường dùng (Button, TextField, Checkbox, Switch, RadioListTile, Slider...).
  • Mục 2. ThemeData & Drawer: Định nghĩa Theme, lý do sử dụng, cấu hình ColorScheme.fromSeed, copyWith, và Drawer chọn 3 màu (Pink, Teal, Orange) kèm Dark Mode và Banner.
  • Mục 3. Navigation & Route: Cơ chế ngăn xếp LIFO (Route Stack), bản chất Widget Navigator & các tham số (initialRoute, onGenerateRoute, onUnknownRoute, observers, pages), so sánh MaterialPageRoute vs Named Routes, truyền nhận dữ liệu 2 chiều (await push, pop result), và Deep Linking — Giải phẫu cấu trúc đường link (Anatomy of a Link: Scheme, Host, Path, Query Params) xử lý qua onGenerateRoute.
  • Mục 4. Layout, Multi-Child Widgets & Responsive Design: Phân tích sâu BoxConstraints (Quy tắc "Constraints down, Sizes up, Parent sets position"), bố cục tuyến tính Row / Column / Flex (MainAxis vs CrossAxis), bố cục xếp lớp Stack & Positioned / Align, bố cục dạng lưới GridView (.count, .extent, .builder & SliverGridDelegate), co giãn linh hoạt Expanded, Flexible, Wrap, FittedBox, AspectRatio, FractionallySizedBox, phân biệt Responsive vs Adaptive và áp dụng thực tế dự án adaptive_layout (20 thẻ sản phẩm đổi số cột khi xoay, Drawer tự biến đổi thành Side Panel cố định).
  • Mục 5. Form, TextEditingController & Validation: Bản chất Form và Validation, tại sao cần thiết, phân biệt TextField vs TextFormField, vai trò và vòng đời của TextEditingController kèm dispose() bắt buộc chống rò rỉ bộ nhớ, cách dùng GlobalKey<FormState>, toàn bộ công thức validator thường dùng (bắt buộc, độ dài, regex email, số thực, so khớp mật khẩu), kịch bản Create vs Edit form và dự án thực hành hoàn chỉnh.
  • Mục 6. Call REST API với http & dio: Quy trình soi JSON thực tế, tạo Model, fetch API GET/POST, bảng mã HTTP Status Code, nâng cao với thư viện dio.
  • Mục 7. Quản lý State với Riverpod: State là gì, so sánh Provider vs Riverpod, hệ sinh thái thư viện (flutter_riverpod, riverpod_annotation, build_runner, riverpod_generator), quy tắc sinh file .g.dart, ref.watch vs ref.read và dự án REST Users thực chiến.
  • Mục 8. Lưu trữ cục bộ với SharedPreferences: Lưu trữ Primitive Types, StringList JSON, Token JWT, cấu hình Theme và quản lý đồng bộ với Riverpod.
  • Mục 9. Cơ sở dữ liệu SQLite & Full CRUD: Bản chất SQLite, Singleton DatabaseHelper, bộ 4 thao tác CRUD, Riverpod AsyncNotifier, giải quyết trọn vẹn 7 yêu cầu thi thực hành (Validation, Confirm Dialog, SnackBar, Dispose Controller).
