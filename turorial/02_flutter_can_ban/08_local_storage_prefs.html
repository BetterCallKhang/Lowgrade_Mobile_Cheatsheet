Mục 8. Lưu Trữ Dữ Liệu Cục Bộ (Local Storage) Với shared_preferences & Riverpod

Hướng dẫn toàn diện từ cơ chế bản chất đến thực chiến: Local Storage là gì? Vì sao dùng? Dùng khi nào? So sánh các giải pháp lưu trữ, phân tích các thư viện đi kèm, từng bước nhỏ chi tiết xây dựng app Quản lý Ghi chú (CRUD Notes lưu JSON StringList) kết hợp Riverpod + Code Generation, lưu cấu hình cài đặt, và mô hình xác thực JWT Token thực tế.

1. Bản Chất: Local Storage Là Gì? Dùng Thế Nào? Vì Sao Phải Dùng?

1.1. Local Storage là gì?

Trong ứng dụng di động, các biến và State lưu trên RAM (bộ nhớ tạm) sẽ bị xóa sạch ngay khi người dùng vuốt đóng ứng dụng (Kill App) hoặc hệ điều hành thu hồi bộ nhớ. Local Storage (Lưu trữ cục bộ) là cơ chế ghi dữ liệu xuống bộ nhớ vật lý (Flash Storage/Disk) của điện thoại để dữ liệu vẫn tồn tại vĩnh viễn kể cả khi tắt máy, tắt nguồn khởi động lại.

Bộ Nhớ RAM (State / Biến)

Tốc độ cực nhanh nhưng là bộ nhớ tạm thời (Volatile). Tắt app, tắt màn hình lâu hoặc máy hết RAM là mất toàn bộ dữ liệu người dùng đang làm việc.

Mất dữ liệu khi kill app
Local Storage (Disk / Máy máy)

Lưu dữ liệu bền vững ngay trên thiết bị (Persistence). Mở lại ứng dụng là đọc ra ngay, không cần kết nối Internet / Wifi / 4G.

Bền vững, Offline-first
Remote Storage (Server Cloud API)

Lưu trên Database máy chủ (MySQL, Mongo, Firebase). Đồng bộ nhiều thiết bị nhưng bắt buộc phải có mạng và độ trễ cao.

Cần Internet & Call API

1.2. Vì sao và khi nào chúng ta dùng Local Storage?

  • Duy trì phiên đăng nhập (Auth Session): Lưu lại mã token accessToken, refreshToken sau khi Login API thành công, giúp người dùng không phải nhập lại mật khẩu mỗi lần mở app.
  • Lưu cấu hình & Trải nghiệm cá nhân (User Preferences): Trạng thái Dark Mode/Light Mode, ngôn ngữ ứng dụng (vi/en), âm lượng, cờ đã xem màn hình giới thiệu (isFirstOpen = false).
  • Bộ nhớ đệm Offline (Caching) & CRUD cơ bản: Lưu danh sách ghi chú (Notes), danh sách yêu thích, giỏ hàng tạm thời để khi mất mạng người dùng vẫn xem và chỉnh sửa được bình thường.

1
Tạo Model Note Hỗ Trợ Chuyển Đổi JSON (lib/model/note.dart)

shared_preferences không hỗ trợ lưu thẳng Object Dart tuỳ ý. Muốn lưu được một danh sách ghi chú, ta phải chuyển đổi Object sang Map JSON → Mã hóa chuỗi String (jsonEncode).

lib/model/note.dart 
class Note {
  int id;
  String title;
  String content;

  Note(this.id, this.title, this.content);

  // 1. Chuyển đổi từ Map JSON sang Object Note (Đọc từ máy lên)
  factory Note.fromJson(Map<String, dynamic> json) {
    return Note(
      json['id'] as int,
      json['title'] as String,
      json['content'] as String,
    );
  }

  // 2. Chuyển đổi từ Object Note sang Map JSON (Chuẩn bị ghi xuống máy)
  Map<String, dynamic> toJson() {
    return {
      'id': id,
      'title': title,
      'content': content,
    };
  }
}
2
Khai Báo sharedPreferencesProvider (lib/providers/shared_preferences_provider.dart)

Hàm lấy SharedPreferences.getInstance() là bất đồng bộ (Future). Để không phải await mỗi khi đọc hay ghi dữ liệu trong UI, ta tạo 1 Provider giữ giá trị đồng bộ và cố tình throw UnimplementedError() để ghi đè (override) lúc khởi động ứng dụng.

lib/providers/shared_preferences_provider.dart 
import 'package:riverpod_annotation/riverpod_annotation.dart';
import 'package:shared_preferences/shared_preferences.dart';

part 'shared_preferences_provider.g.dart';

// Khai báo Provider cung cấp instance SharedPreferences cho toàn bộ ứng dụng
@riverpod
SharedPreferences sharedPreferences(Ref ref) {
  // Chủ động throw Exception vì Provider này bắt buộc sẽ được ghi đè (overrideWithValue)
  // ngay từ hàm main() trước khi bất kỳ Widget nào được vẽ
  throw UnimplementedError('sharedPreferencesProvider must be overridden in ProviderScope');
}
3
Khởi Tạo Máy & Override Provider trong lib/main.dart

Sử dụng WidgetsFlutterBinding.ensureInitialized() để chắc chắn Flutter Engine đã kết nối với tầng hệ điều hành Native, sau đó lấy instance và truyền vào overrides của ProviderScope.

lib/main.dart 
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:local_storage/providers/shared_preferences_provider.dart';
import 'package:local_storage/ui/note_list_screen.dart';
import 'package:shared_preferences/shared_preferences.dart';

void main() async {
  // 1. Đảm bảo cầu nối Flutter Engine với Native OS đã sẵn sàng trước khi gọi hàm Async
  WidgetsFlutterBinding.ensureInitialized();

  // 2. Đọc khởi tạo SharedPreferences từ bộ nhớ máy người dùng
  final prefsInstance = await SharedPreferences.getInstance();

  runApp(
    ProviderScope(
      // 3. Ghi đè (override) provider với instance đã sẵn sàng
      overrides: [
        sharedPreferencesProvider.overrideWithValue(prefsInstance),
      ],
      child: const MyApp(),
    ),
  );
}

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      debugShowCheckedModeBanner: false,
      title: 'Local Storage Demo',
      theme: ThemeData(
        colorScheme: ColorScheme.fromSeed(seedColor: Colors.deepPurple),
        useMaterial3: true,
      ),
      home: const NoteListScreen(),
    );
  }
}
4
Xây Dựng NoteNotifier Thực Hiện Đọc/Ghi/Xóa/Sửa (lib/providers/note_notifier.dart)

Notifier đóng vai trò giữ trạng thái List<Note> trên RAM và tự động đồng bộ hóa xuống bộ nhớ Disk qua chìa khóa _notesKey = 'notes'.

lib/providers/note_notifier.dart 
import 'dart:convert';
import 'package:local_storage/model/note.dart';
import 'package:local_storage/providers/shared_preferences_provider.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';

part 'note_notifier.g.dart';

@riverpod
class NoteNotifier extends _$NoteNotifier {
  // Key định danh duy nhất để lưu và đọc dữ liệu trong Local Storage
  static const String _notesKey = 'notes';

  // Hàm khởi tạo State: Chạy đầu tiên khi Widget đọc Provider
  @override
  List<Note> build() {
    return _loadNotesFromStorage();
  }

  // ================= 1. READ (ĐỌC TỪ LOCAL STORAGE LÊN RAM) =================
  List<Note> _loadNotesFromStorage() {
    final prefs = ref.read(sharedPreferencesProvider);
    // Đọc danh sách chuỗi (StringList), nếu chưa có dữ liệu thì trả về mảng rỗng []
    final List<String> notesJsonList = prefs.getStringList(_notesKey) ?? [];

    // Duyệt từng chuỗi JSON -> giải mã jsonDecode -> chuyển thành Object Note
    final notes = notesJsonList
        .map((noteString) => Note.fromJson(jsonDecode(noteString) as Map<String, dynamic>))
        .toList();

    return notes;
  }

  // ================= 2. PERSIST (LƯU TOÀN BỘ STATE XUỐNG DISK) =================
  Future<void> _saveNotesToStorage() async {
    final prefs = ref.read(sharedPreferencesProvider);
    // Biến toàn bộ Object Note trong state -> Map (toJson) -> Chuỗi JSON (jsonEncode)
    final List<String> noteStringList =
        state.map((note) => jsonEncode(note.toJson())).toList();

    // Ghi xuống bộ nhớ máy qua SharedPreferences
    await prefs.setStringList(_notesKey, noteStringList);
  }

  // ================= 3. CREATE (THÊM GHI CHÚ MỚI) =================
  Future<void> addNote(String title, String content) async {
    final newNote = Note(
      DateTime.now().millisecondsSinceEpoch, // Sinh ID duy nhất theo mốc thời gian
      title,
      content,
    );

    // BẮT BUỘC: Tạo mảng mới bằng spread operator [...] để Riverpod phát hiện state thay đổi
    // TUYỆT ĐỐI KHÔNG DÙNG: state.add(newNote) -> Không kích hoạt render lại UI
    state = [...state, newNote];

    // Lưu bền vững xuống Disk
    await _saveNotesToStorage();
  }

  // ================= 4. DELETE (XÓA THEO ID) =================
  Future<void> deleteNote(int id) async {
    // Lọc lấy các note có ID khác với ID cần xóa
    state = state.where((note) => note.id != id).toList();

    // Đồng bộ lại Disk
    await _saveNotesToStorage();
  }

  // ================= 5. UPDATE (SỬA NỘI DUNG GHI CHÚ) =================
  Future<void> editNote(Note updatedNote) async {
    // Duyệt mảng và thay thế note có ID tương ứng
    state = [
      for (final note in state)
        if (note.id == updatedNote.id) updatedNote else note
    ];

    // Đồng bộ lại Disk
    await _saveNotesToStorage();
  }
}
Lưu ý cực kỳ quan trọng về Immutability

Trong Riverpod, state là bất biến (Immutable). Nếu bạn dùng state.add(item) hoặc state.remove(item), vùng nhớ (Memory Reference) của List không đổi, Riverpod sẽ coi như State chưa từng thay đổi và giao diện sẽ đứng im không cập nhật. Hãy luôn gán mảng mới: state = [...state, newItem];.

6. Giao Diện Hiển Thị & Thao Tác (lib/ui/note_list_screen.dart)

Màn hình kết hợp hiển thị lưới GridView 2 cột, nút bấm mở Dialog nhập liệu (Add Note), nút sửa và nút xóa tương tác trực tiếp với State.

lib/ui/note_list_screen.dart 
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:local_storage/model/note.dart';
import 'package:local_storage/providers/note_notifier.dart';

// 1. Kế thừa ConsumerWidget để dùng đối tượng 'ref'
class NoteListScreen extends ConsumerWidget {
  const NoteListScreen({super.key});

  // Hộp thoại nhập tiêu đề & nội dung ghi chú (Dùng chung cho cả Thêm và Sửa)
  void _showNoteDialog(BuildContext context, WidgetRef ref, [Note? existingNote]) {
    final titleController = TextEditingController(text: existingNote?.title ?? '');
    final contentController = TextEditingController(text: existingNote?.content ?? '');

    showDialog(
      context: context,
      builder: (ctx) => AlertDialog(
        title: Text(existingNote == null ? 'Thêm Ghi Chú Mới' : 'Chỉnh Sửa Ghi Chú'),
        content: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            TextField(
              controller: titleController,
              decoration: const InputDecoration(
                labelText: 'Tiêu đề',
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 12),
            TextField(
              controller: contentController,
              maxLines: 3,
              decoration: const InputDecoration(
                labelText: 'Nội dung',
                border: OutlineInputBorder(),
              ),
            ),
          ],
        ),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(ctx),
            child: const Text('Hủy'),
          ),
          FilledButton(
            onPressed: () {
              final title = titleController.text.trim();
              final content = contentController.text.trim();
              if (title.isEmpty) return;

              if (existingNote == null) {
                // Gọi notifier để thêm mới
                ref.read(noteProvider.notifier).addNote(title, content);
              } else {
                // Gọi notifier để cập nhật
                ref.read(noteProvider.notifier).editNote(
                  Note(existingNote.id, title, content),
                );
              }
              Navigator.pop(ctx);
            },
            child: const Text('Lưu'),
          ),
        ],
      ),
    );
  }

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // 2. ref.watch lắng nghe danh sách notes. Bất kỳ khi nào State đổi, Widget sẽ tự vẽ lại!
    final List<Note> notes = ref.watch(noteProvider);

    return Scaffold(
      appBar: AppBar(
        title: const Text('Sổ Tay Ghi Chú (Local Storage)'),
        backgroundColor: Theme.of(context).colorScheme.inversePrimary,
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: () => _showNoteDialog(context, ref),
        icon: const Icon(Icons.add),
        label: const Text('Thêm Note'),
      ),
      body: notes.isEmpty
          ? const Center(
              child: Column(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  Icon(Icons.note_alt_outlined, size: 64, color: Colors.grey),
                  SizedBox(height: 12),
                  Text('Chưa có ghi chú nào trong máy!\nHãy bấm nút "Thêm Note" bên dưới.',
                      textAlign: TextAlign.center,
                      style: TextStyle(color: Colors.grey, fontSize: 16)),
                ],
              ),
            )
          : Padding(
              padding: const EdgeInsets.all(12.0),
              child: GridView.builder(
                gridDelegate: const SliverGridDelegateWithFixedCrossAxisCount(
                  crossAxisCount: 2,
                  childAspectRatio: 0.95,
                  crossAxisSpacing: 10,
                  mainAxisSpacing: 10,
                ),
                itemCount: notes.length,
                itemBuilder: (context, index) {
                  final note = notes[index];
                  return Card(
                    elevation: 3,
                    shape: RoundedRectangleBorder(borderRadius: BorderRadius.circular(12)),
                    child: Padding(
                      padding: const EdgeInsets.all(12.0),
                      child: Column(
                        crossAxisAlignment: CrossAxisAlignment.start,
                        children: [
                          Row(
                            mainAxisAlignment: MainAxisAlignment.spaceBetween,
                            children: [
                              Expanded(
                                child: Text(
                                  note.title,
                                  style: const TextStyle(fontWeight: FontWeight.bold, fontSize: 16),
                                  maxLines: 1,
                                  overflow: TextOverflow.ellipsis,
                                ),
                              ),
                              IconButton(
                                constraints: const BoxConstraints(),
                                padding: EdgeInsets.zero,
                                icon: const Icon(Icons.delete_outline, color: Colors.redAccent, size: 20),
                                onPressed: () {
                                  // Xóa note khỏi RAM & Local Storage
                                  ref.read(noteProvider.notifier).deleteNote(note.id);
                                },
                              ),
                            ],
                          ),
                          const Divider(),
                          Expanded(
                            child: Text(
                              note.content,
                              style: const TextStyle(color: Colors.black87),
                              overflow: TextOverflow.fade,
                            ),
                          ),
                          Align(
                            alignment: Alignment.bottomRight,
                            child: IconButton(
                              icon: const Icon(Icons.edit_note, size: 22, color: Colors.blueAccent),
                              onPressed: () => _showNoteDialog(context, ref, note),
                            ),
                          )
                        ],
                      ),
                    ),
                  );
                },
              ),
            ),
    );
  }
}

7. Các Kịch Bản Thực Chiến Khác Của Local Storage

1. Lưu Trạng Thái Cài Đặt (Dark / Light Mode)

Lưu biến Boolean đơn giản vào bộ nhớ máy để mở app lên là giữ nguyên giao diện người dùng yêu thích:

Theme Settings Example
// 1. Lưu cờ Dark Mode
Future<void> saveDarkMode(bool isDark) async {
  final prefs = await SharedPreferences.getInstance();
  await prefs.setBool('is_dark_mode', isDark);
}

// 2. Đọc khi khởi động
Future<bool> loadDarkMode() async {
  final prefs = await SharedPreferences.getInstance();
  return prefs.getBool('is_dark_mode') ?? false; // mặc định sáng
}
2. Lưu JWT Token Khi Đăng Nhập (Login Auth)

Lưu chuỗi Access Token nhận về từ REST API sau khi Login thành công và tự động xóa khi Đăng xuất (Logout):

Auth Storage Example
// Lưu Token sau khi POST Login thành công (200 OK)
final prefs = await SharedPreferences.getInstance();
await prefs.setString('accessToken', responseData['accessToken']);
await prefs.setString('username', responseData['username']);

// Kiểm tra khi vừa mở app
final token = prefs.getString('accessToken');
if (token != null) {
  // Đã đăng nhập -> Nhảy thẳng vào HomeScreen
} else {
  // Chưa đăng nhập -> Hiện LoginScreen
}

// Khi người dùng bấm Logout
await prefs.remove('accessToken');
await prefs.remove('username');

8. Bảng Lỗi Thường Gặp & Cách Khắc Phục (Troubleshooting)

Triệu chứng lỗi Nguyên nhân gốc rễ Cách khắc phục triệt để
Binding has not been initialized Gọi SharedPreferences.getInstance() trong hàm main() trước khi Flutter Engine kết nối xong. Thêm dòng WidgetsFlutterBinding.ensureInitialized(); lên dòng đầu tiên của main().
UnimplementedError khi gọi ref.read(sharedPreferencesProvider) Quên truyền overrides: [sharedPreferencesProvider.overrideWithValue(...)] trong ProviderScope. Kiểm tra lại cấu trúc file main.dart, đảm bảo runApp(ProviderScope(overrides: [...], child: MyApp())) đã có override.
Dữ liệu biến mất khi tắt app mở lại (Data not persisting) Chỉ thay đổi state trên RAM mà quên gọi hàm ghi await prefs.setStringList(...) xuống Disk. Mỗi lần thực hiện Create / Update / Delete xong, phải luôn gọi hàm await _saveNotesToStorage();.
Giao diện không tự động vẽ lại sau khi thêm hoặc xóa Note Sử dụng phương thức làm biến đổi mảng gốc như state.add() thay vì tạo mảng mới. Dùng cú pháp trải (spread operator): state = [...state, newNote];.
Báo lỗi đỏ không tìm thấy class NoteNotifierProvider hoặc file .g.dart Chưa chạy lệnh sinh mã tự động sau khi viết xong annotation @riverpod. Chạy Terminal: dart run build_runner build --delete-conflicting-outputs.
