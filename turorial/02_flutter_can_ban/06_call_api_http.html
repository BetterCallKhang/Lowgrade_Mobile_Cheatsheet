Mục 6. Quy trình Gọi REST API thực chiến với gói http & dio

Hướng dẫn từng bước nhỏ (Step-by-step) cách làm việc với API: Soi trước cấu trúc JSON trả về → Xây dựng Model Class (fromJson/toJson) → Viết hàm gọi API (GET, POST) → Parse JSON & Bắt lỗi mạng chuẩn theo đúng đề bài thực hành và thi PE.

Các nguồn REST API mở miễn phí để luyện tập (Mock & Public APIs)

Tài nguyên tham khảo trực tiếp

Trước khi viết code, bạn có thể bấm thẳng vào các đường link API mở bên dưới trên trình duyệt để soi cấu trúc JSON mẫu:

  • Chi tiết 1 bài viết (Post ID 3): https://jsonplaceholder.typicode.com/posts/3 (Trả về 1 Object)
  • Danh sách tất cả bài viết: https://jsonplaceholder.typicode.com/posts (Trả về 1 List 100 posts)
  • Danh sách người dùng (Users): https://jsonplaceholder.typicode.com/users (Trả về List User có thông tin id, name, email, phone, address...)
  • Danh sách sản phẩm (E-commerce): https://fakestoreapi.com/products (Dùng cho bài tập bán hàng, có hình ảnh, giá tiền, rating)

Bước 2: Soi cấu trúc JSON mà API trả về (Đề bài thực tế)

Quy tắc vàng khi làm API

Tuyệt đối không viết code mò mẫm! Trước khi gõ code, bạn phải mở trình duyệt hoặc phần mềm Postman/Thunder Client truy cập vào URL API để xem nó trả về cấu trúc gì (dạng Object { } hay dạng List [ ], gồm những trường nào, kiểu dữ liệu là số hay chữ).

Đề bài: Cho URL API https://jsonplaceholder.typicode.com/posts/3

Khi mở link trên trình duyệt, API trả về đoạn JSON nguyên thuỷ như sau:

json - Cấu trúc API trả về
{
  "userId": 1,
  "id": 3,
  "title": "ea molestias quasi exercitationem repellat qui ipsa sit aut",
  "body": "et iusto sed quo iure\nvoluptatem occaecati omnis eligendi aut ad\nvoluptatem doloribus vel accusantium quis pariatur\nmolestiae porro eius odio et labore et velit aut"
}

Phân tích dữ liệu:

  • Đây là 1 Object (bọc trong { }), tương ứng với kiểu Map<String, dynamic> trong Dart.
  • Có 4 trường: userId (int), id (int), title (String), và body (String).

Bước 3: Tạo Model Class chuẩn (Post.dart)

3
Tạo file lib/Post.dart dựa đúng theo các trường JSON vừa soi

Tạo class có đủ các thuộc tính, constructor, factory fromJson để nhào nặn Map thành Object, và toJson / toString:

dart - lib/Post.dart
class Post {
  final int userId;
  final int id;
  final String title;
  final String body;

  // Constructor với Named Parameters (hoặc Positional tuỳ ý)
  Post({
    required this.userId,
    required this.id,
    required this.title,
    required this.body,
  });

  // Factory constructor: Nhận Map JSON và trả về một Object Post hoàn chỉnh
  // Kèm toán tử ?? fallback để tránh bị crash nếu API trả về null
  factory Post.fromJson(Map json) {
    return Post(
      userId: json['userId'] as int? ?? 0,
      id: json['id'] as int? ?? 0,
      title: json['title'] as String? ?? '',
      body: json['body'] as String? ?? '',
    );
  }

  // Chuyển Object thành Map nếu muốn gửi lên server
  Map toJson() {
    return {
      'userId': userId,
      'id': id,
      'title': title,
      'body': body,
    };
  }

  // In thông tin đẹp mắt khi print(post)
  @override
  String toString() {
    return 'Post{userId: $userId, id: $id, title: "$title"}';
  }
}

Bước 4: Viết hàm gọi API và chuyển đổi dữ liệu

4
Quy trình xử lý chuẩn 4 bước bên trong hàm Fetch:
  1. Chuyển chuỗi URL thành Uri: Uri.parse(...).
  2. Gọi phương thức HTTP: await http.get(url).
  3. Kiểm tra mã trạng thái (Status Code): Kiểm tra response.statusCode == 200.
  4. Giải mã chuỗi văn bản sang JSON Map/List: jsonDecode(response.body) rồi đẩy qua Post.fromJson().
dart - lib/main.dart - Hàm fetchPost và fetchAllPosts
import 'dart:convert';               // Cần gói này để dùng hàm jsonDecode()
import 'package:http/http.dart' as http; // Import thư viện http đặt bí danh là 'http'
import 'Post.dart';

// 1. Hàm GET 1 bài viết theo ID
Future fetchPost(int id) async {
  final url = Uri.parse('https://jsonplaceholder.typicode.com/posts/$id');

  try {
    // Gửi yêu cầu GET lên server
    final response = await http.get(url);

    // 200 = OK (Thành công)
    if (response.statusCode == 200) {
      // response.body lúc này là 1 chuỗi String thô: '{"userId": 1, ...}'
      // jsonDecode sẽ biến chuỗi đó thành Map
      final Map rawJson = jsonDecode(response.body);
      
      // Đưa Map vào Post.fromJson để có Object hoàn chỉnh
      return Post.fromJson(rawJson);
    } else {
      throw Exception('Server trả về mã lỗi: ${response.statusCode}');
    }
  } catch (e) {
    throw Exception('Lỗi kết nối mạng: $e');
  }
}

// 2. Hàm GET danh sách nhiều bài viết (List)
Future> fetchAllPosts() async {
  final url = Uri.parse('https://jsonplaceholder.typicode.com/posts');
  final response = await http.get(url);

  if (response.statusCode == 200) {
    // Vì API này trả về 1 mảng JSON bọc trong [ ... ], nên jsonDecode ra List
    final List jsonList = jsonDecode(response.body);

    // Duyệt từng phần tử bằng .map() và đổi thành Post
    return jsonList.map((item) => Post.fromJson(item)).toList();
  } else {
    throw Exception('Không tải được danh sách');
  }
}

// Hàm main chạy thử nghiệm
void main() async {
  print('Đang gọi API lấy Post id = 3...');
  var p = await fetchPost(3);
  
  print('--- KẾT QUẢ NHẬN ĐƯỢC ---');
  print(p.toString());
  print('Tiêu đề bài viết: ${p.title}');
}

Bước 5: Gửi dữ liệu mới lên Server (HTTP POST)

Lưu ý khi gọi POST

Khi gửi dữ liệu (tạo tài khoản, tạo bài viết mới), bạn phải:

  • Kèm header 'Content-Type': 'application/json' để server hiểu.
  • Dùng jsonEncode(map) để mã hoá Map trong Dart thành chuỗi JSON thô gửi đi.
dart - Gọi HTTP POST
Future createPost(String title, String body, int userId) async {
  final url = Uri.parse('https://jsonplaceholder.typicode.com/posts');

  final response = await http.post(
    url,
    headers: {
      'Content-Type': 'application/json; charset=UTF-8',
    },
    body: jsonEncode({
      'title': title,
      'body': body,
      'userId': userId,
    }),
  );

  // 201 = Created (Tạo thành công)
  if (response.statusCode == 201) {
    return Post.fromJson(jsonDecode(response.body));
  } else {
    throw Exception('Lỗi tạo bài viết: ${response.statusCode}');
  }
}

6. Bảng tra cứu mã trạng thái HTTP (Status Code) hay gặp

Tra cứu danh mục mã chuẩn đầy đủ tại: MDN Web Docs - HTTP Response Status Codes → hoặc httpstatuses.com →

Status CodeTên mãÝ nghĩa thực tếCách xử lý trong code Flutter
200 OK Thành công Yêu cầu đã được server xử lý trọn vẹn (dùng cho GET, PUT). Lấy response.body parse sang Model.
201 Created Tạo mới thành công Server đã lưu bản ghi mới thành công (thường là POST). Thông báo Snackbar thành công trên UI và load lại danh sách.
400 Bad Request Yêu cầu không hợp lệ Dữ liệu gửi lên sai định dạng (thiếu trường, sai kiểu dữ liệu). Kiểm tra lại payload trong jsonEncode hoặc log xem server báo thiếu trường nào.
401 Unauthorized Chưa xác thực Chưa đăng nhập, thiếu Header Bearer Token hoặc JWT hết hạn. Xoá token lưu trong SharedPreferences và điều hướng về màn hình Login.
403 Forbidden Bị từ chối truy cập Đã đăng nhập nhưng không có quyền (ví dụ User thường cố vào trang Admin). Hiển thị thông báo "Bạn không có quyền thực hiện chức năng này".
404 Not Found Không tìm thấy Đường dẫn URL bị sai chính tả hoặc ID bài viết không tồn tại. Kiểm tra lại link URL hoặc hiển thị màn hình "Nội dung không tồn tại".
500 Server Error Lỗi máy chủ Lỗi sập phía backend (crash database, bug server). Báo cho người dùng "Hệ thống đang bảo trì, vui lòng thử lại sau".

7. Nâng cao: Gọi API chuyên nghiệp với thư viện dio

Vì sao nhiều dự án Flutter lớn dùng Dio thay vì http?

Thư viện mặc định http tuy nhẹ và chuẩn nhưng có nhược điểm: phải dùng Uri.parse(), phải jsonDecode() thủ công, không tự gắn Token tự động. dio là thư viện mạng (networking) mạnh mẽ số 1 của Flutter với các tính năng vượt trội:

  • Tự động Parse JSON: Không cần gõ jsonDecode(response.body), response.data đã là Map hoặc List sẵn!
  • BaseOptions & Timeout: Cấu hình URL gốc dùng chung (baseUrl) và thời gian chờ (Connect / Receive Timeout).
  • Interceptors (Bộ đánh chặn): Tự động nhét Token JWT vào mọi request gửi đi, tự động in log đẹp mắt (Pretty Logger).
  • Upload / Download file: Báo % tiến độ tải (Progress bar).
1
Cài đặt package dio
Terminal
flutter pub add dio
2
Code mẫu thực hành gọi API với Dio (So sánh cùng bài toán Post)

Xem code mẫu dưới đây để thấy sự tinh gọn của Dio:

dart - dio_service.dart
import 'package:dio/dio.dart';
import 'Post.dart';

// 1. Khởi tạo đối tượng Dio cấu hình sẵn baseUrl và Timeout
final dio = Dio(
  BaseOptions(
    baseUrl: 'https://jsonplaceholder.typicode.com',
    connectTimeout: const Duration(seconds: 10), // Quá 10s tự huỷ
    receiveTimeout: const Duration(seconds: 10),
    headers: {
      'Content-Type': 'application/json',
      // 'Authorization': 'Bearer my_token_here', // Tự động đính kèm Token
    },
  ),
);

// 2. Hàm GET 1 bài viết bằng Dio
Future fetchPostWithDio(int id) async {
  try {
    // Chỉ cần truyền đuôi path, không cần Uri.parse
    final response = await dio.get('/posts/$id');

    // KHÔNG CẦN jsonDecode! response.data đã là Map sẵn
    return Post.fromJson(response.data);
  } on DioException catch (e) {
    // Dio bắt lỗi chuyên sâu: timeout, mất mạng, lỗi 404/500
    if (e.type == DioExceptionType.connectionTimeout) {
      throw Exception('Kết nối mạng quá chậm, vui lòng thử lại');
    }
    throw Exception('Lỗi Dio: ${e.response?.statusCode} - ${e.message}');
  }
}

// 3. Hàm GET danh sách bài viết bằng Dio
Future> fetchAllPostsWithDio() async {
  try {
    final response = await dio.get('/posts');
    // response.data đã là List
    final List list = response.data;
    return list.map((item) => Post.fromJson(item)).toList();
  } catch (e) {
    throw Exception('Lỗi lấy danh sách: $e');
  }
}

// 4. Hàm POST tạo bài viết mới bằng Dio
Future createPostWithDio(String title, String body, int userId) async {
  try {
    // Truyền thẳng Map vào 'data', KHÔNG CẦN jsonEncode()
    final response = await dio.post(
      '/posts',
      data: {
        'title': title,
        'body': body,
        'userId': userId,
      },
    );

    return Post.fromJson(response.data);
  } catch (e) {
    throw Exception('Lỗi tạo bài: $e');
  }
}
