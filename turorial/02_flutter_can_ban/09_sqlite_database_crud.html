1. Bản Chất: SQLite Là Gì? Dùng Thế Nào? Vì Sao Phải Dùng SQLite?

1.1. SQLite là gì?

SQLite là một hệ quản trị cơ sở dữ liệu quan hệ (RDBMS - Relational Database Management System) nhúng (embedded), siêu nhẹ, mã nguồn mở và hoạt động độc lập (serverless). Khác với MySQL, SQL Server hay PostgreSQL cần một server dịch vụ riêng biệt lắng nghe cổng mạng (port), SQLite được tích hợp trực tiếp vào nhân hệ điều hành của thiết bị di động (Android, iOS) và lưu trữ toàn bộ dữ liệu (bảng, bản ghi, chỉ mục) vào chỉ một file nhị phân duy nhất nằm trong thư mục nội bộ (Internal Storage) của ứng dụng.

🗄️ Serverless & Nhúng Trực Tiếp

Không cần cài đặt Database Server, không cần cấu hình IP/Port hay Username/Password. Engine SQLite chạy trực tiếp bên trong cùng tiến trình bộ nhớ của ứng dụng Flutter.

1.2. SQLite được dùng như thế nào trong Flutter?

Trong ứng dụng Flutter, SQLite hoạt động theo mô hình cầu nối (Platform Channels / FFI):

  1. Định vị đường dẫn file DB: Ứng dụng hỏi hệ điều hành thư mục an toàn dành riêng cho app (thông qua hàm getDatabasesPath()) và nối với tên file (ví dụ: note_management.db).
  2. Khởi tạo & Tạo bảng (Schema): Khi mở DB lần đầu tiên (openDatabase), hàm callback onCreate sẽ kích hoạt để chạy câu lệnh DDL CREATE TABLE ... tạo cấu trúc các cột dữ liệu.
  3. Thực thi truy vấn (CRUD): Dart code gửi các yêu cầu CRUD dưới dạng câu lệnh SQL chuẩn hoặc thông qua các hàm tiện ích Object-Relational: query(), insert(), update(), delete().
  4. Chuyển đổi dữ liệu (ORM Mapping): Kết quả trả về từ SQLite luôn là một mảng Map List<Map<String, Object?>>. Lớp Model trong Dart sẽ ánh xạ qua lại bằng fromJson() và toJson().

1.3. Vì sao phải dùng SQLite? (Ưu điểm vượt trội)

  • Truy vấn có chọn lọc & tốc độ cao: Khi danh sách có hàng chục nghìn dòng, bạn chỉ cần lấy 10 bản ghi mới nhất (LIMIT 10) hoặc lọc các ghi chú chứa từ khóa nhất định (WHERE title LIKE '%họp%') mà không phải load toàn bộ dữ liệu vào RAM rồi lọc thủ công.
  • Bảo toàn tính toàn vẹn dữ liệu (ACID Transactions): Đảm bảo thao tác ghi hoặc thành công 100% hoặc rollback hoàn toàn, không bao giờ xảy ra tình trạng crash app làm hỏng hoặc mất nửa chừng dữ liệu.
  • Ràng buộc quan hệ dữ liệu: Dễ dàng thiết kế nhiều bảng liên kết với nhau (ví dụ: Bảng Category liên kết với Bảng Notes qua category_id, bảng Orders với OrderItems).
  • Bảo mật & Cô lập: File database được lưu trong Sandbox nội bộ của ứng dụng, các ứng dụng khác trên điện thoại không thể tự ý đọc hay can thiệp.

2. So Sánh Chuyên Sâu: SharedPreferences vs SQLite Local Database

Tiêu chí so sánh SharedPreferences (Mục 8) SQLite Database / sqflite (Mục 9)
Bản chất lưu trữ File XML (Android) / Plist (iOS) dạng Key - Value đơn giản. Một file database quan hệ nhị phân .db có bảng, cột và chỉ mục (Index).
Cấu trúc dữ liệu Phi cấu trúc (Lưu Primitive Types: bool, int, double, String, List<String>). Có cấu trúc chặt chẽ (Schema, Table, Column, Data Types: INTEGER, TEXT, REAL, BLOB).
Truy vấn & Lọc tìm kiếm Không hỗ trợ lọc. Phải nạp toàn bộ String JSON vào RAM rồi chạy vòng lặp lọc. Truy vấn cực mạnh bằng SQL: WHERE, ORDER BY, LIMIT, OFFSET, JOIN.
Dung lượng phù hợp Rất nhỏ (vài KB đến dưới 1-2 MB). Dùng nhiều sẽ gây giật lag do nạp toàn bộ file vào RAM khi mở app. Lớn (từ vài MB đến hàng trăm MB / hàng trăm nghìn bản ghi) mà vẫn mượt mà nhờ đọc phân trang.
Quan hệ giữa các bảng Không hỗ trợ (Flat Data). Hỗ trợ quan hệ 1-1, 1-N, N-N qua Khóa chính (Primary Key) & Khóa ngoại (Foreign Key).
Trường hợp sử dụng thực tế Lưu DarkMode, User Token (JWT), Ngôn ngữ, Cờ kiểm tra lần đầu mở app (isFirstOpen). Danh sách công việc (Todo/Notes), Giỏ hàng Offline, Lịch sử giao dịch, Cache tin nhắn, Danh mục sản phẩm.

3. Tổng Quan Các Thư Viện (Packages) Sẽ Sử Dụng & Vai Trò Cốt Lõi

Để xây dựng một ứng dụng SQLite hoàn chỉnh, mượt mà trên cả Mobile (Android, iOS) lẫn Web (Chrome Dev), chúng ta kết hợp các thư viện chuẩn sau:

📦 1. sqflite: ^2.4.2

Plugin SQLite chính thức và phổ biến nhất cho Flutter (Android, iOS, macOS). Cung cấp các API mở kết nối DB, thực thi lệnh DDL (tạo bảng) và các hàm tiện ích CRUD (insert, query, update, delete, transaction).

📦 2. path: ^1.9.1

Thư viện xử lý đường dẫn tệp tin đa nền tảng. Cung cấp hàm join(dir, 'app.db') giúp tự động chuẩn hóa dấu gạch nối (/ trên Linux/macOS/Android hoặc \ trên Windows) một cách chính xác tuyệt đối.

🌐 3. sqflite_common_ffi_web: ^1.2.0

Giải pháp đưa SQLite lên môi trường trình duyệt Web (Chrome) dựa trên nền tảng WebAssembly (Wasm) và IndexedDB. Giúp bạn test app SQLite nhanh chóng trên trình duyệt mà không cần mở máy ảo Android nặng nề.

⚡ 4. flutter_riverpod & riverpod_annotation

Bộ đôi quản lý State hiện đại. Cầu nối giữa giao diện UI và Cơ sở dữ liệu SQLite: Tự động tải danh sách ghi chú khi mở màn hình, phản ứng tự động vẽ lại giao diện khi có thêm/sửa/xóa thông qua ref.invalidateSelf().

Bước 2: Xây dựng Model Note với fromJson & toJson

Tạo file lib/model/note.dart. Model này đại diện cho 1 bản ghi trong bảng cơ sở dữ liệu. Lưu ý rằng trường id có kiểu int? (nullable) vì khi thêm mới, SQLite sẽ tự động tăng giá trị id (AUTOINCREMENT):

lib/model/note.dart 
class Note {
  int? id;         // id tự tăng trong SQLite, tạo mới thì để null
  String title;    // Tiêu đề ghi chú
  String content;  // Nội dung ghi chú

  Note({
    this.id,
    required this.title,
    required this.content,
  });

  // Chuyển dữ liệu Map đọc từ SQLite thành Object Note
  factory Note.fromJson(Map json) {
    return Note(
      id: json['id'] as int?,
      title: json['title'] as String,
      content: json['content'] as String,
    );
  }

  // Chuyển Object Note thành Map để truyền vào hàm insert/update của sqflite
  Map toJson() {
    return {
      'id': id,
      'title': title,
      'content': content,
    };
  }
}

Bước 3: Xây dựng lớp DatabaseHelper (Singleton Pattern & CRUD)

Tạo file lib/db/database_helper.dart. Ta áp dụng Singleton Pattern (private constructor) để đảm bảo toàn bộ ứng dụng chỉ có duy nhất 1 kết nối Database mở đồng thời, tránh xung đột file lock. Đồng thời viết đủ 4 hàm CRUD (getAll, create, update, delete):

lib/db/database_helper.dart 
import 'package:flutter/foundation.dart';
import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';
import 'package:sqflite_common_ffi_web/sqflite_ffi_web.dart';
import 'package:sqlite_intro/model/note.dart';

class DatabaseHelper {
  final _databaseName = 'note_management.db';
  static const _noteTableName = 'notes';

  // 1. Singleton pattern: Đảm bảo chỉ có 1 instance kết nối duy nhất
  DatabaseHelper._privateConstructor();
  static final DatabaseHelper instance = DatabaseHelper._privateConstructor();

  static Database? _database;

  // 2. Getter bất đồng bộ lấy database
  Future get database async {
    _database ??= await _initDatabase();
    return _database!;
  }

  // 3. Khởi tạo kết nối SQLite
  Future _initDatabase() async {
    // Nếu chạy trên Web Chrome: dùng factory FFI Web
    if (kIsWeb) {
      databaseFactory = databaseFactoryFfiWeb;
      return openDatabase(_databaseName, version: 1, onCreate: _onCreate);
    }

    // Nếu chạy trên Mobile (Android/iOS): Lấy thư mục databases chuẩn
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, _databaseName); // Nối chuỗi đường dẫn chuẩn
    return openDatabase(path, version: 1, onCreate: _onCreate);
  }

  // 4. Hàm tạo bảng chỉ chạy lần đầu tiên
  Future _onCreate(Database db, int version) async {
    await db.execute('''
      CREATE TABLE $_noteTableName (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        content TEXT NOT NULL
      )
    ''');
  }

  // 5. READ: Lấy toàn bộ danh sách notes (sắp xếp mới nhất lên đầu)
  Future> getAll() async {
    final db = await database;
    final List> maps = await db.query(
      _noteTableName,
      orderBy: 'id DESC',
    );
    return [for (final m in maps) Note.fromJson(m)];
  }

  // 6. CREATE: Thêm một Note mới
  Future create(Note note) async {
    final db = await database;
    return db.insert(_noteTableName, note.toJson());
  }

  // 7. UPDATE: Cập nhật Note theo id (Dùng whereArgs để chống SQL Injection)
  Future update(Note note) async {
    final db = await database;
    return db.update(
      _noteTableName,
      note.toJson(),
      where: 'id = ?',
      whereArgs: [note.id],
    );
  }

  // 8. DELETE: Xóa Note theo id
  Future delete(int id) async {
    final db = await database;
    return db.delete(
      _noteTableName,
      where: 'id = ?',
      whereArgs: [id],
    );
  }
}

Bước 4: Tạo State Notifier với Riverpod & Lệnh sinh mã tự động

Tạo file lib/providers/note_notifier.dart. Notifier chịu trách nhiệm gọi hàm DB và thông báo cho giao diện vẽ lại bằng ref.invalidateSelf():

lib/providers/note_notifier.dart 
import 'package:riverpod_annotation/riverpod_annotation.dart';
import 'package:sqlite_intro/db/database_helper.dart';
import '../model/note.dart';

part 'note_notifier.g.dart';

@riverpod
class NoteNotifier extends _$NoteNotifier {
  // Khi giao diện lắng nghe, hàm build() sẽ tự đọc danh sách Note từ SQLite
  @override
  Future> build() {
    return DatabaseHelper.instance.getAll();
  }

  // Thêm mới Note
  Future addNote(Note note) async {
    await DatabaseHelper.instance.create(note);
    ref.invalidateSelf(); // Kích hoạt build() chạy lại để nạp danh sách mới
    await future;         // Chờ đến khi build() mới nạp xong dữ liệu
  }

  // Cập nhật Note
  Future updateNote(Note note) async {
    await DatabaseHelper.instance.update(note);
    ref.invalidateSelf();
    await future;
  }

  // Xóa Note
  Future deleteNote(int id) async {
    await DatabaseHelper.instance.delete(id);
    ref.invalidateSelf();
    await future;
  }
}

Bước 5: Xây dựng màn hình Form thêm mới (NoteCreateScreen)

Tạo file lib/ui/note_create_screen.dart. Màn hình này thỏa mãn Tiêu chí 1, 2 và 3: Form có GlobalKey, kiểm tra độ dài title ≥ 3, content ≥ 10, bắt buộc gọi dispose() để hủy controller, hiển thị SnackBar và Navigator.pop():

lib/ui/note_create_screen.dart 
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:sqlite_intro/model/note.dart';
import 'package:sqlite_intro/providers/note_notifier.dart';

class NoteCreateScreen extends ConsumerStatefulWidget {
  const NoteCreateScreen({super.key});

  @override
  ConsumerState createState() => _NoteCreateScreenState();
}

class _NoteCreateScreenState extends ConsumerState {
  final GlobalKey _formKey = GlobalKey();
  final TextEditingController _titleController = TextEditingController();
  final TextEditingController _contentController = TextEditingController();

  // Bắt buộc: Hủy controller trong dispose() chống rò rỉ bộ nhớ
  @override
  void dispose() {
    _titleController.dispose();
    _contentController.dispose();
    super.dispose();
  }

  Future _saveForm() async {
    // 1. Kiểm tra Validate
    if (_formKey.currentState!.validate()) {
      final newNote = Note(
        title: _titleController.text.trim(),
        content: _contentController.text.trim(),
      );

      // 2. Lưu vào SQLite thông qua Notifier
      await ref.read(noteProvider.notifier).addNote(newNote);

      // 3. Hiển thị SnackBar thông báo và quay về trang danh sách
      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Thêm mới Note thành công!'),
            backgroundColor: Colors.green,
          ),
        );
        Navigator.pop(context);
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Create Note')),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              TextFormField(
                controller: _titleController,
                decoration: const InputDecoration(
                  labelText: 'Title',
                  border: OutlineInputBorder(),
                ),
                // Tiêu chí 2: Title ít nhất 3 ký tự
                validator: (value) {
                  if (value == null || value.trim().length < 3) {
                    return 'Title phải có ít nhất 3 ký tự';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 16),
              TextFormField(
                controller: _contentController,
                maxLines: 4,
                decoration: const InputDecoration(
                  labelText: 'Content',
                  border: OutlineInputBorder(),
                ),
                // Tiêu chí 2: Content ít nhất 10 ký tự
                validator: (value) {
                  if (value == null || value.trim().length < 10) {
                    return 'Content phải có ít nhất 10 ký tự';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 24),
              FilledButton.icon(
                onPressed: _saveForm,
                icon: const Icon(Icons.save),
                label: const Text('Save Note'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import 'package:sqlite_intro/model/note.dart';
import 'package:sqlite_intro/providers/note_notifier.dart';

class NoteEditScreen extends ConsumerStatefulWidget {
  final Note note; // Nhận đối tượng Note cần sửa
  const NoteEditScreen({super.key, required this.note});

  @override
  ConsumerState createState() => _NoteEditScreenState();
}

class _NoteEditScreenState extends ConsumerState {
  final GlobalKey _formKey = GlobalKey();
  late final TextEditingController _titleController;
  late final TextEditingController _contentController;

  @override
  void initState() {
    super.initState();
    // Gán dữ liệu hiện tại của Note vào Form
    _titleController = TextEditingController(text: widget.note.title);
    _contentController = TextEditingController(text: widget.note.content);
  }

  @override
  void dispose() {
    _titleController.dispose();
    _contentController.dispose();
    super.dispose();
  }

  Future _saveEditForm() async {
    if (_formKey.currentState!.validate()) {
      // Giữ nguyên id cũ để cập nhật đúng bản ghi
      final updatedNote = Note(
        id: widget.note.id,
        title: _titleController.text.trim(),
        content: _contentController.text.trim(),
      );

      await ref.read(noteProvider.notifier).updateNote(updatedNote);

      if (mounted) {
        ScaffoldMessenger.of(context).showSnackBar(
          const SnackBar(
            content: Text('Cập nhật Note thành công!'),
            backgroundColor: Colors.blue,
          ),
        );
        Navigator.pop(context);
      }
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Edit Note')),
      body: Padding(
        padding: const EdgeInsets.all(16.0),
        child: Form(
          key: _formKey,
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.stretch,
            children: [
              TextFormField(
                controller: _titleController,
                decoration: const InputDecoration(
                  labelText: 'Title',
                  border: OutlineInputBorder(),
                ),
                validator: (v) {
                  if (v == null || v.trim().length < 3) {
                    return 'Title phải có ít nhất 3 ký tự';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 16),
              TextFormField(
                controller: _contentController,
                maxLines: 4,
                decoration: const InputDecoration(
                  labelText: 'Content',
                  border: OutlineInputBorder(),
                ),
                validator: (v) {
                  if (v == null || v.trim().length < 10) {
                    return 'Content phải có ít nhất 10 ký tự';
                  }
                  return null;
                },
              ),
              const SizedBox(height: 24),
              FilledButton.icon(
                onPressed: _saveEditForm,
                icon: const Icon(Icons.check),
                label: const Text('Update Note'),
              ),
            ],
          ),
        ),
      ),
    );
  }
}

7. Bảng Tổng Hợp Lỗi Thường Gặp Khi Dùng SQLite & Cách Xử Lý

Hiện tượng / Thông báo lỗi Nguyên nhân gốc rễ Cách giải quyết dứt điểm
MissingPluginException (No implementation found for method getDatabasesPath) Chạy lệnh getDatabasesPath() khi app chưa kết nối Native Channels hoặc vừa thêm plugin sqflite vào pubspec.yaml nhưng chỉ Hot Reload. Tắt hẳn app (Dừng Debug / Stop Run) và thực hiện Rebuild lại từ đầu (Full Restart) để Gradle tích hợp thư viện native C/C++ vào Android APK. Thêm WidgetsFlutterBinding.ensureInitialized(); ở hàm main().
databaseFactory not initialized hoặc màn hình xám xịt khi chạy trên trình duyệt Web (Chrome) Mặc định thư viện sqflite chỉ hỗ trợ Mobile (Android/iOS). Khi chạy trên Web cần dùng factory FFI Web. Trong _initDatabase(), kiểm tra if (kIsWeb) { databaseFactory = databaseFactoryFfiWeb; } và chạy terminal: dart run sqflite_common_ffi_web:setup.
table notes already exists hoặc không thấy cột mới thêm Phương thức _onCreate chỉ chạy đúng 1 lần khi DB vừa được tạo. Khi bạn sửa code DDL tạo cột mới, SQLite thấy file .db đã tồn tại nên không chạy lại _onCreate. Gỡ cài đặt (Uninstall) app khỏi máy ảo/điện thoại rồi cài lại, hoặc tăng biến version: 2 trong openDatabase và viết hàm onUpgrade.
Nguy cơ dính lỗ hổng bảo mật SQL Injection Ghép chuỗi thô trực tiếp vào câu lệnh SQL, ví dụ: rawDelete("DELETE FROM notes WHERE id = $id"). Nếu tham số chứa mã độc SQL, kẻ xấu có thể can thiệp dữ liệu. Luôn dùng dấu chấm hỏi (Placeholder ?) và truyền giá trị qua mảng whereArgs: db.delete('notes', where: 'id = ?', whereArgs: [id]);.
UI không tự động cập nhật khi vừa Insert/Delete thành công Quên báo hiệu cho State Management biết dữ liệu dưới DB đã thay đổi. Trong Notifier, sau mỗi hàm create/update/delete, luôn gọi ref.invalidateSelf(); await future; để Riverpod tự động kéo dữ liệu mới nhất lên màn hình.
A TextEditingController was used after being disposed Màn hình đã bị đóng nhưng một hàm bất đồng bộ (hoặc Animation) vẫn cố tình truy cập vào _titleController.text sau khi đã gọi dispose(). Kiểm tra if (!mounted) return; trước khi thao tác trên UI hoặc chuyển dòng dispose() xuống cuối cùng sau khi mọi tiến trình kết thúc.
